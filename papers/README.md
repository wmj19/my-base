# Papers

用于统一保存本仓库的论文原始文件，例如 PDF、补充材料或其他原文附件。

## 维护说明

- 后续所有论文原始文件优先放在本目录，不再分散到各专题目录。
- 文件名优先保留稳定标识，例如 arXiv ID、DOI 简写或 `YYYY-first-author-short-title.pdf`。
- 专题笔记、日报和综述中用相对链接指向本目录中的原始文件。
- 如果文件很大或数量很多，先确认是否需要 Git LFS 或外部归档。
