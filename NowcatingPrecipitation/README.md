- 新增论文优先放入 `literature/daily/`，并在需要去重时更新 `literature/paper-index.json`。
- 论文原始文件统一放入仓库根目录 `papers/`，本专题只保留笔记、索引和总结。
- 阶段性方法总结放入 `summaries/`，并尽量反向链接到已有日报或索引条目。
- 对论文发表状态、数据集公开性、代码链接和实验细节等易变化信息，需要记录核验日期；未联网核验的内容应明确标注。
