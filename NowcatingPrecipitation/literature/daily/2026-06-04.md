### 1. A Deep Learning Method Integrating Meteorological Data for Heavy Precipitation Nowcasting in the Alps Region

- **链接**: https://doi.org/10.3390/app16094481
- **PDF**: 无公开 PDF；ResearchGate 页面显示可请求全文
- **来源**: Applied Sciences / ResearchGate / EBSCO，2026-06-04 检索中作为近 7 天新近抓取/索引结果发现
- **发布日期/版本日期**: 2026-05；ResearchGate/EBSCO 结果在本次扫描中显示近 4-6 天内抓取
- **作者**: Yilin Mu, Jiahe Liu, Yang Li, Ruidong Zhang
- **机构/会议/期刊**: Applied Sciences, 16(9), 4481
- **DOI / arXiv ID**: 10.3390/app16094481
- **关键词标签**: heavy precipitation nowcasting; Nwf-Net; optical flow; radar echo; recurrent neural network; Alpine region
- **研究方向**: Multi-source fusion；Physics-informed / physical constraints；Radar echo extrapolation
- **使用的数据集**: Alpine region radar echo / multi-source meteorological data
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 可检索摘要说明 Nwf-Net 的 MET 模块结合高空风场与传统光流来表征 radar echoes 的位移和形态变化，RIC 模块用深度循环网络修正强对流回波强度，并在 Alps 区域用 32 dBZ 阈值评估。

**摘要**

论文面向阿尔卑斯复杂地形下的短时强降水预报。作者指出数值模式在高分辨率强降水捕捉上不足，而传统雷达外推难以同时描述平流、形变和强度调整。为此提出 Nwf-Net，将多源气象资料、光流运动估计和深度循环网络结合，用于提高强对流回波的临近预报能力。

**方法概述**

Nwf-Net 由 Morphological Evolution Track Module (MET) 和 Rainfall Intensity Correction Module (RIC) 串联组成。MET 利用高空风场和光流算法联合刻画雷达回波位移与形态演变；RIC 使用深度循环网络对降水/回波强度进行订正，重点改善强对流区域的强度维持。

**主要贡献**

1. 将传统光流外推、高空环境风和深度网络强度订正组合为两阶段 nowcasting 框架。
2. 针对复杂地形强降水场景设计，强调对强对流回波位移、形变和强度变化的联合处理。
3. 在 32 dBZ 阈值下报告 CSI、HSS 和 F1 优于传统数值模式及部分主流模型。

**与基于雷达回波的降水临近预报的关系**

高度相关。该方法直接围绕雷达回波外推和强回波强度订正展开，可作为“光流/物理运动估计 + 深度学习强度修正”的混合路线案例。

**值得关注的原因**

复杂地形区域的强降水 nowcasting 往往受地形触发、垂直风场和局地强对流影响。Nwf-Net 与纯 radar-only 深度模型不同，强调把运动估计和环境风信息显式纳入流程，适合与 NowPrecip、NowcastNet、PW-FouCast 等融合物理或环境背景的方案比较。

**可能局限**

目前可检索页面主要提供摘要级信息，尚需核查完整实验设置、雷达产品类型、训练/测试时段划分、开源代码和跨区域泛化能力。

**后续讨论问题**

1. MET 中高空风场对复杂地形强降水位移误差的贡献有多大？
2. RIC 的深度循环网络主要修正强度衰减，还是也修正位置偏差？
3. 该方法是否能迁移到中国西南、华南山区等地形降水 nowcasting 场景？

### 2. TSPF-GAN: A lightweight temporal-spatial-pixel feature fusion GAN for radar-based precipitation nowcasting

- **链接**: https://doi.org/10.1007/s12145-025-02056-9
- **PDF**: 无公开 PDF；ResearchGate 页面提供 Springer preview
- **来源**: Earth Science Informatics / EBSCO / ResearchGate，2026-06-04 检索中作为近 7 天新近索引结果发现
- **发布日期/版本日期**: Published online 2025-12-12；Earth Science Informatics 19(1), 2026；EBSCO 结果在本次扫描中显示近 6 天抓取
- **作者**: Haiping Zhang, Benze Zhang, Baitian Liu, Dongjing Wang, Liming Guan, Chonglei Zhu, Zeng Zhang
- **机构/会议/期刊**: Earth Science Informatics, 19(1), Article 3
- **DOI / arXiv ID**: 10.1007/s12145-025-02056-9
- **关键词标签**: TSPF-GAN; radar-based precipitation nowcasting; GAN; lightweight model; temporal-spatial-pixel fusion; Shanghai radar
- **研究方向**: GAN / adversarial models；Radar echo extrapolation；CNN encoder-decoder
- **使用的数据集**: Netherlands real precipitation radar dataset；Shanghai radar dataset
- **重点公开数据集匹配**: ShangHai / Shanghai radar
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 可检索摘要说明该任务是基于当前观测预测 radar echo sequences；实验使用荷兰真实降水雷达数据集，并与扩散方法在 Shanghai radar dataset 上比较。

**摘要**

论文关注雷达降水临近预报中两个常见问题：强降水样本不平衡导致模型对重雨区不敏感，以及大模型计算成本高。作者提出 TSPF-GAN，用轻量级生成对抗网络和时空像素级特征融合来增强强降水区域预测。

**方法概述**

TSPF-GAN 的核心是 Temporal-Spatial-Pixel Fusion Module (TSPFM)，通过阈值引导机制和多尺度特征融合加强对重降水区域的感知。模型整体只有约 4.5M 参数，并配合针对重降水区域增强的混合损失函数训练，以在保持预测质量的同时降低计算资源需求。

**主要贡献**

1. 提出面向 radar-based precipitation nowcasting 的轻量 GAN 框架。
2. 用阈值引导的时空像素融合模块增强强降水区域表达。
3. 在荷兰雷达数据上验证，并在 Shanghai radar dataset 上与扩散模型比较，报告参数量显著降低。

**与基于雷达回波的降水临近预报的关系**

高度相关。该文直接预测雷达回波/降水雷达序列，且包含 Shanghai radar 公开基准信号，可用于补充轻量化 GAN 与强降水不平衡处理方向。

**值得关注的原因**

ShangHai/Shanghai Radar 是本项目重点跟踪数据集之一。TSPF-GAN 的价值在于把强降水感知和轻量化放在同一框架中，适合与 DiffCast、FADiff、PixelFlowCast、WADEPre 等强调强回波细节但通常计算较重的方法比较。

**可能局限**

公开可访问材料有限，暂未核查完整基线表、Shanghai 数据预处理、阈值设置和代码可复现性；Springer 正文访问情况仍需后续确认。

**后续讨论问题**

1. TSPFM 的阈值引导是否依赖数据集特定雨强/反射率阈值？
2. 与扩散模型相比，TSPF-GAN 的优势主要来自参数量、推理速度还是强降水召回？
3. Netherlands radar 与 Shanghai radar 的分布差异是否会影响轻量模型泛化？

### 3. MMF-RNN: A Multimodal Fusion Model for Precipitation Nowcasting Using Radar and Ground Station Data

- **链接**: https://doi.org/10.1109/TGRS.2025.3528423
- **PDF**: 无公开 PDF
- **来源**: IEEE Transactions on Geoscience and Remote Sensing / Monash University metadata / DBLP，2026-06-04 检索中作为近 7 天新近抓取/索引结果发现
- **发布日期/版本日期**: 2025；DBLP/researchr 结果在本次扫描中显示近 7 天抓取
- **作者**: Qian Liu, Yongxiang Xiao, Yaocheng Gui, Guilan Dai, Haoran Li, Xu Zhou, Aiai Ren, Guoqiang Zhou, Jun Shen
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing, Vol. 63, Article 4101416
- **DOI / arXiv ID**: 10.1109/TGRS.2025.3528423
- **关键词标签**: MMF-RNN; radar and ground station fusion; recurrent neural network; BDWLoss; multimodal loss; RAIN-F
- **研究方向**: Multi-source fusion；ConvLSTM / recurrent models；Radar-gauge fusion
- **使用的数据集**: RAIN-F radar and ground station dataset
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Monash 元数据摘要说明 MMF-RNN 使用双分支编码器提取 radar 和 ground station data 特征，在 RAIN-F 数据集上评估，并面向 0-2 h radar echo extrapolation / precipitation nowcasting。

**摘要**

论文认为许多深度学习降水临近预报工作主要改进模型结构，但较少处理误差累积和多模态数据不一致问题。MMF-RNN 通过融合雷达和地面站观测，尝试提高重降水预测能力，并缓解单模态雷达模型在复杂降水场景中的误差放大。

**方法概述**

模型使用双分支编码器分别提取雷达图像和地面站序列特征，再通过注意力机制进行融合。作者提出 block-based dynamic weighted loss (BDWLoss) 让模型更关注难预测区域，并设计 multimodal loss 约束单模态与融合特征的一致性。MMF-RNN 可嵌入 ConvLSTM、PredRNN、PredRNN++ 和 MIM 等不同循环主干。

**主要贡献**

1. 提出雷达与地面站数据融合的 recurrent nowcasting 框架。
2. 用 BDWLoss 处理难预测区域和误差累积。
3. 用 multimodal loss 缓解单模态和融合多模态表征之间的不一致。
4. 在 RAIN-F 数据集上报告对重降水 CSI/HSS 的明显提升。

**与基于雷达回波的降水临近预报的关系**

高度相关。该文以雷达资料为主要空间输入，并将地面站观测作为补充信息，属于 radar-gauge / radar-station fusion nowcasting 方向。

**值得关注的原因**

对于业务 nowcasting，纯雷达序列常受遮挡、估计误差和局地强降水样本不足影响。MMF-RNN 提供了一个把地面站信息系统性接入 RNN 外推框架的近期 TGRS 案例，可与 MM-RNN、MSDM、MS-FTNet 等多源融合模型形成谱系。

**可能局限**

RAIN-F 数据集的公开性、站点密度、空间插值方式和跨区域泛化仍需进一步核查；IEEE 正文未直接开放，细节依赖元数据摘要。

**后续讨论问题**

1. 地面站观测对雷达强降水漏报的修正是否在高阈值上最明显？
2. MMF-RNN 与雷达-卫星融合模型相比，哪类多源信息对 0-2 h lead time 更有效？
3. BDWLoss 是否可以迁移到扩散、Mamba 或 Transformer nowcasting 主干？
