### 1. METEO-DLNet: Quantitative Precipitation Nowcasting Net Based on Meteorological Features and Deep Learning

- **链接**: https://doi.org/10.3390/rs16061063
- **PDF**: https://www.mdpi.com/2072-4292/16/6/1063/pdf
- **来源**: Remote Sensing / MDPI / Crossref / ResearchGate full-text preview
- **发布日期/版本日期**: 2024-03-17；Crossref indexed 2026-07-24
- **作者**: Jianping Hu; Bo Yin; Chaoqun Guo
- **机构/会议/期刊**: Remote Sensing, 16(6), 1063
- **DOI / arXiv ID**: 10.3390/rs16061063
- **关键词标签**: METEO-DLNet; Meteo-LSTM; radar echo extrapolation; spatial attention; differential attention; multi-scale fusion
- **研究方向**: ConvLSTM / recurrent models；Transformer / attention models；Radar echo extrapolation；Quantitative precipitation nowcasting
- **使用的数据集**: 论文实验中的 radar echo test set；可访问摘要和全文预览未显示具体数据集名称
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref 摘要说明该方法面向基于 radar echo extrapolation 的短时降水预报；ResearchGate/MDPI 全文预览说明框架预测 radar echo images，并给出 radar echo test set 上的比较结果。

**摘要**

论文提出 METEO-DLNet，用于短时定量降水临近预报。作者认为已有深度学习雷达回波外推模型对降水过程的气象特征利用不足，尤其在局地回波图像与整体趋势不一致时，传统结构容易出现预测偏差。

**方法概述**

METEO-DLNet 以 Meteo-LSTM 和多尺度融合为核心。Meteo-LSTM 结合空间注意力和差分注意力，学习雷达回波图像在空间和时间尺度上的演变特征；融合机制使用 self-attention 与 gating，将局地尺度图像和整体趋势进行合并，得到未来雷达回波图像。

**主要贡献**

1. 提出面向雷达回波图像预测的 METEO-DLNet 框架。
2. 在 LSTM 单元中引入空间注意力和差分注意力，以加强对回波时空演变特征的建模。
3. 用多尺度融合机制缓解局部图像与全局趋势偏离导致的预测误差。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务明确围绕 radar echo extrapolation 和 radar echo image prediction，可作为注意力增强 recurrent nowcasting 模型的补充条目。

**值得关注的原因**

它把“气象特征”显式放入 recurrent 单元和多尺度融合设计中，可与 PrecipLSTM、ST-LSTM-SA、Rainformer、ST-TriMambaUNet 等以时空特征增强为主的确定性模型比较。

**可能局限**

可访问元数据没有给出具体公开数据集名称，也未命中 CIKM、ShangHai、SEVIR 或 MetNet；后续需要核验完整 PDF 中的数据来源、样本划分和阈值定义。

**后续讨论问题**

1. Meteo-LSTM 的差分注意力主要改善位移误差，还是改善强回波强度保持？
2. 该模型能否在 CIKM、Shanghai 或 SEVIR 上与 Rainformer / Earthformer 做统一复现？
3. 多尺度融合的收益是否来自全局趋势约束，还是来自局地特征的额外容量？

### 2. A Radar Reflectivity Image Prediction Method: The Spatial MIM + Pix2Pix

- **链接**: https://doi.org/10.3390/rs15235554
- **PDF**: https://www.mdpi.com/2072-4292/15/23/5554/pdf
- **来源**: Remote Sensing / MDPI / Crossref / ResearchGate full-text preview
- **发布日期/版本日期**: 2023-11-29；Crossref indexed 2026-07-23
- **作者**: Jianlin Guo; Zhiying Lu; Qin Yan; Jianfeng Zhang
- **机构/会议/期刊**: Remote Sensing, 15(23), 5554
- **DOI / arXiv ID**: 10.3390/rs15235554
- **关键词标签**: Spatial MIM; Pix2Pix; radar reflectivity image prediction; GAN; dual-polarization weather radar; Oklahoma radar
- **研究方向**: ConvLSTM / recurrent models；GAN / adversarial models；Radar reflectivity；Short-term weather radar forecasting
- **使用的数据集**: NOAA dual-polarization weather radar data from Oklahoma, United States, Q2-Q3 2021
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI / ResearchGate 全文预览说明论文预测 radar reflectivity images，并使用 NOAA 提供的 Oklahoma dual-polarization weather radar data 进行实验。

**摘要**

论文研究雷达反射率图像预测。作者指出，雷达反射率图像可以反映对流云内部发展，对降水预测有重要价值；但常规预测模型容易丢失高频细节，导致结果模糊、强回波结构不清晰。

**方法概述**

方法分为两个阶段。第一阶段使用 Spatial Memory in Memory (Spatial MIM) 网络生成粗略的未来雷达反射率图像；第二阶段把 Spatial MIM 的结果输入 Pix2Pix 网络，对高频细节进行增强，从而改善图像模糊问题并提高反射率强度估计精度。

**主要贡献**

1. 将 Spatial MIM 用于雷达反射率图像的时空预测。
2. 结合 Pix2Pix 对预测图像进行细节增强，针对深度回归模型常见的模糊问题做后处理式修正。
3. 在 NOAA/Oklahoma 双偏振天气雷达资料上验证未来反射率图像预测效果。

**与基于雷达回波的降水临近预报的关系**

相关性中高。该文不是标准公共基准降水 nowcasting 论文，但任务是天气雷达反射率图像预测，属于短时天气雷达 forecasting / radar reflectivity extrapolation 的相邻方向。

**值得关注的原因**

Spatial MIM + Pix2Pix 代表一种“先时序外推、再生成式锐化”的两阶段方案，可与 AENN、GAN-rcLSTM、DGMR 以及后续 diffusion / flow matching 模型比较其清晰度提升是否带来物理可信度风险。

**可能局限**

论文没有命中 CIKM、ShangHai、SEVIR 或 MetNet；任务表述更偏 radar reflectivity image prediction，和定量降水 nowcasting 的指标、阈值及降水单位仍需映射。

**后续讨论问题**

1. Pix2Pix 增强的高频细节是否会引入位置偏移或虚假强回波？
2. Spatial MIM 粗预测与 Pix2Pix 细化之间是否能端到端联合训练？
3. 如果迁移到 CIKM / Shanghai / SEVIR，生成式细节增强能否提升高阈值 CSI？

### 3. WinG-LSTM: a precipitation nowcasting model integrating swin transformer and LSTM

- **链接**: https://doi.org/10.1007/s00704-026-06079-0
- **PDF**: 无稳定开放 PDF；Springer/ResearchGate 页面提供预览
- **来源**: Theoretical and Applied Climatology / Springer / Crossref / ResearchGate preview
- **发布日期/版本日期**: 2026-02-14；Crossref indexed 2026-03-21；本轮 priority dataset 搜索中新抓取 / 新发现
- **作者**: Xu Yang; Changyong Zheng; Yating Wu; Xu Chu; Jun Zhang
- **机构/会议/期刊**: Theoretical and Applied Climatology, 157, article 138
- **DOI / arXiv ID**: 10.1007/s00704-026-06079-0
- **关键词标签**: WinG-LSTM; Swin Transformer; PredRNN; SwiGLU; radar echo images; CIKM2017; Shanghai Radar
- **研究方向**: Transformer / attention models；ConvLSTM / recurrent models；Radar echo extrapolation；Precipitation nowcasting
- **使用的数据集**: CIKM2017；Shanghai Radar dataset
- **重点公开数据集匹配**: CIKM；ShangHai / Shanghai
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Springer 摘要说明 precipitation nowcasting 本质上是 radar echo images 的 spatiotemporal extrapolation；ResearchGate/Springer 预览说明 WinG-LSTM 在 CIKM2017 和 Shanghai Radar dataset 上评估，并输出更接近真实 radar observations 的预测。

**摘要**

论文提出 WinG-LSTM，将 Swin Transformer 与 PredRNN 结合，用于雷达回波图像序列的降水临近预报。作者关注 CNN/RNN 框架难以捕捉长程空间依赖、强降水强度和范围被低估等问题。

**方法概述**

WinG-LSTM 在 PredRNN 式时序建模基础上引入 Swin Transformer 模块，通过窗口注意力捕捉更大范围的空间依赖；同时在 Swin Transformer 的 MLP block 中加入 gating 机制，以增强特征表达。模型针对雷达回波序列进行未来帧预测，并在 CIKM2017 与 Shanghai Radar 两个数据集上比较。

**主要贡献**

1. 将 Swin Transformer 的局部窗口注意力与 LSTM / PredRNN 时序建模结合。
2. 在 MLP 中引入 gating 机制，提高雷达回波特征表达能力。
3. 在 CIKM2017 和 Shanghai Radar 两个重点公开数据集上报告相对比较模型的性能提升。

**与基于雷达回波的降水临近预报的关系**

相关性很高。该文直接预测 radar echo images，并命中本任务重点关注的 CIKM 和 Shanghai / ShangHai 数据集，便于与 ConvLSTM、TrajGRU、PredRNN、Rainformer、DiffCast 等公开基准方法横向比较。

**值得关注的原因**

CIKM 与 Shanghai Radar 是国内雷达回波外推文献中常用公开基准。WinG-LSTM 提供了一个 Transformer + recurrent 的混合路线，可用于比较注意力结构对强回波保持和长时效空间结构的帮助。

**可能局限**

正式发表和 Crossref indexed 日期早于本轮 7 天窗口；本次纳入依据是 priority dataset 检索中新发现且本地未收录。缺少稳定开放 PDF 时，后续还需要核验完整实验设置、输入输出长度、阈值和代码可用性。

**后续讨论问题**

1. WinG-LSTM 在 CIKM2017 与 Shanghai Radar 上的优势是否主要来自 Swin window attention，还是来自 PredRNN 递推结构？
2. 与纯 Transformer 或 Mamba 模型相比，recurrent 路径是否仍能改善长 lead time 稳定性？
3. SwiGLU 式 gating 对高阈值强回波 CSI 是否有单独贡献？
