### 1. Exploring the ability of regional extrapolation for precipitation nowcasting with deep learning

- **PDF**: https://refubium.fu-berlin.de/bitstream/handle/fub188/44865/metz_Vol_33_No_4_p305-321_Exploring_the_ability_of_regional_extrapolation_for_precipitation_nowcasting_with_deep_learning_105576.pdf

- **机构/会议/期刊**: Meteorologische Zeitschrift, Vol. 33 No. 4, pp. 305-321
- **DOI / arXiv ID**: 10.1127/metz/2024/1189
- **关键词标签**: TrajGRU; regional transfer; fine-tuning; RADOLAN; German Weather Service radar; deep learning
- **研究方向**: ConvLSTM / recurrent models；Radar-derived precipitation；Precipitation nowcasting；Transfer learning / regional extrapolation
- **使用的数据集**: DWD RADOLAN / German Meteorological Service radar data；德国不同区域的雷达降水场
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Freie Universität Berlin 页面摘要明确说明该工作将 Trajectory Gated Recurrent Unit 应用于 German Meteorological Service 的 radar data；Refubium/PDF 元数据关键词包含 RADOLAN，并在正文中介绍 RADOLAN 数据集。

**摘要**

论文研究深度学习降水临近预报模型能否从一个区域迁移到另一个区域，尤其是在目标区域强降水样本较少时，预训练模型是否能通过少量微调获得更好的 nowcasting 能力。问题背景是德国局地短时强降水频率低、空间差异明显，直接为每个区域训练模型可能数据不足。

**方法概述**

作者使用 TrajGRU 作为时空序列预测模型，在 RADOLAN 雷达降水数据上进行预训练和区域微调。实验比较不同训练区域、目标区域和降水强度阈值下的 CSI、HSS、POD、FAR 等指标，并考察预测时效到 100 分钟时模型 skill 的变化。

**主要贡献**

1. 将雷达降水 nowcasting 的区域迁移问题显式化，评估从一个德国区域迁移到另一个区域的可行性。
2. 证明在目标区域训练数据有限、强降水稀缺时，预训练 + fine-tuning 能保留源区域模型的部分 skill。
3. 按不同降水阈值和 lead time 展示区域外推能力，为业务部署中的本地化微调提供参考。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文直接使用 DWD 雷达降水产品做深度学习临近预报，重点不在新网络结构，而在区域泛化、迁移学习和少样本强降水场景。

**值得关注的原因**

很多公开基准默认训练集和测试集来自同一区域；该文更接近业务问题：一个区域训练出的模型能否服务另一个区域，哪些阈值下迁移最容易失效。

**可能局限**

实验集中在德国 RADOLAN 产品，未覆盖 CIKM、Shanghai、SEVIR 等公共视频预测式基准；不同区域的雷达质量控制、地形影响和降水气候差异可能限制泛化结论。

**后续讨论问题**

1. RADOLAN 的降水强度阈值能否和 CIKM / SEVIR 的 dBZ 或 VIL 阈值建立可比关系？
2. 区域迁移收益主要来自运动模式共享，还是来自降水强度分布的相似性？
3. 是否可以用 domain adaptation 或 test-time adaptation 替代简单 fine-tuning？

- **机构/会议/期刊**: Atmospheric Research, Vol. 319, Article 108010
- **DOI / arXiv ID**: 10.1016/j.atmosres.2025.108010
- **关键词标签**: high-resolution radar; U-Net; CINRAD; X-band radar; S-band radar; spatial resolution; convective cases
- **研究方向**: CNN encoder-decoder；Radar-derived precipitation；Quantitative precipitation nowcasting；Data-resolution study
- **使用的数据集**: North China CINRAD network observations；one S-band and nine X-band dual-polarimetric radars；1000 m, 500 m, and 100 m gridded radar data

- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ScienceDirect 摘要和数据片段说明模型使用不同空间分辨率的 radar data 训练；数据来自中国北方 CINRAD 网络中的一个 S-band 和九个 X-band 双偏振雷达。

**摘要**

论文关注一个常被模型结构研究忽略的问题：在深度学习降水临近预报中，提高雷达输入分辨率是否比增加模型规模更有效。作者认为，很多研究默认使用公里级雷达网格，但现代 X 波段双偏振雷达已经能提供百米级空间分辨率，这可能直接改善强对流边界和局地降水结构的预测。

**方法概述**

作者构建两个 U-Net 架构模型，一个较大、一个较小，并分别使用 1000 m、500 m、100 m 三种空间分辨率雷达数据训练。实验以中国北方多个 S / X 波段双偏振雷达融合数据为基础，在两个对流降水个例中比较预测精度、偏差和空间对齐表现，同时和若干 baseline 做对比。

**主要贡献**

1. 系统比较雷达空间分辨率对深度学习 nowcasting 性能的影响。
2. 证明 100 m 级雷达数据有助于模型捕捉降水边界和局地强对流结构。
3. 提出在资源有限时，优先提升数据分辨率可能比扩大网络参数更划算。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文直接讨论雷达数据分辨率对 DL nowcasting 的影响，对高分辨率城市暴雨、X 波段雷达网和小模型部署有参考价值。

**值得关注的原因**

当前公共基准多为统一裁剪后的低到中等分辨率栅格，容易把研究焦点放在模型结构上。该文提醒：雷达观测分辨率本身可能是提升临近预报空间细节的关键瓶颈。

**可能局限**

实验主要基于少数中国北方对流个例，跨季节、跨区域和业务连续运行稳定性仍需验证。论文没有命中 CIKM / Shanghai / SEVIR 等重点公开数据集，因此不便直接和视频预测文献做基准对齐。

**后续讨论问题**

1. 100 m 雷达输入的收益是否能在 30-90 分钟更长 lead time 中保持？
2. 高分辨率数据带来的收益是否主要体现在强降水阈值，还是也提升弱降水覆盖？
3. 若将 100 m 数据下采样成公共基准格式，会损失哪些空间结构信息？

### 3. Mutual Information Boosted Precipitation Nowcasting from Radar Images

- **链接**: https://doi.org/10.3390/rs15061639
- **PDF**: https://www.mdpi.com/2072-4292/15/6/1639/pdf
- **来源**: Remote Sensing / Crossref / MDPI search metadata
- **发布日期/版本日期**: 2023-03-17；Crossref indexed 2026-07-17
- **作者**: Yuan Cao; Danchen Zhang; Xin Zheng; Hongming Shan; Junping Zhang
- **机构/会议/期刊**: Remote Sensing, 15(6), 1639
- **DOI / arXiv ID**: 10.3390/rs15061639
- **关键词标签**: mutual information; MIR; TSS; data imbalance; radar echo intensity; curriculum learning; HKO-7; ECP; TAASRAD19
- **研究方向**: Loss reweighting；ConvLSTM / recurrent models；Radar echo extrapolation；Heavy-rainfall imbalance
- **使用的数据集**: ECP; TAASRAD19; HKO-7
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI / ResearchGate 可访问全文片段说明论文以历史和未来 radar echo images 表示 X 与 Y，关注 radar echo intensity prediction，并展示 ECP、TAASRAD19、HKO-7 三个雷达回波强度数据集的分布。

**摘要**

论文从互信息角度分析降水临近预报中不同预测时长任务的信息量，指出长 lead time 和强对流稀缺会使模型难以兼顾整体图像质量与强降水区域表现。作者希望用简单的训练策略改善雷达回波强度预测中的类别不平衡问题。

**方法概述**

论文提出 Mutual Information-based Reweighting (MIR) 和 Time Superimposing Strategy (TSS)。MIR 根据输入与目标之间的互信息关系调整训练权重，避免只按降水强度分布粗暴上采样；TSS 类似课程学习，把不同 forecast length 的任务组合起来，使模型逐步学习更困难的长时效预测。

**主要贡献**

1. 用互信息解释不同预测时长和雷达回波强度类别之间的可预测性差异。
2. 提出 MIR 与 TSS 两种可插拔训练策略，用于改善强回波预测。
3. 在 ECP、TAASRAD19、HKO-7 等雷达回波数据上验证策略可适配多种基础模型。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文不是提出全新 backbone，而是针对雷达回波 nowcasting 中常见的强回波稀缺和长 lead time 信息衰减问题设计训练策略。

**值得关注的原因**

强降水区域往往只占少量像素，简单加权可能牺牲整体稳定性。互信息视角能帮助区分“难预测但重要”的区域和“统计上稀有但条件信息不足”的区域。

**可能局限**

论文使用的 HKO-7、ECP、TAASRAD19 不属于本任务重点公开数据集中的 CIKM、Shanghai、SEVIR、MetNet；互信息估计本身可能受样本量和离散化方式影响。

**后续讨论问题**

1. MIR 是否能和 focal loss、balanced loss 或 heavy-rain mask loss 组合？
2. 在 CIKM / SEVIR 上，互信息随 lead time 衰减的形态是否一致？
3. TSS 对生成式模型是否仍有帮助，还是主要适用于确定性回归模型？

### 5. LLMDiff: Diffusion Model Using Frozen LLM Transformers for Precipitation Nowcasting

- **来源**: Sensors / Crossref / MDPI
- **发布日期/版本日期**: 2024-09-19；Crossref indexed 2026-07-20
- **作者**: Lei She; Chenghong Zhang; Xin Man; Jie Shao
- **机构/会议/期刊**: Sensors, 24(18), 6049
- **DOI / arXiv ID**: 10.3390/s24186049
- **关键词标签**: LLMDiff; diffusion model; frozen LLM transformer; Earthformer; SEVIR; radar echo map; probabilistic nowcasting

- **使用的数据集**: SEVIR
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI 摘要说明 LLMDiff 在 SEVIR 数据集上优于 SOTA；关键词包含 radar echo map，正文说明 precipitation nowcasting 使用 radar echo maps 作为输入并预测 future radar echo images。

**摘要**

论文提出 LLMDiff，将扩散模型用于概率式降水临近预报，并尝试把冻结的大语言模型 Transformer block 作为视觉编码层，用于捕捉雷达回波序列中的长时序上下文和运动趋势。作者认为扩散模型适合描述降水系统不确定性，但需要更有效的条件信息和时序依赖建模。

**方法概述**

LLMDiff 包含条件 encoder-decoder 网络和 denoising 网络。第一阶段使用 EDNet 生成条件帧，第二阶段使用基于 Earthformer 的扩散 denoising 网络生成未来雷达回波序列。模型在 denoising 网络中插入冻结的 LLM Transformer block，并通过线性层对齐维度，希望借助预训练 Transformer 的序列建模能力改善运动趋势估计。

**主要贡献**

1. 将冻结 LLM Transformer block 引入雷达降水 nowcasting 的扩散框架。
2. 使用条件帧而非单纯隐特征来引导 denoising，提高空间信息保留。
3. 在 SEVIR 基准上报告优于多种时空预测和扩散模型 baseline。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文使用重点公开数据集 SEVIR，且明确以 radar echo maps / future radar echo images 为 nowcasting 对象，可用于生成式 SEVIR 模型比较。

**值得关注的原因**

LLM block 是否真能迁移到物理时空序列仍有争议，但这个设计代表了“通用预训练模块 + 气象扩散模型”的尝试。它也适合和 Earthformer、PreDiff、DuoCast、PDRF、FREUD 等 SEVIR 生成式路线比较。

**可能局限**

论文对冻结 LLM block 的物理含义解释较弱，提升可能来自更大容量或额外时序 mixing，而不一定来自语言模型知识。实验主要集中在 SEVIR，跨雷达体制、跨区域和业务实时性仍需验证。

**后续讨论问题**

1. 冻结 LLM Transformer block 与随机初始化 Transformer block 的差异是否经过充分消融？
2. LLMDiff 在强回波阈值 CSI 上是否优于确定性模型，还是主要改善感知质量？
3. 该方法能否迁移到 CIKM / Shanghai，尤其是在输入尺寸和雷达变量不同的情况下？

### 6. DSADNet: A Dual-Source Attention Dynamic Neural Network for Precipitation Nowcasting

- **链接**: https://doi.org/10.3390/su16093696
- **PDF**: https://www.mdpi.com/2071-1050/16/9/3696/pdf
- **来源**: Sustainability / Crossref / MDPI
- **发布日期/版本日期**: 2024-04-28；Crossref indexed 2026-07-18
- **作者**: Jinliang Yao; Junwei Ji; Rongbo Wang; Xiaoxi Huang; Zhiming Kang; Xiaoran Zhuang
- **机构/会议/期刊**: Sustainability, 16(9), 3696
- **DOI / arXiv ID**: 10.3390/su16093696
- **关键词标签**: DSADNet; radar-rainfall fusion; dynamic convolution; attention; ConvLSTM; Jiangsu
- **研究方向**: Multi-source fusion；ConvLSTM / recurrent models；Radar-gauge fusion；Quantitative precipitation nowcasting
- **使用的数据集**: Jiangsu, China real dataset；historical radar echo sequence and rainfall sequence
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI 摘要说明 DSADNet 从 radar maps 和 rainfall maps 中提取有效信息，并在 Jiangsu, China real dataset 上实验；问题定义明确使用 historical radar echo sequence 和 historical rainfall sequence 预测未来降水。

**摘要**

论文针对单纯雷达回波外推再通过 Z-R 关系转换降水可能引入噪声和经验参数误差的问题，提出融合雷达图与降水图的双源模型，直接预测未来降水。作者希望同时利用雷达对云雨演变的敏感性和 rainfall maps 对真实降水的直接刻画能力。

**方法概述**

DSADNet 设计 Fusion-Module 融合雷达回波和降水信息，用动态卷积突出强降水区域，并加入 self-attention memory 捕捉长程时空依赖。解码端以增强的 ConvLSTM 结构输出未来 rainfall sequence，目标是减少单雷达外推和固定 Z-R 转换带来的误差。

**主要贡献**

1. 将 radar maps 与 rainfall maps 作为双源输入，避免完全依赖 Z-R 关系。
2. 在 Fusion-Module 中建模两阶段雷达回波演变和降水信息融合。
3. 用动态卷积和注意力机制增强强回波 / 强降水区域的预测。

**与基于雷达回波的降水临近预报的关系**

相关性中高。雷达回波是核心输入之一，但目标直接是未来降水图，属于 radar-rainfall fusion 型定量降水临近预报。

**值得关注的原因**

很多雷达 echo extrapolation 论文默认预测雷达再转雨强；DSADNet 直接把雨量图纳入模型，适合作为雷达-雨量融合路线的代表。

**可能局限**

数据集为江苏本地真实数据，公开可复现性有限；论文没有命中重点公开数据集，和 CIKM / SEVIR 类视觉基准的可比性较弱。

**后续讨论问题**

**摘要**

该 ICASSP 论文是 Cao 等人在雷达图像降水临近预报中处理强降水类别不平衡的一篇早期会议工作。它关注传统 MSE / MAE 损失对常见弱降水或无降水像素偏向明显，导致强降水预测被平滑或低估的问题。

**方法概述**

论文提出 hybrid weighting loss，将重加权损失与普通回归损失结合，在提升少数强降水区域预测能力的同时，尽量避免整体图像质量退化。该思路后来与互信息重加权、课程式训练等方法形成连续研究线索。

**主要贡献**

1. 较早系统讨论雷达图像 nowcasting 中像素强度分布不平衡对损失函数的影响。
2. 提出混合加权损失，兼顾强降水区域和整体雷达图像重建。
3. 为后续 Mutual Information Boosted Precipitation Nowcasting 等训练策略提供前置基础。

**与基于雷达回波的降水临近预报的关系**

相关性中高。论文直接以 radar images precipitation nowcasting 为对象，但当前可访问页面缺少完整数据集和实验细节，因此更适合作为 loss-design 方向的会议条目。

**值得关注的原因**

强降水低估是雷达临近预报模型的长期问题。该文虽然较早，但能与 MIR、balanced loss、focal loss、torrential loss 等后续策略构成一条清晰的损失函数演化线。

**可能局限**

开放元数据不足，难以核验具体数据集、阈值和 baseline；且 2023 年 Remote Sensing 论文已经扩展了同一研究方向，因此阅读优先级低于期刊扩展版。

3. 在 SEVIR / CIKM 上，loss reweighting 是否能替代生成式模型对强回波细节的改善？
