### 1. FBAP-Net: A Frequency-Band-Aware Amplitude–Phase Network for Precipitation Nowcasting

- **链接**: https://doi.org/10.1109/TGRS.2026.3742897
- **PDF**: 无公开 PDF（IEEE Xplore 订阅访问）
- **来源**: IEEE Xplore / Crossref
- **发布日期/版本日期**: 2026-10-13（Early Access）
- **作者**: Yu Xue; Xinyu Zhang; Mohamed Wahib; Peng Chen
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing；Early Access
- **DOI / arXiv ID**: 10.1109/TGRS.2026.3742897
- **关键词标签**: radar echo; precipitation nowcasting; frequency-domain modeling; amplitude–phase disentanglement; hybrid attention; high-reflectivity echo; CIKM; Shanghai
- **研究方向**: 频域雷达回波临近预报；幅相解耦；多频带注意力；强回波保持
- **使用的数据集**: CIKM 2017；Shanghai 2020 雷达回波数据集
- **重点公开数据集匹配**: **CIKM**；**ShangHai / Shanghai**
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: IEEE Xplore 官方摘要将任务定义为雷达回波临近预报，并明确报告在 CIKM 2017 与 Shanghai 2020 上开展实验，评估一般降水阈值和高反射率回波指标。

**中文摘要总结**

雷达回波临近预报需要同时刻画回波结构运动与强度演变，而现有幅相解耦方法通常对相位谱进行较粗粒度建模，难以适配不同频带的异质结构。FBAP-Net 将相位谱划分为低、中、高频带，并协调相位驱动的结构预测与振幅驱动的强度预测。论文在 CIKM 2017 和 Shanghai 2020 上报告，该方法在一般降水阈值保持竞争力，并在多个高反射率指标上优于对比方法。

**方法概述**

FB-Hybrid PhaseNet 以混合注意力和层次门控融合分别建模低、中、高频相位动态；Spatio-Temporal Amplitude Network 学习时间强度趋势和多尺度空间变化；Amplitude–Phase Mixer 通过低频幅相重组与空间域细化，融合两条预测路径，以同时改善回波位置、边界与强度保持。

**主要贡献**

1. 将相位预测从单一整体频谱扩展为低、中、高频带的异质建模。
2. 设计振幅分支补偿强度演变，并用幅相混合器协调结构和强度预测。
3. 在 CIKM 2017 与 Shanghai 2020 两个重点公开雷达数据集上验证方法。
4. 针对高反射率区域报告明显优势，直接回应强回波衰减与边界模糊问题。

**与基于雷达回波的降水临近预报的关系**

模型直接以历史雷达回波为输入并预测未来回波，核心目标是保持中到强降水区域的空间结构和反射率强度，属于典型雷达回波外推与降水临近预报。

**值得关注的原因**

该工作同时命中 CIKM 与 ShangHai / Shanghai，可直接与大量已有雷达临近预报模型比较；其对不同频带相位结构的显式拆分，也为解决强回波位置漂移和强度衰减提供了清晰的频域建模思路。

**可能局限**

1. 当前可访问的官方摘要未公开数据划分、输入输出时长、完整指标表和计算成本，尚不能判断提升在不同阈值与预报时效上的稳定性。
2. 实验集中于两个中国区域雷达基准，跨气候区、业务雷达拼图和不同质量控制流程的泛化仍待验证。
3. 摘要未说明概率预报或不确定性估计能力，高反射率优势是否伴随空报增加需要查看全文。

**后续讨论问题**

1. 低、中、高频带对位移、形变和生消过程分别贡献多少，频带边界是否可自适应学习？
2. 在 SEVIR 等不同雷达产品上，幅相协调能否保持高阈值 CSI 优势？
3. 如果加入概率分支或集合预测，频域幅相结构如何与不确定性校准共同优化？

### 2. SegTrans-Diff: A Segmented Spatiotemporal Transformer With Echo-Aware Diffusion Refinement for Long-Lead Radar Echo Extrapolation

- **链接**: https://doi.org/10.1109/TGRS.2026.3740026
- **PDF**: 无公开 PDF（IEEE Xplore 订阅访问）
- **来源**: IEEE Xplore / Crossref
- **发布日期/版本日期**: 2026-10-06（正式发表）；Crossref 主记录于 2026-10-17 重新索引，补充材料记录于 2026-10-16 重新索引
- **作者**: Fangli Wu; Huantong Geng; Jinzhong Min; Zhanpeng Shi; Shaoqiang Ma
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing，Volume 64，Article Sequence Number 4113420
- **DOI / arXiv ID**: 10.1109/TGRS.2026.3740026
- **关键词标签**: radar echo extrapolation; long-lead nowcasting; segmented forecasting; Transformer; diffusion refinement; spectral feature refinement; Shanghai
- **研究方向**: Transformer / attention models；Diffusion / generative models；长时效雷达回波外推；确定性—生成式协同
- **使用的数据集**: Shanghai 雷达回波数据集
- **重点公开数据集匹配**: **ShangHai / Shanghai**
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: IEEE Xplore 官方摘要明确说明在 Shanghai radar echo dataset 上开展 0–3 h 雷达回波外推实验，并以 CSI、HSS、邻域强回波技能和 FID 评估结果。

**中文摘要总结**

长时效雷达回波外推同时面临位置偏移、强度衰减和空间模糊。确定性模型通常位置更稳定但输出偏平滑，生成模型能恢复细节却可能产生位置不确定或虚假回波。SegTrans-Diff 将 0–3 h 预报拆为分段确定性预测与回波感知扩散细化两阶段：前者提供可靠的覆盖范围、运动路径和中尺度形态，后者在这些约束下补充对流尺度细节。Shanghai 数据集实验显示，SegTrans 的像素级 CSI、HSS 最优，扩散细化进一步改善强回波邻域技能并降低 FID。

**方法概述**

SegTrans 使用 Segmented Temporal Encoding 把短输入、长输出的不对称问题转化为分段子任务；SegTrans-Block 结合 Window-Wise Global Attention 与 Frequency-Wise Temporal Modeling，学习中尺度组织和长时序演变。扩散分支不从头生成回波，而是以 SegTrans 预报和编码器的历史时空上下文为条件，通过 Echo-Aware Gated Spectral Feature Refinement 在回波覆盖与边界门控下恢复高频细节。

**主要贡献**

1. 用分段预测重构 0–3 h 长时效雷达外推，降低短输入到长输出的建模不对称。
2. 组合窗口级全局注意力与频率维时序建模，兼顾空间组织和长期演变。
3. 将确定性位置先验作为扩散细化条件，避免生成分支脱离历史运动路径。
4. 在 Shanghai 数据集上同时改善像素技能、强回波邻域技能和感知质量；官方摘要报告相对 DiffCast 的 FID 降低 42.8%。

**与基于雷达回波的降水临近预报的关系**

该工作直接预测未来 3 h 雷达回波序列，重点处理强对流回波的位置可靠性和细节真实性，是长时效雷达外推与强降水临近预报的高相关方法。

**值得关注的原因**

它把确定性模型的稳定定位与扩散模型的细节生成进行显式分工，并命中 ShangHai / Shanghai 重点数据集，适合用于研究“长时效位置可靠性—高频纹理—强回波技能”之间的平衡。

**可能局限**

1. 当前公开证据只报告 Shanghai 单一数据集，跨区域和跨雷达产品的泛化尚未验证。
2. 两阶段 Transformer—扩散框架可能带来更高训练与推理成本，官方摘要未给出时延、参数量或采样步数。
3. FID 与邻域技能改善不一定等价于像素级定量降水偏差减小，仍需核查不同阈值和时效的完整指标。

**后续讨论问题**

1. 分段长度与扩散细化强度如何影响 1–3 h 的位置误差和虚假回波？
2. 在 CIKM 或 SEVIR 上，确定性先验是否仍能约束扩散模型而不抑制新生对流？
3. 能否以少步扩散或蒸馏方式降低业务化推理成本，同时保留强回波邻域技能？

### 3. MultiPredNet: Multi-Source Fusion and Multi-Objective Learning for Radar Echo Extrapolation

- **链接**: https://doi.org/10.1109/CCRIS71163.2026.11721786
- **PDF**: 无公开 PDF（IEEE Xplore 订阅访问）
- **来源**: IEEE Xplore / Crossref
- **发布日期/版本日期**: 会议日期 2026-08-28 至 2026-08-30；2026-10-13 加入 IEEE Xplore
- **作者**: Ran Zong; Jianhong Gan; Juntao Li; Anna Xu
- **机构/会议/期刊**: 2026 7th International Conference on Control, Robotics and Intelligent System（CCRIS）；Nanjing, China
- **DOI / arXiv ID**: 10.1109/CCRIS71163.2026.11721786
- **关键词标签**: radar echo extrapolation; multi-source fusion; meteorological variables; topography; ConvLSTM; composite loss; severe weather nowcasting
- **研究方向**: Multi-source fusion；ConvLSTM / recurrent models；多目标损失；强对流临近预报
- **使用的数据集**: 山西省雷达数据集；配套气象变量；静态地形信息
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: IEEE Xplore 官方摘要明确说明实验使用山西省雷达数据集，模型同时编码雷达时间特征、气象变量和静态地形，并预测未来雷达回波；结果按 10、20、30 dBZ 阈值报告 CSI。

**中文摘要总结**

仅依赖雷达历史序列的模型难以充分捕捉复杂环境下对流的新生和演变。MultiPredNet 将雷达时序特征、气象变量与静态地形信息进行多分支编码，再用残差 ConvLSTM 逐步生成未来雷达回波，并以强度重建、结构一致性和降水判别组成复合目标。山西省雷达实验中，论文报告在 10、20、30 dBZ 阈值的 CSI 分别达到 0.702、0.621 和 0.522，优于代表性基线。

**方法概述**

多分支编码器分别提取雷达序列、环境气象量和地形特征并进行融合；残差 ConvLSTM 解码器通过逐步预测和特征传递维持时空连续性；复合损失同时优化像素强度、结构形态与有无降水判别，减少模型只拟合主导弱回波样本的倾向。

**主要贡献**

1. 在雷达回波外推中联合利用动态气象环境与静态地形背景。
2. 以残差 ConvLSTM 解码器增强未来回波的时空连续性和特征传播。
3. 将强度、结构与降水判别目标组合训练，覆盖不同反射率阈值。
4. 通过消融与可视化验证多源融合、残差解码和复合优化各自的作用。

**与基于雷达回波的降水临近预报的关系**

雷达回波既是核心动态输入也是预测目标，其他气象变量和地形用于补充回波生消背景，属于雷达主导的多源融合临近预报。

**值得关注的原因**

该工作强调对流新生不仅取决于历史回波平移，还受环境场和地形约束；对中国复杂地形区域的雷达外推、多源资料选择和多目标损失设计具有直接参考价值。

**可能局限**

1. 当前官方摘要未公开观测时间范围、雷达空间/时间分辨率、具体气象变量和数据划分，复现实验所需信息有限。
2. 数据来自山西单一区域，地形和气候依赖可能限制跨区域泛化。
3. 摘要未说明数据是否公开，也未报告较长时效、极高反射率或概率校准结果。

**后续讨论问题**

1. 环境气象变量与地形分别对对流新生、移动和强度变化贡献多少？
2. 在缺失部分气象变量或雷达质量下降时，多分支融合能否稳定退化？
3. 将复合损失应用到 CIKM、Shanghai 或 SEVIR 时，阈值技能和跨区域迁移性能如何变化？

### 4. Identification of Atmospheric Dynamics of a Tropical Hail Event and Application of Radar Reflectivity Nowcasting Using a UNet-ConvLSTM2D Deep Learning Model

- **链接**: https://journal3.upgris.ac.id/index.php/lpt/article/view/1087
- **PDF**: https://journal3.upgris.ac.id/index.php/lpt/article/download/1087/557
- **来源**: Lontar Physics Today / 官方全文 / Crossref
- **发布日期/版本日期**: 2026-10-19 在线发表；2026-10-18 接收
- **作者**: Muhizzadin Abdul Adzan; Deni Septiadi; Adi Mulsandi; Latifah Nurul Qomariyatuzzamzami
- **机构/会议/期刊**: Lontar Physics Today，Vol. 5 No. 3，pp. 379–396；Sekolah Tinggi Meteorologi Klimatologi dan Geofisika
- **DOI / arXiv ID**: 10.26877/lpt.v5i3.1087
- **关键词标签**: tropical hail; CMAX radar reflectivity; UNet-ConvLSTM2D; Indonesia; convective nowcasting; radar-satellite-reanalysis analysis
- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；强对流与冰雹雷达临近预报
- **使用的数据集**: Soekarno-Hatta Class I Meteorological Station 的 Tangerang C-band 雷达 CMAX 反射率；2023-01 至 2024-10，8 min 间隔，原始 4084 × 4084；Himawari-9 卫星和 ERA5 用于冰雹环境分析
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 官方全文明确以 Soekarno-Hatta 站 CMAX 雷达反射率 PNG 序列训练和验证 UNet-ConvLSTM2D，并用 2024-10-28 Depok 冰雹过程的 CMAX 雷达观测测试未来 8–56 min 反射率预报。

**中文摘要总结**

论文联合雷达、Himawari-9 卫星和 ERA5 分析 2024 年 10 月 28 日 Depok 冰雹过程，并评估 UNet-ConvLSTM2D 对 CMAX 雷达反射率的短时预测。模型以 7 帧历史雷达图预测未来 7 帧，在 8 min 时效能较好捕捉回波位置和形态，但随时效增加，结构相似度和阈值技能下降，并明显低估超过 55 dBZ 的冰雹强回波。CSI 从 8 min 的 0.588 降至 56 min 的 0.284，HSS 从 0.637 降至 0.057。

**方法概述**

研究保留连续 14 帧、每 8 min 一帧的 CMAX 序列，将 4084 × 4084 图像裁剪为 256 × 256 后下采样到 64 × 64，并转换为归一化反射率。训练/验证数据包含 2730 / 683 个序列；模型使用三层 ConvLSTM 编码器、TakeLastFrame 与 ConvLSTM 瓶颈，以及带跳连的 Conv3DTranspose 解码器，从 7 帧输入生成 7 帧未来回波。冰雹个例另以卫星云顶温度和 ERA5 热动力、动力指标解释环境背景。

**主要贡献**

1. 提供印尼热带海洋性环境下的本地 C-band 雷达深度学习 nowcasting 实验。
2. 将雷达回波预测与卫星、ERA5 的冰雹环境诊断结合，连接数据驱动预报与物理过程解释。
3. 对 5、10、20、30、40 dBZ 多阈值及 8–56 min 多时效进行定量评估。
4. 直接揭示模型对局地强回波核心的系统性低估和随时效退化问题。

**与基于雷达回波的降水临近预报的关系**

模型输入与预测目标均为 CMAX 雷达反射率序列，任务是对冰雹强对流过程的未来 8–56 min 回波演变进行 nowcasting，与强降水和灾害性对流预警高度相关。

**值得关注的原因**

热带印尼业务雷达的公开深度学习临近预报案例相对少见；该文提供了真实 C-band 雷达个例、清晰的序列构造和多阈值退化证据，可用于研究区域迁移、强回波样本不平衡和低成本基线。

**可能局限**

1. 独立测试集中只突出一个冰雹过程，难以评估跨事件、跨季节与跨雷达站泛化。
2. 下采样到 64 × 64 可能损失局地强回波核心和边界细节。
3. 使用 MSE 训练会偏向主导的低到中等反射率，40 dBZ 阈值技能在长时效接近零。
4. 研究主要验证确定性单次预报，尚未量化集合不确定性或校准性。

**后续讨论问题**

1. 使用强回波重加权、分位数损失或概率生成模型，能否减轻 >40 dBZ 核心低估？
2. 保留更高空间分辨率或加入多尺度裁剪后，冰雹单体结构与移动路径能改善多少？
3. 在更多印尼冰雹和强降水事件、不同 C-band 雷达站上，模型的跨区域迁移能力如何？

## 本轮结论

本轮去重后新增 4 篇合格论文。FBAP-Net 与 SegTrans-Diff 分别从频域幅相解耦、确定性—扩散协同角度处理强回波保持，并命中 CIKM 和/或 ShangHai / Shanghai；MultiPredNet 关注雷达、环境变量和地形的多源融合；印尼 UNet-ConvLSTM2D 论文提供了热带冰雹 CMAX 雷达个例及明确的长时效退化证据。未发现新的 SEVIR 或 MetNet 合格条目。
