### 1. Nowcasting of Extreme Precipitation Using Deep Generative Models

- **链接**: https://doi.org/10.1109/ICASSP49357.2023.10094988
- **开放页面 / 代码**: https://research.tudelft.nl/en/publications/nowcasting-of-extreme-precipitation-using-deep-generative-models/；https://github.com/bbbbihr/Nowcasting-of-extreme-precipitation
- **来源**: Crossref / IEEE ICASSP / TU Delft Research Portal / GitHub
- **发布日期/版本日期**: Published 2023-06-04；Crossref indexed 2026-08-28 UTC
- **作者**: Haoran Bi; Maksym Kyryliuk; Zhiyi Wang; Cristian Meo; Yanbo Wang; Ruben Imhoff; Remko Uijlenhoet; Justin Dauwels
- **机构/会议/期刊**: ICASSP 2023 - 2023 IEEE International Conference on Acoustics, Speech and Signal Processing
- **DOI / arXiv ID**: 10.1109/ICASSP49357.2023.10094988
- **关键词标签**: VQGAN; Transformer; Extreme Value Loss; PySTEPS; generative nowcasting; radar data
- **研究方向**: GAN / generative models；Transformer / attention models；Probabilistic nowcasting；Extreme precipitation
- **使用的数据集**: 作者开放代码说明需要下载 precipitation data，并将 radar data 转换为 latent-space token sequences；开放页面未明确列出数据集正式名称
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 官方 GitHub README 明确把训练好的 VQGAN 用于将 radar data 转换为 latent-space token sequences，并提供 nowcasting 与 extreme precipitation detection 测试脚本；TU Delft 页面说明任务是 precipitation nowcasting，并以 PySTEPS 作为传统 nowcasting 对照。

**摘要**

论文把极端降水临近预报建模为生成式时空序列预测问题。作者提出 VQGAN + autoregressive Transformer 的两阶段结构，先把高分辨率降水 / 雷达场编码为离散 latent token，再用 Transformer 预测未来 token 序列。为强化极端降水表现，模型加入 Extreme Value Loss，目标是在保持常规降水预测能力的同时减少极端事件被平均化的问题。

**方法概述**

方法先训练 VQGAN 学习雷达 / 降水场的离散表示，再用自回归 Transformer 在 latent space 中建模序列演变。EVL 被加入 Transformer 训练，以提高尾部强降水区域的权重。实验将深度生成模型与 PySTEPS 等传统 nowcasting 方法比较，重点观察普通阈值与极端阈值上的表现差异。

**主要贡献**

1. 将 VQGAN + Transformer 引入极端降水临近预报。
2. 用 Extreme Value Loss 显式处理尾部强降水样本。
3. 以 PySTEPS 作为传统雷达外推参照，便于连接机器学习和业务 nowcasting 方法。
4. 提供开放代码，可追踪 radar data latent token 化和极端事件筛选流程。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务是观测驱动的短时降水预报，官方代码明确出现 radar data 序列转换和 nowcasting 测试流程，适合作为生成式极端降水 nowcasting 路线的早期记录。

**值得关注的原因**

该记录此前未进入本地索引，且 Crossref 在本轮窗口重新索引。它与后续 NowcastingGPT-EVL、PID-GAN 等 TU Delft / KNMI 系列极端降水生成式工作有关，可用于整理极端事件损失函数和 latent generative nowcasting 的脉络。

**可能局限**

开放摘要没有清楚列出数据集正式名称、空间分辨率和完整划分协议；如果用于正式综述，需要后续获取 IEEE 正文或作者 PDF 核验数据来源。VQGAN + Transformer 的训练和推理成本也可能高于 ConvRNN / PySTEPS baseline。

### 2. Enhanced rainfall nowcasting using deep learning models incorporating polarimetric radar data

- **链接**: https://doi.org/10.1007/s11069-025-07587-4
- **开放页面 / 软件**: https://link.springer.com/article/10.1007/s11069-025-07587-4；https://doi.org/10.5281/zenodo.11365829
- **来源**: Crossref / Springer Nature Link / Natural Hazards
- **发布日期/版本日期**: Published online 2025-08-18；issue date 2025-10；Crossref indexed 2026-08-28 UTC
- **作者**: Qiming Cheng; Jiayue Zhu; Yihong Su; Ye Rao; Fei Liu; Shaochun Yuan; Yang He; Zhen Liu; Yili Zheng; Gang Zhu; Yao Chen
- **机构/会议/期刊**: Natural Hazards, 121, 19761-19780
- **DOI / arXiv ID**: 10.1007/s11069-025-07587-4
- **关键词标签**: ConvNeXt-Unet-X2; Video Swin-Unet; polarimetric radar; ZH; ZDR; KDP; extreme rainfall
- **研究方向**: CNN encoder-decoder；Radar echo extrapolation；Dual-polarization radar；Extreme rainfall nowcasting
- **使用的数据集**: Pan et al. (2021) 数据；NJU-CPOL（Nanjing University C-band polarimetric radar）；ZH、ZDR、KDP 多变量极化雷达输入
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Springer 摘要明确称 deep learning radar echo extrapolation 是 rainfall nowcasting 的主要方法之一，并说明模型融合 polarimetric radar variables；数据可用性和缩写表指向 Pan et al. (2021) 与 NJU-CPOL。

**摘要**

论文关注传统单极化雷达输入在极端降水中的状态刻画不足问题。作者提出 ConvNeXt-Unet-X2，并系统比较只使用 ZH 与融合 ZH、ZDR、KDP 等极化变量的效果。常规降水下双极化增益有限，但在极端降水样本中，多变量融合显著提高 CSI 并降低 FAR，说明输入数据质量和极化信息对深度 nowcasting 模型很关键。

**方法概述**

模型在 U-Net 形态中引入 ConvNeXt block 和 batch normalization，构建 ConvNeXt-Unet-X2 作为强 baseline。输入侧增加极化雷达特征提取模块，比较单变量 ZH 和多变量 ZH + ZDR + KDP 配置。实验用 SSIM、CSI、FAR 等指标评估不同降水强度条件下的雷达回波外推质量。

**主要贡献**

1. 提出面向 polarimetric radar echo extrapolation 的 ConvNeXt-Unet-X2。
2. 量化 ZH、ZDR、KDP 融合在常规降水和极端降水下的不同收益。
3. 强调输入雷达变量对深度学习 nowcasting 的影响，而不只关注网络结构。
4. 提供软件 DOI，便于后续复核实现细节。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文标题、摘要、数据可用性和变量定义都直接指向极化天气雷达回波外推，实验对象是用历史雷达变量预测后续降水 / 回波状态。

**值得关注的原因**

近期 radar echo extrapolation 论文多侧重 Transformer、diffusion 或 GAN，该文从输入变量质量切入，说明双极化变量对极端降水更有价值。它可以和 NJU-CPOL / NJU_CPOL_update2308 系列论文共同整理为“极化雷达变量融合”方向。

**可能局限**

Springer 正文为订阅预览，本轮无法完整核验训练划分、样本时段和全部消融细节；公开摘要显示常规降水下多变量收益很小，需要判断复杂输入是否值得业务部署成本。

**后续讨论问题**

- **来源**: Crossref / Scientific Reports / Nature

- **DOI / arXiv ID**: 10.1038/s41598-024-68951-1
- **关键词标签**: ResNet-Attention-BiLSTM; CBAM; NJU-CPOL; dual-polarization radar; ZH; ZDR; KDP
- **研究方向**: ConvLSTM / recurrent models；Attention models；Dual-polarization radar；Strong convective precipitation forecasting
- **使用的数据集**: NJU-CPOL 双偏振天气雷达数据，2014-2019 年 268 次降水事件；多高度 ZH、ZDR、KDP 雷达变量；配套 precipitation grid data
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Nature 正文数据可用性声明列出 NJU-CPOL dual-polarization radar data and precipitation grid data；方法部分说明输入包含 1 km、3 km、7 km 高度的 ZH、ZDR、KDP，并用前 1 小时雷达序列预测后 1 小时 ZH。

**摘要**

论文提出 ResNet-Attention-BiLSTM，用于强对流降水短时预报。模型利用双偏振雷达在不同高度上的 ZH、ZDR、KDP 变量，先通过 ResNet 提取空间特征，再使用注意力机制突出关键回波区域，最后用 BiLSTM 建模时序变化。实验使用 NJU-CPOL 2014-2019 年降水事件，输出未来 1 小时的反射率预测。

**方法概述**

网络包含三类模块：ResNet 用于多高度、多变量雷达场的空间编码；CBAM / attention 机制用于增强关键强回波和空间区域；BiLSTM 用于捕捉前后时间步之间的序列依赖。任务设置为输入过去 1 小时 10 帧雷达观测，预测未来 1 小时 10 帧 ZH 场，并用 CSI、POD、FAR 等指标评估不同 lead time。

**主要贡献**

1. 将多高度双偏振雷达变量用于强对流降水 nowcasting。
2. 组合 ResNet、attention 和 BiLSTM，兼顾空间特征和时序推理。
3. 在 NJU-CPOL 2014-2019 数据上验证，数据来源清楚。
4. 输出未来 ZH 序列，任务形式贴近 radar echo extrapolation。

**与基于雷达回波的降水临近预报的关系**

相关性高。实验数据、输入变量和输出目标都来自双偏振天气雷达，预测窗口为 1 小时，符合雷达驱动短临预报要求。

**值得关注的原因**

该文提供了多高度极化雷达变量用于强对流预报的完整开放页面，可作为 NJU-CPOL 方向中 attention + recurrent 架构的代表，也适合和 ConvNeXt-Unet-X2 的极化变量融合结论对照。

**可能局限**

BiLSTM 结构对二维雷达场的长距离平移建模能力可能有限；论文重点在强对流个例和 NJU-CPOL 区域数据，跨区域泛化仍需额外验证；未来只预测 ZH，没有直接输出多变量联合未来场。

**后续讨论问题**

1. 多高度 ZH/ZDR/KDP 中哪些高度层对 1 小时预报最关键？
2. Attention 模块是否主要改善强回波定位，还是降低虚警？
3. 该模型能否迁移到 NJU_CPOL_update2308 或其他公开双偏振数据？

### 4. Nowcasting Heavy Rainfall With Convolutional Long Short-Term Memory Networks: A Pixelwise Modeling Approach

- **链接**: https://doi.org/10.1109/JSTARS.2024.3383397
- **开放页面**: https://research.knu.ac.kr/en/publications/nowcasting-heavy-rainfall-with-convolutional-long-short-term-memo/
- **来源**: Crossref / IEEE J-STARS / Kyungpook National University research portal / ResearchGate full-text snippets
- **发布日期/版本日期**: Published 2024；Crossref indexed 2026-08-28 UTC
- **作者**: Yi Victor Wang; Seung Hee Kim; Geunsu Lyu; Choeng-Lyong Lee; Soorok Ryu; Gyuwon Lee; Ki-Hong Min; Menas C. Kafatos
- **机构/会议/期刊**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing, 17, 8424-8433
- **DOI / arXiv ID**: 10.1109/JSTARS.2024.3383397
- **关键词标签**: ConvLSTM; CLSTM; pixelwise modeling; stratified sampling; dual-polarimetric weather radar; heavy rainfall
- **研究方向**: ConvLSTM / recurrent models；Radar reflectivity prediction；Extreme / heavy rainfall nowcasting
- **使用的数据集**: 韩国半岛暖季 mesoscale convective systems 事件；开放摘要未列出数据集正式名称，关键词和全文片段指向 dual-polarimetric weather radar / radar images
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: KNU 页面关键词包含 dual-polarimetric weather radar 与 rainfall nowcasting；ResearchGate/IEEE 全文片段说明输入为过去 radar images，输出为 predicted radar reflectivity image。

**摘要**

论文把强降水临近预报视为像素级雷达反射率预测问题，使用 ConvLSTM 处理中尺度对流系统的时空演变。作者关注强降水样本稀缺导致的类别不平衡，采用 stratified sampling 改善模型对强回波像素的学习。实验覆盖 10-60 min lead time，并报告像素级指标，以评估模型在暖季韩国半岛强降水事件中的可用性。

**方法概述**

方法以 ConvLSTM / CLSTM 为核心，将连续雷达图像输入到循环卷积网络中，输出未来反射率图像。与只做整体图像相似度评价不同，论文强调 pixelwise modeling 和采样策略，让训练过程更关注强降水像素。评估关注短 lead time 到 1 小时范围内的预测质量。

**主要贡献**

1. 将 heavy rainfall nowcasting 明确落到像素级雷达反射率预测。
2. 用 stratified sampling 缓解强降水像素稀缺问题。
3. 在韩国半岛中尺度对流系统上验证 10-60 min 预报。
4. 为 ConvLSTM 在强降水场景下的训练策略提供可比较记录。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务是用雷达图像预测未来雷达反射率图像，且面向 10-60 min heavy rainfall nowcasting。

**值得关注的原因**

很多 ConvLSTM 工作容易在强降水阈值下表现退化；该文把采样策略作为核心变量，和 weighted loss、EVL、focal-style loss 等方向可以放在同一个“极端像素重加权”主题中比较。

**可能局限**

开放页面没有完整列出雷达数据源、空间分辨率和训练划分；ResearchGate/IEEE 片段可证明 radar reflectivity 输入输出，但正式复盘仍应获取 PDF 复核协议。ConvLSTM 结构本身可能难以处理较长 lead time 的非线性生消。

- **DOI / arXiv ID**: 10.1109/TGRS.2025.3592853
- **关键词标签**: weighted loss; ConvLSTM; extreme rainfall nowcasting; radar rainfall data; spatial class imbalance
- **研究方向**: ConvLSTM / recurrent models；Loss design；Extreme rainfall nowcasting；Radar rainfall maps

- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ADS 元数据关键词包含 radar rainfall data；IEEE PDF 片段说明研究使用 538 个 AWS 观测补充 / 校正 radar rainfall data，并在 ConvLSTM-based nowcasting model 中测试 weighted loss。

**摘要**

论文研究 weighted loss functions 在极端降雨临近预报中的作用。作者指出极端降雨像素在空间和时间上都稀缺，普通均方误差类损失会让模型偏向弱降水或无雨区域。论文以 ConvLSTM-based nowcasting model 为实验框架，对不同权重函数和空间降雨类别进行比较，评估它们对极端事件命中和虚警的影响。

**方法概述**

方法不是提出全新网络，而是把研究重点放在损失函数设计。作者使用 ConvLSTM nowcasting 模型，对雷达降雨数据中的不同降雨强度类别施加权重，观察模型在极端降水区域的预测变化。AWS 观测用于改进雷达降雨数据质量，降低输入数据异常值对训练和评估的干扰。

**主要贡献**

1. 系统分析 weighted loss 在极端降雨 nowcasting 中的实际作用。
2. 将空间类别不平衡问题和 ConvLSTM 训练目标联系起来。
3. 使用 radar rainfall data，并结合 AWS 对雷达降雨异常值做补充或校正。
4. 为极端降水样本重加权提供可复用的评估思路。

**与基于雷达回波的降水临近预报的关系**

相关性中高。论文预测对象是 radar rainfall data 而非原始反射率图，但数据源和任务均为短时降雨 nowcasting，符合雷达派生降水图的收录条件。

**值得关注的原因**

它和本轮的 ConvLSTM pixelwise modeling、VQGAN + EVL 都围绕“极端降水稀缺导致模型低估”的问题，可以放在同一条方法线索中：采样、损失加权、极值损失和生成式判别。

**可能局限**

IEEE 正文访问受限，本轮只能从 Crossref、ADS、作者实验室页面和 IEEE PDF 片段确认雷达数据与方法；数据集正式名称、区域、分辨率和完整权重函数公式仍需后续 PDF 复核。基于权重的优化可能提升高阈值召回，但同时增加虚警风险。

**摘要**

论文提出 RSFM，用多源时空深度学习融合方法改进台湾台风降雨短时预报。模型同时利用历史降雨累积、雷达反射率、红外卫星图像和地理空间信息，在 2013-2023 年 36 个台风事件上训练和评估。结果显示全多源配置在 1-6 h 预报中降低 RMSE，并改善南部和东部复杂地形区域的 ETS 与 Bias Ratio。

**方法概述**

RSFM 采用 semantic segmentation 与 recurrent encoding 结合的方式，学习台风降雨在空间结构和时间上的演变。实验设置比较不同输入组合，以判断雷达、红外和地理信息对 1-6 h rainfall forecast 的贡献。评价指标包含 RMSE、Bias Ratio、ETS，并与 radar QPE、PERSIANN-CCS 和 ConvLSTM 类方法对比。

**主要贡献**

1. 将 radar reflectivity、IR satellite 和 geospatial data 联合用于台风降雨短时预报。
2. 在 36 个台湾台风事件上验证 1-6 h 多 lead time 预测。
3. 明确比较传统 radar QPE、卫星降水估计和 ConvLSTM baseline。
4. 强调复杂地形区域的区域性准确率改善。

**与基于雷达回波的降水临近预报的关系**

相关性中等偏高。论文不是纯 radar echo extrapolation，而是包含 radar reflectivity 的 radar-satellite-geospatial fusion 短时降雨预测，符合“包含雷达的融合数据集”收录条件。

**值得关注的原因**

该文提供了台风场景下雷达和红外卫星融合的 1-6 h 预报案例，可补充以对流雷达回波外推为主的 benchmark 视角，尤其适合讨论复杂地形和台风降雨结构。

**可能局限**

任务标题使用 rainfall estimation，和严格的 radar echo extrapolation 有差异；雷达只是多源输入之一，难以单独归因雷达变量的贡献；数据集区域性很强，跨气候区泛化仍需验证。

**后续讨论问题**

1. RSFM 的 1-6 h 设定是否应归入 nowcasting，还是更适合短时降雨预报？
2. 雷达反射率与 IR 卫星在不同 lead time 的贡献是否随时间衰减？
3. 台风场景下的多源融合结论能否迁移到普通强对流降水？
