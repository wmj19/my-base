### 1. LMcast: A pretrained language model guided long-term memory transformer for precipitation nowcasting

- **链接**: https://www.sciencedirect.com/science/article/pii/S0893608025010482
- **PDF**: ScienceDirect 页面提供机构访问/购买入口；公开 PDF 未在本次扫描中确认
- **来源**: Neural Networks / ScienceDirect；2026-06-06 检索中作为近 7 天新近抓取结果发现
- **发布日期/版本日期**: 2025-10；ScienceDirect / 数据库元数据本次新近索引
- **作者**: Feifan Gao, Chuyao Luo, Guangbo Deng, Xutao Li, Baoquan Zhang, Demin Yu, Yunming Ye
- **机构/会议/期刊**: Neural Networks, 195, 108168
- **DOI / arXiv ID**: 10.1016/j.neunet.2025.108168
- **关键词标签**: LMcast; pretrained language model; long-term memory transformer; VQ-VAE; radar datasets; SEVIR; Shanghai Radar; CIKM
- **研究方向**: Transformer / attention models；Memory network；Radar echo extrapolation；Precipitation nowcasting
- **使用的数据集**: SEVIR, MeteoNet, Shanghai Radar, CIKM
- **重点公开数据集匹配**: CIKM; ShangHai; SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ScienceDirect 摘要和实验设置说明该文在四个公开 radar datasets 上评测，包括 SEVIR、MeteoNet、Shanghai Radar 和 CIKM；其中 MeteoNet 不是本项目优先标签中的 MetNet。

**摘要**

论文面向长时效降水临近预报中有效信息随 lead time 增长而衰减的问题，提出 LMcast。核心思想是借助预训练语言模型的检索/生成能力，从历史降雨过程码本中召回相似未来演变作为长期先验，再与当前观测提取的短期记忆融合，生成未来降水序列。

**方法概述**

LMcast 包含 PLM-Guided VQ-VAE 和 Transformer 预测网络。前者将历史降雨过程编码到离散码本，并用预训练语言模型辅助召回相似历史未来；后者把召回的长期记忆与当前输入形成的短期记忆结合，缓解多步预测中的模糊和趋势漂移。

**主要贡献**

1. 将预训练语言模型引入降水 nowcasting 的历史记忆召回流程。
2. 设计长期记忆和短期记忆融合结构，用于多步雷达序列预测。
3. 在 SEVIR、MeteoNet、Shanghai Radar、CIKM 四个公开雷达数据集上进行系统实验。

**与基于雷达回波的降水临近预报的关系**

高度相关。该文直接以雷达图像序列为预测对象，且覆盖本项目重点跟踪的 CIKM、ShangHai/Shanghai 和 SEVIR 数据集，可作为公开基准方法对比的重要条目。

**值得关注的原因**

LMcast 把大模型/语言模型能力转化为历史过程检索先验，而不是直接用 LLM 生成天气图像。这个方向适合与 McCast、PredRNN、EarthFormer、FREUD、FlowCast 等长期记忆、潜空间修正和生成式 nowcasting 方法比较。

**可能局限**

方法依赖历史过程码本和相似样本召回，跨区域、跨季节或极端罕见降水过程中的记忆覆盖度可能成为瓶颈。MeteoNet 虽然是公开雷达数据集，但不应与 Google MetNet 模型/数据混写。

**后续讨论问题**

1. PLM 召回到的历史过程是否能解释为物理相似天气型，还是主要是特征空间近邻？
2. 在 SEVIR 高阈值强回波上，LMcast 的长期记忆是否比生成式模型更稳定？
3. 上海/CIKM 数据集上是否存在与训练码本重复或近似的样本泄漏风险？

### 2. Improving precipitation nowcasting via multiphysical parameter fusion in radar echo extrapolation

- **PDF**: ScienceDirect 页面提供机构访问/购买入口

- **作者**: Yuankang Ye, Feng Gao, Shaoqing Zhang, Chang Liu
- **机构/会议/期刊**: Journal of Hydrology, 668, 134947
- **DOI / arXiv ID**: 10.1016/j.jhydrol.2026.134947
- **关键词标签**: PIEE; multimodal radar echo extrapolation; polarimetric radar; physics-informed; multi-source fusion
- **研究方向**: Multi-source fusion；Physics-informed / physical constraints；Radar echo extrapolation；Transformer / attention models
- **使用的数据集**: real multimodal radar echo dataset；雷达反射率和四类偏振/物理参数
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ScienceDirect 摘要说明 PIEE 将 radar echo reflectivity 与四个额外 radar-derived physical parameters 集成到深度学习框架；实验使用 real multimodal radar echo dataset。

**摘要**

论文认为传统雷达回波外推常把任务简化为单一反射率序列预测，难以刻画水凝物相态和动力演变。作者提出 Physics-Informed Multimodal Echo Extrapolation neural network (PIEE)，把雷达反射率与多种偏振/物理参数共同输入，用多模态信息增强降水临近预报。

**方法概述**

PIEE 使用编码解码结构，包含双分支多模态编码器、Inter-Intra 特征抽取与融合模块，以及门控时空自注意力模块。模型既处理单一反射率外推，也处理多雷达参数融合，并通过消融分析评估不同物理参数对外推精度的贡献。

**主要贡献**

1. 提出面向雷达回波外推的 physics-informed multimodal 融合框架。
2. 在不依赖插值拼接的前提下引入多个雷达偏振物理变量。
3. 通过消融和解释性分析讨论各雷达物理参数对预测稳定性和空间连续性的作用。

**与基于雷达回波的降水临近预报的关系**

高度相关。该文直接预测未来雷达回波，并从 reflectivity-only 扩展到多偏振参数融合，是 radar-only 与 radar-multimodal nowcasting 之间的重要连接。

**值得关注的原因**

很多深度 nowcasting 模型只使用单通道反射率或 VIL，PIEE 强调雷达系统内部多物理变量的协同信息，适合与 SwinKAN、MMF-RNN、PDDN、雷达-NWP 融合模型比较。

**可能局限**

可访问摘要未披露完整数据区域、数据开放状态和跨区域实验。多偏振参数在不同雷达网中的可用性、标定一致性和缺测处理会影响业务迁移。

**后续讨论问题**

1. 不同偏振参数对高强度回波保持的贡献是否随天气型变化？
2. PIEE 的多模态融合能否迁移到公开单通道雷达基准，或必须依赖多偏振业务产品？
3. 物理参数融合相比加入 NWP 风场/湿度场的收益和成本如何比较？

**摘要**

该 workshop paper 介绍 Microsoft Weather 的业务降水临近预报模型。模型以连续天气雷达拼图作为输入，用 encoder-forecaster ConvLSTM 预测未来雷达反射率，并融合 HRRR 数值模式信息以扩展有效预报时效。

1. 报告了一个已服务 Microsoft Weather 产品的 ConvLSTM 雷达 nowcasting 系统。

**与基于雷达回波的降水临近预报的关系**

高度相关。该文直接从 radar mosaics 预测 future radar reflectivity，是少数公开描述大厂业务雷达 nowcasting 系统的文献。

**值得关注的原因**

它为“研究模型如何进入业务产品”提供案例，可与 DGMR、NowcastNet、PDDN、RainNet 和传统 optical flow 系统比较。特别值得关注其大感受野设计和 NWP 条件化的工程权衡。

**可能局限**

数据和系统细节多为业务内部资产，公开复现受限。模型是确定性预测，概率不确定性、极端事件可靠度和跨区域标定细节需要进一步资料确认。

### 4. Improving precipitation nowcasting using a three-dimensional convolutional neural network model from Multi Parameter Phased Array Weather Radar observations

- **PDF**: ScienceDirect 页面提供 Open Manuscript / 机构访问入口
- **来源**: Atmospheric Research / ScienceDirect；2026-06-06 检索中作为近 7 天新近抓取结果发现

- **机构/会议/期刊**: Atmospheric Research, 262, 105774
- **DOI / arXiv ID**: 10.1016/j.atmosres.2021.105774
- **关键词标签**: 3D CNN; MP-PAWR; phased array weather radar; radar reflectivity; convective storm nowcasting
- **研究方向**: CNN encoder-decoder；Convective storm nowcasting；Radar reflectivity；Three-dimensional radar nowcasting
- **使用的数据集**: Multi-Parameter Phased Array Weather Radar (MP-PAWR) 3-D observations over Tokyo, Japan, 2019-08-01 storm case
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ScienceDirect 摘要说明 3DCNN 使用东京 MP-PAWR 的 unique 3-D observations 进行短生命期局地对流风暴 nowcast，并以 10 dBZ 和 37.5 dBZ radar reflectivity thresholds 评估。

**摘要**

论文提出 3DCNN 模型，利用多参数相控阵天气雷达的三维体扫观测，对东京一次短生命期局地对流风暴进行 10 分钟以内的降水 nowcast。作者将 3DCNN 与三维平流 nowcast 模型 3DNOW 和 persistence 进行比较。

**方法概述**

模型直接处理 MP-PAWR 提供的高时空分辨率三维雷达体数据，以 3D CNN 学习雷达反射率的空间垂直结构和短时演变。评估分为总降水区域和对流降水区域，使用不同反射率阈值衡量命中能力。

**主要贡献**

1. 将三维 CNN 用于高分辨率三维相控阵天气雷达 nowcasting。
2. 以 MP-PAWR 观测验证深度模型对短时局地对流过程的预测能力。
3. 与 3DNOW 对照，展示数据驱动和三维平流模型在不同反射率区域的优势差异。

**与基于雷达回波的降水临近预报的关系**

高度相关。该文不只使用二维雷达拼图，而是使用三维天气雷达观测，对研究三维雷达回波外推和快速对流发展很有参考价值。

**值得关注的原因**

多数公开 nowcasting 基准仍是二维 reflectivity/VIL 序列。MP-PAWR 体扫数据为深度模型理解垂直结构、增长/消散和强对流核心提供了更丰富输入。

**可能局限**

实验聚焦单个东京局地风暴个例，样本覆盖和泛化能力有限。10 分钟 lead time 较短，且 3DCNN 在较长 lead time 对强对流区域不一定优于 3DNOW。

**后续讨论问题**

1. 三维雷达体扫是否能显著改善 30-60 分钟强对流 nowcasting，还是只在极短时效有效？
2. 3D CNN 与 3D ConvLSTM、Transformer 或物理平流约束结合是否更稳健？
3. 相控阵雷达的高频体扫数据如何转换为可复用公开基准？

### 5. Improving radar echo extrapolation models using autoencoder-based perceptual losses

- **链接**: https://www.sciencedirect.com/science/article/pii/S187705092301308X
- **PDF**: ScienceDirect 开放获取页面提供 View PDF 入口
- **来源**: Procedia Computer Science / ScienceDirect；2026-06-06 检索中作为近 7 天新近抓取结果发现
- **发布日期/版本日期**: 2023；Volume 225, Pages 1611-1620；本次扫描中新近抓取
- **作者**: Alexandra-Ioana Albu
- **机构/会议/期刊**: Procedia Computer Science, KES 2023
- **DOI / arXiv ID**: 10.1016/j.procs.2023.10.150
- **关键词标签**: radar echo extrapolation; perceptual loss; autoencoder; MET Norway; nowcasting
- **研究方向**: CNN encoder-decoder；Radar echo extrapolation；Loss function design；Operational nowcasting systems
- **使用的数据集**: MET Norway radar reflectivity data
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ScienceDirect 摘要说明实验使用 MET Norway 收集的 radar reflectivity data，目标是改进 predicted radar maps 的视觉质量。

**摘要**

论文针对深度雷达回波外推中常见的预测模糊问题，提出基于自编码器特征抽取的 perceptual loss。相比借用 ImageNet/VGG 特征，该方法试图用与雷达图像更贴近的自编码器表示约束预测图像质量。

**方法概述**

方法训练或使用自编码器作为特征提取器，在特征空间比较预测雷达图与真实雷达图，从而构造 perceptual loss。实验比较了传统损失和 VGG 式感知损失，报告在 MET Norway radar reflectivity 数据上能提升图像锐度和部分误差指标。

**主要贡献**

1. 将自编码器特征空间用于雷达回波外推的感知损失设计。
2. 避免依赖自然图像预训练特征，降低额外数据和标注需求。
3. 在 MET Norway 雷达反射率数据上验证对模糊预测的改善。

**与基于雷达回波的降水临近预报的关系**

高度相关。该文的主要对象是未来雷达图预测质量，尤其是模糊问题，适合放入“损失函数与感知质量”方向。

**值得关注的原因**

扩散、GAN、频域损失和感知损失都在尝试解决雷达 nowcasting 的高频细节缺失。该文提供了一个计算成本更低、无需外部自然图像模型的替代思路。

**可能局限**

摘要级信息显示作者和数据集规模较有限，是否能改善高阈值 CSI、极端降水命中率或业务告警价值，需要查看完整实验。感知质量提升也可能与物理一致性存在权衡。

**后续讨论问题**

1. 自编码器感知损失是否真正改善强回波结构，还是主要改善视觉锐度？
2. 该损失能否直接叠加到 RainNet、MS-RadarFormer 或 ConvLSTM 类模型？
3. 与频域损失、SSIM/MS-SSIM 或 adversarial loss 相比，它的稳定性如何？

### 6. Physics-Guided Deep Learning for Radar Rainfall Nowcasting in Flash-Flood Early Warning: Lead-Time Skill and an Illustrative Utility Proxy

- **链接**: https://www.sciencedirect.com/science/article/pii/S266659212600003X
- **PDF**: ScienceDirect 开放获取页面提供 View PDF 入口
- **来源**: Natural Hazards Research / ScienceDirect；2026-06-06 检索中作为近 7 天新近抓取结果发现
- **发布日期/版本日期**: 2026-01-27 online；本次扫描中新近抓取/发现
- **作者**: Katsiaryna Bahamazava, Stanley Reznik
- **机构/会议/期刊**: Natural Hazards Research, in press
- **DOI / arXiv ID**: 10.1016/j.nhres.2026.01.003
- **关键词标签**: physics-guided deep learning; radar rainfall nowcasting; U-Net; flash flood early warning; KNMI radar composites
- **研究方向**: Physics-informed / physical constraints；CNN encoder-decoder；Radar-derived precipitation；Operational early warning
- **使用的数据集**: 5 min KNMI radar composites over Amsterdam, 2024-10 to 2025-01
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ScienceDirect 摘要说明研究对象是 Amsterdam 的 5 min KNMI radar composites，构造 60 min 输入到 60 min 输出的 radar rainfall nowcasting 序列。

**摘要**

论文面向城市内涝/暴洪早期预警，研究一种轻量 physics-guided U-Net。作者在标准 U-Net 训练目标中加入针对雨区空间梯度的 masked smoothness 正则项，以鼓励降水场空间连续并减少孤立伪回波。

**方法概述**

模型输入 12 帧、输出 12 帧，覆盖 60 分钟历史到 60 分钟未来。基线为数据驱动 U-Net，物理引导版本在 log(1+R) 训练框架下增加线性雨强空间平滑正则，并在物理单位 mm/h 上评估 RMSE、MAE、CSI、FAR 和 lead-time value proxy。

**主要贡献**

1. 提出低开销的 radar rainfall nowcasting 物理正则化训练目标。
2. 在 Amsterdam KNMI 雷达复合图上评估 5-60 分钟 lead time。
3. 将预报技能曲线与简化效用代理指标连接到暴洪预警价值。

**与基于雷达回波的降水临近预报的关系**

高度相关。输入和输出均为 radar rainfall composite 序列，研究问题直接服务短时降水 nowcasting 和暴洪预警。

**值得关注的原因**

该文不改变推理架构，只在训练目标中加入物理先验，适合与复杂物理耦合、扩散生成和雷达-NWP 融合路线比较。它也提醒 nowcasting 评价不应只看平均误差，还应关注有行动价值的 lead time。

**可能局限**

实验限制在 Amsterdam 单个城市 tile 和冷季样本，作者也指出强对流锐利核心可能被平滑正则过度抑制。效用代理指标是简化构造，不等同于真实灾损模型。

**后续讨论问题**

1. masked smoothness 是否会削弱夏季强对流核心和快速增长回波？
2. 该正则项能否与强降水加权损失或概率 nowcasting 同时使用？
3. 用 CSI 构造预警效用代理时，应如何加入暴露、脆弱性和交通/排水系统信息？

**摘要**

论文将 Kolmogorov-Arnold Networks 引入雷达回波外推，目标是缓解深度 nowcasting 中随 lead time 增长的图像模糊和物理信息退化。作者提出 ConvKAN 和 KAN&evOnet，将 KAN 与 U-Net/演化网络结合，用于更高质量的雷达回波预测。

**方法概述**

方法设计基于 KAN 的卷积层 ConvKAN，并嵌入图像生成网络；同时把 KAN 与 evolution network 结合，学习风暴云移动和物理演变信息。实验在法国 MeteoNet 雷达数据上与 CNN-based 模型比较。

**主要贡献**

1. 将 ConvKAN 用于 radar echo extrapolation 的图像生成网络。
2. 构建 KAN&evOnet，将演化网络和 KAN 结合以增强物理模式学习。
3. 在公开 MeteoNet 数据集上评估 0-1 小时对流 nowcasting。

**与基于雷达回波的降水临近预报的关系**

高度相关。该文直接预测雷达回波图像，属于物理约束/网络结构创新路线，可与 SwinKAN、NowcastNet evolution network 和 ConvLSTM/UNet 系列比较。

**值得关注的原因**

KAN 在科学建模中的可解释函数拟合能力近年受到关注。该文尝试把 KAN 的函数表示能力用于雷达回波运动和强度演变，可能为物理约束网络提供新的组件。

**可能局限**

KAN 类结构的计算成本、训练稳定性和相对常规 CNN/Transformer 的实际收益仍需谨慎评估。MeteoNet 是区域公开数据集，不能自动代表其他雷达网或强对流气候区。

**后续讨论问题**

1. ConvKAN 的收益来自 KAN 表示能力，还是来自额外参数/结构容量？
2. 与 SwinKAN 的双偏振多变量预测相比，本方法是否更偏向单变量雷达图像质量提升？
3. KAN&evOnet 能否和频域损失、光流/平流约束或扩散模型结合？

### 8. Convolutional Residual-Attention: A Deep Learning Approach for Precipitation Nowcasting

- **链接**: https://onlinelibrary.wiley.com/doi/10.1155/2020/6484812
- **PDF**: Wiley 页面提供全文/PDF入口

- **机构/会议/期刊**: Advances in Meteorology, 2020, Article ID 6484812

- **关键词标签**: MAR-CNN; residual attention; radar reflectivity images; Shenzhen radar dataset; precipitation nowcasting
- **研究方向**: CNN encoder-decoder；Transformer / attention models；Radar reflectivity；Quantitative precipitation nowcasting
- **使用的数据集**: Shenzhen Meteorological Bureau two-year meteorological radar intensity dataset; radar reflectivity images with station precipitation labels
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Wiley 全文说明数据为深圳气象局两年 meteorological radar intensity dataset，样本包含多时次、多高度 radar reflectivity images，每个像素记录 radar reflectivity factor。

**摘要**

论文提出 MAR-CNN，将多头注意力与残差连接引入双通道卷积网络，用于从雷达反射率图像预测未来局地降水。研究区域为深圳，数据来自深圳气象局多高度雷达反射率图像与地面站降水记录。

**方法概述**

模型以目标站点周围的雷达反射率子图作为输入，通过双通道 CNN 抽取空间特征，并利用多头注意力突出对降水预测更有贡献的区域。残差连接用于减少注意力机制可能带来的全局信息损失。

**主要贡献**

1. 在雷达反射率降水预测中结合卷积、注意力和残差结构。
2. 使用深圳多高度雷达反射率图像和站点降水样本进行分类/回归式预报。
3. 关注样本类别不平衡，并对强降水类别进行数据增强处理。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文不是标准序列到序列雷达回波外推，而是从历史雷达反射率图像预测局地降水等级/强度；雷达反射率仍是核心输入。

**值得关注的原因**

该文提供了早期 CNN+attention 在中国城市雷达降水预报中的应用案例，可与后续 Transformer、区域站点降水订正和 radar-gauge fusion 方法比较。

**可能局限**

任务更偏站点/局地降水预测而非完整未来雷达场外推；数据为深圳区域私有业务数据，公开复现受限。SMOTE 等增强方式对时空结构是否合理需要谨慎看待。

**后续讨论问题**

1. 站点降水预测和雷达图像外推在评价指标和业务目标上应如何区分？
2. MAR-CNN 的注意力权重是否能稳定对应物理上关键的回波区域？
3. 多高度雷达反射率是否能为强降水临近预报提供比单层拼图更可靠的信号？
