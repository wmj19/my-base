### 1. ST-HFNet: A Spatiotemporal Hierarchical Fusion Network for Radar Echo Extrapolation

- **链接**: https://doi.org/10.1007/978-981-92-3384-7_50
- **PDF**: https://link.springer.com/content/pdf/10.1007/978-981-92-3384-7_50.pdf
- **来源**: Springer Nature Link / Crossref
- **发布日期/版本日期**: Springer 页面显示 2026-07-14 发布；Crossref 于 2026-07-13 创建并索引；会议论文集书目信息标注为 2027
- **作者**: Huantong Geng, Yitong Zhang, Han Zhao, Kefei Ma, Meijing Shi
- **机构/会议/期刊**: ICIC 2026；Lecture Notes in Computer Science, vol. 16644；Advanced Intelligent Computing Technology and Applications
- **DOI / arXiv ID**: 10.1007/978-981-92-3384-7_50
- **关键词标签**: ST-HFNet; radar echo extrapolation; spatiotemporal gated attention; hierarchical feature fusion; Shanghai Dataset
- **研究方向**: Transformer / attention models；CNN encoder-decoder；雷达回波外推；短时天气雷达预报
- **使用的数据集**: Shanghai Dataset，用于 radar echo extrapolation 实验
- **重点公开数据集匹配**: ShangHai / Shanghai
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Springer 摘要明确说明任务是 radar echo extrapolation，并写明模型在 Shanghai Dataset 上取得优于已有模型的表现。

**摘要**

论文提出 ST-HFNet，用于短时天气预报中的雷达回波外推。作者认为已有深度学习回波外推方法在复杂时空依赖、帧间运动建模和强回波形态保持上仍容易出现强度衰减与形状失真，因此设计了同时关注短程与长程依赖的层级融合结构。实验在 Shanghai Dataset 上验证，属于明确使用公开优先数据集的雷达回波外推工作。

**方法概述**

ST-HFNet 由 Spatiotemporal Gated Attention Module 和 Hierarchical Feature Fusion Module 组成。前者用于从连续雷达回波帧中捕捉帧间运动和多尺度时空依赖，后者通过跨层特征融合改善空间表达，减少解码阶段细节损失。整体目标是缓解长期外推中的回波强度衰减和形态模糊。

**主要贡献**

1. 针对雷达回波外推提出 ST-HFNet，将门控时空注意力与层级特征融合结合。
2. 在公开 Shanghai Dataset 上报告优于已有模型的表现，补充了上海雷达回波基准上的新结构对照。
3. 明确聚焦帧间运动动态、短长程依赖和空间细节保持，对强对流回波外推有直接参考价值。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务、输入数据和评估对象均为 radar echo extrapolation，且使用重点关注的 Shanghai Dataset，可直接纳入雷达回波短临模型结构谱系。

**值得关注的原因**

该论文与同一作者团队近期的 MBFE-UNet 都关注雷达回波外推中的强度衰减和结构保持，但 ST-HFNet 更强调时空门控注意力与层级融合。它提供了一个在 Shanghai Dataset 上追踪 attention/fusion 模块效果的新候选基线。

**可能局限**

Springer 可访问内容主要暴露摘要和书目信息，未公开完整实验设置、训练切分、阈值指标和对照表；正文是否包含开放代码、超参数和可复现实验细节仍需获取 PDF 后继续核验。论文集标注年份为 2027，但页面发布和 Crossref 索引均落在本次扫描窗口。

**后续讨论问题**

1. ST-HFNet 在 Shanghai Dataset 上相对 Rainformer、PredRNN、ConvLSTM 或 MBFE-UNet 的增益主要来自门控注意力还是层级融合？
2. 该结构是否能迁移到 CIKM、SEVIR VIL 或业务雷达拼图，尤其是高阈值强回波 CSI？
3. 若加入概率头或扩散式 refinement，能否进一步缓解长 lead time 下的强回波衰减？

### 2. Spread/Error relationship and spatial error structure of precipitation ensemble nowcasting: Comparison of STEPS and generative AI

- **链接**: https://doi.org/10.5194/egusphere-2026-1460
- **PDF**: https://egusphere.copernicus.org/preprints/2026/egusphere-2026-1460/egusphere-2026-1460.pdf
- **来源**: EGUsphere / Crossref / arXiv
- **发布日期/版本日期**: EGUsphere 2026-04-23 发布；Crossref 于 2026-07-08 新索引；EGUsphere 讨论页 2026-07-08 有作者回复更新
- **作者**: Martin Bonte, Lesley De Cruz, Fabian Debal, Stéphane Vannitsem
- **机构/会议/期刊**: EGUsphere preprint
- **DOI / arXiv ID**: 10.5194/egusphere-2026-1460；arXiv:2601.19298
- **关键词标签**: LDCast; STEPS; generative AI; ensemble nowcasting; spread-error relationship; RADCLIM; radar precipitation
- **研究方向**: Generative / diffusion models；Operational nowcasting systems；不确定性 / 概率预报；雷达降水集合预报评估
- **使用的数据集**: Belgian radar composite RADCLIM；选取比利时对流和层状降水事件评估 STEPS 与预训练 LDCast
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: arXiv 全文说明研究使用 Belgian radar composite RADCLIM 评估模型；EGUsphere 讨论页审稿意见也将该研究描述为两个 ensemble radar nowcasting systems 的对比，其中一个为 generative AI 模型 LDCast。

**摘要**

论文比较传统集合外推方法 STEPS 与生成式 AI 降水临近预报模型 LDCast 在比利时区域的集合扩散、误差结构和空间定位能力。研究发现，两类模型的集合 spread 在多数尺度上能估计误差大小，但集合成员对空间误差位置的刻画能力有限，更多反映统计结构而非真实动力学定位信息。

**方法概述**

作者在 Belgian RADCLIM 雷达降水资料上选择对流和层状事件，对 STEPS 与未针对比利时再训练的 LDCast 生成集合预报。分析包括谱误差、谱方差、集合协方差矩阵特征值、FSS，以及 MAAFT surrogate ensembles 对照，用于判断集合成员是否包含超出集合均值的空间误差信息。

**主要贡献**

1. 将 LDCast 作为生成式 AI nowcasting 模型，与业务常用 STEPS 在同一雷达降水区域上做尺度相关评估。
2. 从 spread/error、谱结构和空间误差定位角度评估集合预报，而不仅限于全局 RMSE 或阈值分数。
3. 通过 surrogate ensembles 说明两类模型的集合 skill 主要来自统计特性，空间误差定位能力仍不足。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文使用雷达复合降水资料评估短时集合降水预报，且核心对象包含生成式 AI nowcasting 模型 LDCast，适合作为概率/集合雷达降水 nowcasting 评估方法参考。

**值得关注的原因**

许多深度学习 nowcasting 论文只报告像素误差或阈值 CSI，该研究关注集合成员是否真正携带空间误差定位信息，对 DGMR、LDCast、扩散模型和业务集合外推的可靠性评估都有启发。

**可能局限**

LDCast 没有在 Belgian RADCLIM 上重新训练，因此结论同时反映模型跨区域迁移和集合生成机制本身；论文主要是诊断评估，不是新 nowcasting 架构。RADCLIM 与 LDCast 原训练数据的降水定义、空间平滑和预处理差异可能影响公平比较。

**后续讨论问题**

1. 如果 LDCast 在 RADCLIM 上重新训练，集合成员的空间误差定位能力是否会改善？
2. 这些 spread/error 与 surrogate ensemble 指标是否可以用于评价 DGMR、NowcastNet 或扩散式雷达 nowcasting？
3. 在业务预警中，集合 spread 能估计误差大小但不能定位误差时，应如何传达不确定性？
