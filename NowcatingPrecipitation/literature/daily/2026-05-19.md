**摘要**

论文面向 1-2 小时强降水临近预报，提出先外推雷达回波、再结合雨量站进行定量降水校正的两阶段框架。SAAR-UNet 通过 ASPP、残差卷积和空间注意力增强强回波变化的外推能力；RST-RainNet 则采用双分支残差校正策略，把外推回波转换为更高精度的降水预报。

**方法概述**

方法把雷达 echo extrapolation 与 radar-gauge QPE/QPN 串联起来：第一阶段用注意力 U-Net 变体预测未来回波结构，第二阶段用深度网络融合雨量站信息，对由回波得到的定量降水结果进行残差修正。这样的结构更接近水文应用中“先雷达外推、再雨量校准”的业务链条。

**主要贡献**

- 将雷达回波外推和雨量站残差校正结合，用于 1 小时和 2 小时定量降水临近预报。
- 在 SAAR-UNet 中引入 ASPP、残差卷积和空间注意力，以改善强回波区域变化预测。
- 用 RST-RainNet 修正外推回波对应的降水估计，强调 radar-gauge 融合对区域降水动态的改善。

**与基于雷达回波的降水临近预报的关系**

该工作直接以雷达回波外推为第一环节，并将输出服务于短时定量降水预报。它适合放入“雷达-雨量站融合”和“雷达回波到定量降水”的方向中，与单纯预测 VIL/反射率的 SEVIR 系列模型形成互补。

**值得关注的原因**

许多深度学习 nowcasting 论文停留在回波图像指标上，该文把雷达外推结果进一步接入雨量站校正和定量降水评估，更贴近洪水防御与水文调度场景。

**可能局限**

可见元数据未给出数据集名称、雷达体制、区域、训练测试划分和强降水分层指标；需要获取全文后确认数据可复现性、雨量站空间分布以及两阶段误差传播。

**摘要**

论文针对现有临近降水模型难以学习雷达回波图像时空非线性变化的问题，提出基于变分自编码器的预报方法。模型在潜空间中定义概率分布以重构雷达回波图像，并结合自注意力和离散潜空间表达复杂上下文语义。

**方法概述**

方法以 VAE 为核心，用潜变量分布表达未来回波图像的不确定结构；自注意力模块学习雷达回波图像在空间和时间维度上的依赖关系；离散潜空间用于增强复杂语义和上下文模式的捕捉。实验与 SimVP 和 PhyDNet 进行比较，目标是预测后续 5 帧雷达回波。

**主要贡献**

- 将 VAE 潜空间建模用于 SEVIR 雷达回波临近预报。
- 引入自注意力捕捉回波图像的时空依赖。
- 使用离散潜空间增强复杂回波结构的上下文表示，并与 SimVP、PhyDNet 比较。

**与基于雷达回波的降水临近预报的关系**

该论文直接以 SEVIR 雷达回波图像作为实验对象，属于公开雷达基准上的生成式/潜空间 nowcasting 工作。它可以作为中文期刊中使用 SEVIR 的补充条目，适合与 PreDiff、DiffCast、PixelFlowCast 等潜空间或生成式方法对照。

**值得关注的原因**

VAE 路线在近期扩散/流模型热潮中常被作为压缩或潜空间建模基础。该文虽然可能不是最新的大模型结构，但对“潜空间表达如何影响雷达回波后续帧预测”仍有综述价值。

**可能局限**

目前可见信息来自 EBSCO 元数据，缺少模型结构细节、SEVIR 预处理、阈值指标和公开代码。仅预测未来 5 帧，长时效和强回波阈值表现还需要阅读全文核查。

- **机构/会议/期刊**: EGUsphere / under review for Geoscientific Model Development
- **DOI / arXiv ID**: 10.5194/egusphere-2026-46
- **关键词标签**: ConvLSTM；STI-DEDN；spatio-temporal information transformation；ADGLoss；multi-meteorological factors；SEVIR；VIL
- **研究方向**: ConvLSTM / recurrent models；Multi-source fusion；Physics-informed / physical constraints；Radar echo extrapolation
- **使用的数据集**: SEVIR；输入/变量包括 VIL、IR107、VIS、IR069 等多源气象变量
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: EGUsphere 摘要说明模型基于美国 SEVIR 数据集进行 1 小时降水预报；审稿补充材料进一步指出目标变量是 SEVIR 的 VIL，VIL 是雷达衍生的对流强度代理。

**摘要**

论文提出 STI-DEDN，将 ConvLSTM 改造成基于时空信息变换思想的双编码器-解码器训练框架，用多源气象变量预测未来 1 小时降水/VIL 演变。作者还提出自适应加权梯度损失 ADGLoss，以缓解预报时效延长后的模糊和高强度降水低估。

**方法概述**

STI-DEDN 用 ConvLSTM 作为主干，在正向时空转换和反向时间-空间重构之间建立双学习约束，试图用神经网络近似 STI 方程中的非线性映射。数据侧使用 SEVIR 的 VIL、可见光、红外和水汽通道等多源变量，训练目标强调 1 小时多步预测。ADGLoss 对强降水梯度区域增加权重，以改善中高强度 VIL 结构。

**主要贡献**

- 将 ConvLSTM 与 STI-inspired 双学习框架结合，增强多源变量到未来降水/VIL 的映射。
- 在 SEVIR 多模态设置中融合 VIL、VIS、IR 等变量，关注异构气象变量之间的时空依赖。
- 用 ADGLoss 缓解中高强度降水区域的系统性低估。

**与基于雷达回波的降水临近预报的关系**

该论文使用 SEVIR VIL 作为核心目标变量，属于雷达衍生 VIL 的多源临近预报。它既保留了 ConvLSTM 路线，又引入类似物理/动力系统动机的双向约束，可放在“ConvLSTM 后续模型”和“多源/机制启发建模”之间讨论。

**值得关注的原因**

审稿意见已经指出该文应更准确地称为 VIL nowcasting，而不是直接地表降雨率预报。这一点对综述写作有价值：SEVIR 论文需要区分雷达 VIL 预测和地表降水量预测，避免把雷达代理变量与真实降水积累混用。

**可能局限**

审稿材料提示 STI 方程与实际网络实现之间的关系需要更谨慎表述；CRPS/BSS 等概率指标若来自确定性输出也需要澄清。随机 SEVIR 切分可能高估泛化，最好等待修订稿确认。

### 4. Tuning of Convolutive Nowcasting Precipitation Models and Evaluation by Rainfall Event Type

- **链接**: https://journals.ametsoc.org/view/journals/aies/5/2/AIES-D-25-0032.1.xml
- **PDF**: 期刊页面提供 Download PDF；未记录稳定 PDF URL
- **来源**: Artificial Intelligence for the Earth Systems / American Meteorological Society
- **发布日期/版本日期**: 2026-04-06 online；AMS 结果在本次 7 日扫描中作为新近抓取结果浮现
- **作者**: Baptiste Guigal, Laurent Barthès, Emmanuel Moreau, Cécile Mallet
- **机构/会议/期刊**: Artificial Intelligence for the Earth Systems, Volume 5, Issue 2
- **DOI / arXiv ID**: 10.1175/AIES-D-25-0032.1
- **关键词标签**: ConvLSTM；SmaAt-UNet；DGMR；PySTEPS；Météo-France Mosaic；rain-event clustering；model tuning
- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；Diffusion / generative models；Operational nowcasting systems
- **使用的数据集**: Météo-France Mosaic / PANTHERE 雷达衍生降水图；巴黎区域 10 年、1 km、5 min 分辨率降水图
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: AMS 摘要说明数据集为 Météo-France Mosaic 产品的 1 km、5 min 降水图；论文预印本/索引摘要进一步说明这些 5 分钟降水累积是 radar-derived rainfall accumulations。

**摘要**

论文不提出新架构，而是系统调参和评估 ConvLSTM、SmaAt-UNet、DGMR 与 PySTEPS 在不同雨型上的表现。数据来自巴黎区域多年高时空分辨率降水图，并按雨型聚类为小范围弱雨、大范围弱雨、中等降水和局地强降水等类别，以分析不同模型配置对强降水事件的影响。

**方法概述**

作者测试输入序列长度、扩展空间输入窗口、输出时效长度和卷积核大小等因素。对 ConvLSTM 而言，增加历史上下文到约 40 分钟、使用更宽空间窗口、训练更长输出序列并优化卷积核大小，可以提升 60 分钟预报，尤其改善强降水事件。SmaAt-UNet 也通过输入时效和空间窗口调整获得收益。

**主要贡献**

- 将常用 nowcasting 模型的调参影响按雨型分组评估，而不是只报告全样本平均指标。
- 说明 ConvLSTM 在更长输入上下文和更大初层卷积核下对强降水事件更有利。
- 用真实雷达衍生降水图展示分辨率、预报时效和水文应用尺度之间的权衡。

**与基于雷达回波的降水临近预报的关系**

该论文使用雷达衍生降水图，关注实际 nowcasting 模型配置，而非新模型堆叠。它对综述中的“ConvLSTM 是否仍有价值”“模型评价是否应按雨型分组”以及“业务水文尺度如何影响指标”都有直接参考意义。

**值得关注的原因**

近期很多论文强调新架构，但实际业务系统常受输入长度、输出窗口、卷积核和空间边界效应影响。该文提供了模型调参和事件类型分层评估的证据，可作为方法比较章节中的实用补充。

**可能局限**

数据来自巴黎区域，跨气候区和跨雷达网络泛化仍需验证。论文主要讨论已有模型调参，方法创新性有限，但工程诊断价值较高。

**后续讨论问题**

3. 若使用扩散/流匹配模型，类似输入窗口和输出窗口调参是否同样关键？

### 5. MambaCast: An Efficient Precipitation Nowcasting Model With Dual-Branch Mamba

- **PDF**: 无公开 PDF
- **来源**: IEEE Geoscience and Remote Sensing Letters metadata；DBLP；ORCID/Crossref metadata

- **机构/会议/期刊**: IEEE Geoscience and Remote Sensing Letters, 23, Article 3500105, pp. 1-5
- **DOI / arXiv ID**: 10.1109/LGRS.2025.3626369
- **关键词标签**: MambaCast；dual-branch Mamba；state-space model；CNN branch；CastFusion；radar echo data
- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；Transformer / attention models；Radar echo extrapolation
- **使用的数据集**: 两个公开雷达数据集；可见元数据未列出具体名称
- **重点公开数据集匹配**: 无可验证匹配
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 可见摘要明确说明 precipitation nowcasting using radar echo data，并表示实验在两个公开雷达数据集上验证。

**摘要**

论文提出 MambaCast，一个基于 Mamba 的双分支高效降水临近预报模型，目标是在复杂非线性雷达回波序列建模中兼顾计算效率和预测精度。模型用状态空间分支建模全局低频演变，用 CNN 分支建模局地高频瞬态结构，再通过 CastFusion 自适应融合。

**方法概述**

SSM Branch 通过选择性扫描捕捉雷达回波场的全局低频演变，CNN Branch 用门控时空注意力提取局地高频变化，CastFusion 在不同频率尺度之间动态集成特征。整体设计与近期 MambaRain、VMU-Diff、PredUMamba 等状态空间 nowcasting 工作形成同一技术趋势。

**主要贡献**

- 将 dual-branch Mamba 结构用于雷达回波临近预报。
- 分离低频全局演变与高频局地瞬态，试图缓解 Mamba 对细节表达不足和 CNN 对长程依赖不足的问题。
- 在两个公开雷达数据集上报告优于基线模型的结果。

**与基于雷达回波的降水临近预报的关系**

该论文直接以雷达 echo data 为对象，属于 Mamba/状态空间模型进入 radar nowcasting 的最新工程化路线之一。它适合与 MambaRain、PredUMamba 和 VMU-Diff 一起讨论状态空间模型在长程时空依赖和推理效率上的潜力。

**值得关注的原因**

Mamba 类模型在降水临近预报中的吸引力在于线性复杂度和长序列建模能力。MambaCast 的双分支设计明确把低频运动和高频细节拆开，有助于评估状态空间模型是否能替代部分 Transformer 或 ConvLSTM 结构。

**可能局限**

当前可见元数据未给出两个公开雷达数据集名称、指标表、代码和消融细节；重点公开数据集是否包含 SEVIR、CIKM 或 ShangHai 尚无法确认。需要获取 IEEE 全文后核查复现性。
