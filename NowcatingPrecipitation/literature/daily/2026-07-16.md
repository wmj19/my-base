### 1. SCECA-Net: A Deep Learning-Based Model for Precipitation Nowcasting

- **链接**: https://doi.org/10.1109/tgrs.2025.3534278
- **PDF**: 无开放 PDF
- **来源**: IEEE Transactions on Geoscience and Remote Sensing / Crossref / Semantic Scholar / ResearchGate metadata snippet

- **作者**: Liangzhi Li; Xu Zhang; Ling Han
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing
- **DOI / arXiv ID**: 10.1109/TGRS.2025.3534278
- **关键词标签**: SCECA-Net; CNN; spatial-channel attention; SCConv; ECA; radar echo extrapolation; severe convective weather
- **研究方向**: CNN encoder-decoder；Transformer / attention models；雷达回波外推；强对流降水临近预报
- **使用的数据集**: Shijiazhuang 和 Nanjing 双偏振雷达回波数据集
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Semantic Scholar 摘要明确称 precipitation nowcasting 的主要挑战是 radar echo map prediction，ResearchGate 摘要片段说明实验使用 Shijiazhuang 和 Nanjing dual-polarization radar echo datasets。

**摘要**

论文面向强对流天气降水临近预报中的雷达回波外推问题，指出现有方法存在回波边界预测不准、特征冗余和推理耗时等问题。SCECA-Net 用全 CNN 架构结合空间-通道增强卷积注意力，以提升关键回波区域的特征提取和预测效率。

**方法概述**

模型采用 MIMO 式预测思路减少递归误差，并在网络中嵌入 SCECA 模块，将 spatial/channel reconstruction convolution 与 efficient channel attention 结合，用于降低空间与通道冗余。Dense Layer 中连续卷积用于缓解过拟合和特征干扰。

**主要贡献**

1. 将空间重构、通道重构和高效通道注意力组合到雷达回波外推网络中。
2. 面向强弱回波区域的差异化关注，改善回波边界和强回波区域预测。
3. 在中国双偏振雷达回波数据上报告了效率和准确率提升。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接把 precipitation nowcasting 建模为 radar echo map prediction，适合作为 CNN/attention 类雷达回波外推基线。

**值得关注的原因**

该文强调降低冗余特征和推理成本，对业务化短时雷达外推有参考价值，尤其适合与 Rainformer、MSPTS-Net、MBFE-UNet 等轻量或高效 CNN/attention 模型对比。

**可能局限**

IEEE 正文在当前环境不可直接访问，数据划分、雷达产品细节、阈值指标和代码开放情况仍需后续获取全文核验。

**摘要**

RainHCNet 针对强降水临近预报中高频细节与低频全局结构难以兼顾的问题，提出混合高低频和跨尺度监督网络。论文在 KNMI、Shanghai、SEVIR 三个数据集上评估，特别强调高强度降水事件预测能力。

**方法概述**

模型以 U-Net 为基础，引入 Hybrid Channel-Spatial Attention 捕获低频全局依赖，并用 Cross-scale Supervision Module 融合深浅层多尺度特征，减少上采样阶段的降水信息损失。作者还设计动态损失权重，使训练更关注高强度降水样本和低频结构。

**主要贡献**

1. 将高频局地结构、低频全局依赖和跨尺度监督整合到轻量 U-Net 类 nowcasting 模型中。
2. 提供 RainHCNet 与轻量版 RainHCNet dagger，用于不同计算资源场景。
3. 同时在 KNMI、Shanghai、SEVIR 上评估，便于跨区域和公开基准比较。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文以雷达回波外推为背景，并命中 Shanghai 与 SEVIR 两个重点数据集，适合纳入公开基准对照表。

**值得关注的原因**

近期雷达 nowcasting 模型常在强降水阈值下出现平滑和强度低估。RainHCNet 直接把低频结构、高强度样本和跨尺度监督作为设计目标，适合与 diffusion、Mamba 和 Transformer 系列比较“强降水保真度 vs. 推理成本”。

- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；雷达回波外推；长时效结构保持
- **使用的数据集**: RadarCIKM；RadarKNMI

- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: EurekaMag 摘要页面说明 MS-DIMNet 在 RadarCIKM 和 RadarKNMI 数据集上实验，并用于 long-term precipitation nowcasting；Crossref 元数据给出 DOI、期刊和 2026-07-14 索引时间。

**摘要**

论文关注长时效降水临近预报中结构消散、记忆退化和图像模糊问题。MS-DIMNet 通过多尺度时序聚合和双分支交互记忆单元，同时增强短期空间结构和长期趋势保持。

**方法概述**

Temporal Multiscale Aggregation 模块通过跨帧对齐和显式聚合冗余信息构造更稳健的空间结构表示。Dual-branch Interactive Memory Unit 将宏观平流趋势与局地瞬态形变分开建模，再用自适应门控平衡两条分支，从而减轻深层循环过程中的记忆衰减。

**主要贡献**

1. 设计 TMSA 以利用相邻帧空间冗余，提升短期结构表达。
2. 用双分支记忆单元分别建模大尺度移动和局地形变。
3. 在 RadarCIKM 和 RadarKNMI 上报告气象指标和结构相似度领先表现。

**与基于雷达回波的降水临近预报的关系**

相关性高。数据集直接为 RadarCIKM 和 RadarKNMI，其中 RadarCIKM 命中重点公开数据集，适合与 PredRANN、PFST-LSTM、MSPTS-Net 和 SLTSL 等序列记忆模型比较。

**值得关注的原因**

该文延续了“显式分解平流趋势与局地形变”的路线，对长时效雷达回波外推中常见的结构消散问题有直接价值。

**可能局限**

IEEE 正文不可访问，Semantic Scholar 暂无摘要；本次主要依据 Crossref 元数据和 EurekaMag 摘要，完整实验设置、数据划分和消融仍需后续核验。

**主要贡献**

1. 在 ConvRNN 框架中引入 TAM 和 LAM，增强长时依赖和层间信息保留。
2. 在 CIKM AnalytiCup 2017 雷达数据上进行实验，并开放官方 PyTorch 代码。

相关性高。该文使用 CIKM 雷达回波数据，是 CIKM 系列 recurrent/attention baseline 的重要条目。

**值得关注的原因**

PredRANN 和 PFST-LSTM 来自同一作者群，可作为比较“注意力保留表示”与“伪流位置对齐/空间记忆”两种 ConvRNN 改进路线的成对基线。

- **机构/会议/期刊**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing
- **DOI / arXiv ID**: 10.1109/JSTARS.2020.3040648
- **关键词标签**: PFST-LSTM; pseudoflow; spatial memory; position alignment; CIKM AnalytiCup 2017; radar echo extrapolation
- **研究方向**: ConvLSTM / recurrent models；光流 / 伪流建模；雷达回波外推；时空序列建模
- **使用的数据集**: CIKM AnalytiCup 2017；MovingMNIST++
- **重点公开数据集匹配**: CIKM
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Semantic Scholar 摘要说明实验包括 CIKM AnalytiCup 2017；官方 GitHub README 称 PFST-LSTM 是 precipitation nowcasting / radar echo extrapolation 模型，并明确在 CIKM AnalytiCup 2017 数据集上实验。

**摘要**

PFST-LSTM 针对卷积 RNN 缺少细粒度空间外观记忆、当前观测与历史隐藏状态存在位置错位的问题，引入伪流预测、空间记忆单元和位置对齐模块，以改善雷达回波序列预测。

**方法概述**

模型在 LSTM 单元中加入 spatial memory cell 保存精细空间外观，并通过 position alignment module 调整当前观测与历史状态的空间位置。PFST-LSTM 构成 sequence-to-sequence 架构，用于结合空间外观和运动信息。

**主要贡献**

1. 在 ConvLSTM 类结构中显式引入伪流和位置对齐。
2. 使用 CIKM AnalytiCup 2017 雷达数据验证，并开放官方代码和训练说明。
3. 针对长时效回波外推中的位移误差和细节遗失提供了结构化解决方案。

**与基于雷达回波的降水临近预报的关系**

相关性高。它是 CIKM 上重要的 recurrent baseline，适合与 PredRANN、FDNet、MS-DIMNet 等运动/记忆增强模型对照。

**值得关注的原因**

PFST-LSTM 的伪流思想与后续 optical flow、flow-deformation、rectified flow 路线存在概念联系，可用于梳理“显式运动建模”在雷达 nowcasting 中的演化。

**可能局限**

仅依赖 CIKM 和 MovingMNIST++ 的早期评估，缺少现代多区域雷达数据集和强降水高阈值对比。

**后续讨论问题**

1. Pseudoflow alignment 是否可以与 Mamba/Transformer 的长程建模结合？

3. 与 FDNet 的 flow/deformation 双路径分解相比，PFST-LSTM 的运动建模粒度有何差异？

**摘要**

论文将视频预测深度学习模型用于巴西 São Paulo 的天气雷达图像临近预报，使用历史雷达反射率图序列预测未来 1 小时反射率序列，并讨论模型连续运行辅助预报员判断降水边界趋势的可行性。

**方法概述**

作者采用 PredRNN++ 处理雷达反射率图像序列，将降水临近预报转化为未来图像帧预测任务。模型输出用于展示降水边界移动和演变趋势，强调作为业务预报辅助工具的潜力。

**主要贡献**

1. 将 PredRNN++ 应用于 São Paulo 本地天气雷达反射率序列。
2. 评估最长 1 小时 lead time 的未来反射率图预测。
3. 关注连续业务使用场景，而不仅是离线 benchmark。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接使用 weather radar reflectivity images，是区域业务雷达场景中的深度学习视频预测案例。

**值得关注的原因**

公开基准多集中在中国、美国、欧洲雷达数据。该文提供南美城市区域雷达应用案例，有助于比较模型在不同雷达网络、气候和降水系统下的泛化问题。

**可能局限**

模型较早，主要使用 PredRNN++，缺少与现代 Transformer、Mamba 或生成式模型对比；本次未能访问 MDPI 正文页面，仅依据 DOI 元数据和 Semantic Scholar 摘要记录。
