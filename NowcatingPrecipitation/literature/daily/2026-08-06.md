**摘要**

论文面向 0-2 小时降水临近预报，关注现有生成式方法对历史条件信息利用不足、时空依赖捕捉不完整，以及复杂山地场景适应性弱的问题。作者提出 WaveCastNet，一个基于 U-Net 的 Diffusion Transformer，通过多尺度增强与高效时空依赖提取提升雷达降水场的未来序列预测。实验覆盖自建皖南山区降水数据集、SEVIR 和 Shanghai Radar，并报告在皖南与 Shanghai Radar 上达到领先表现，在 SEVIR 上也具有竞争力。

**方法概述**

WaveCastNet 以扩散式 U-Net / Transformer 结构为主干。Multi-Scale Enhancement (MSE) 模块通过小波分解显式分离低频全局趋势和高频局地细节，为扩散预测提供更充分的历史条件约束；Spatial-Temporal Dependency Extraction (STDE) 模块引入 Spatial-Temporal Mixture-of-Head (ST-MoH) attention，用于同时建模时间动态依赖和空间相关性。整体目标是在保持生成式细节的同时减少强降水结构模糊和时空不一致。

**主要贡献**

1. 提出 WaveCastNet，将 U-Net-based diffusion Transformer 用于雷达 / 雷达衍生降水临近预报。
2. 设计 MSE 模块，用小波分解强化历史条件中的大尺度组织和小尺度局地演变。
3. 设计 STDE / ST-MoH attention 模块，增强对降水序列时间依赖与空间相关的联合建模。
4. 构建 Southern Anhui Mountain Precipitation dataset，并在 SEVIR 与 Shanghai Radar 上进行公开基准评估；论文给出 GitHub 仓库，但当前仓库页面仍显示 code is coming soon。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接面向短时 precipitation nowcasting，实验包含 Shanghai Radar 和 SEVIR 这两个本项目重点公开雷达 / 雷达衍生基准；Southern Anhui Mountain 数据集也用于检验复杂地形下的区域临近预报适应性。它适合纳入“扩散 / flow 生成式 nowcasting”“复杂地形雷达临近预报”和“公开基准对比”专题。

**值得关注的原因**

WaveCastNet 和近期 QWRF-Net、CRFT、FREUD、PixelFlowCast、DuoCast 等工作都说明雷达 nowcasting 正在从单纯 backbone 改进转向“多尺度条件表征 + 生成式未来序列建模”。该文同时命中 Shanghai Radar 与 SEVIR，便于和历史收录的扩散、flow matching、Mamba、Transformer 方法做基准层面对比。

**可能局限**

论文的正式出版时间信息在 IEEE / Crossref / ResearchGate 之间显示不完全一致，需要后续以 IEEE 最终页面为准。GitHub 当前只显示仓库占位，代码和数据是否真正开放、Southern Anhui Mountain 数据集是否可复现、SEVIR / Shanghai Radar 的预处理和阈值设置是否与既有论文一致，都需要继续核查。

**后续讨论问题**

1. WaveCastNet 的收益主要来自小波多尺度条件表示，还是 ST-MoH attention 对时空一致性的改善？
2. Southern Anhui Mountain 数据集的雷达质量控制、地形遮挡处理和公开许可如何定义？
3. 在 SEVIR 与 Shanghai Radar 上，WaveCastNet 与 QWRF-Net、DuoCast、CRFT、FREUD、DiffCast 的采样成本和高阈值 CSI 是否可在同一协议下比较？
