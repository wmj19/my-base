### 1. Stable Attention Response for Reliable Precipitation Nowcasting

- **链接**: https://arxiv.org/abs/2605.13181
- **PDF**: https://arxiv.org/pdf/2605.13181
- **来源**: arXiv
- **发布日期/版本日期**: 2026-05-13，v1；2026-05-15 例行扫描中新发现
- **作者**: Wenrui Chen, Chen Zhen, Chao Chen, Yi Xu, Zhangcan Kang, Xiao Xiang Zhu, Yuyang Wang
- **机构/会议/期刊**: arXiv preprint
- **DOI / arXiv ID**: arXiv:2605.13181；10.48550/arXiv.2605.13181
- **关键词标签**: SEVIR；MeteoNet；降水临近预报；注意力稳定性；可靠性
- **研究方向**: Transformer / attention models；Benchmark / dataset paper；可靠性分析
- **使用的数据集**: SEVIR；MeteoNet
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: arXiv 元数据说明实验使用 SEVIR 和 MeteoNet；其中 SEVIR 是包含 NEXRAD VIL 雷达衍生拼图的临近预报基准，可满足雷达数据纳入条件。

**摘要**

论文关注深度学习降水临近预报中的可靠性问题，提出从注意力响应的稳定性出发分析模型预测。核心思想是高注意力响应区域在连续预报中应保持相对稳定，若注意力迁移异常，可能对应误差累积或结构失真。

**方法概述**

作者提出 HARE / HARECast 思路，把注意力响应稳定性显式用于临近预报模型设计或诊断。该方向不是单纯追求更复杂的时空 backbone，而是尝试约束模型在关键降水区域上的表征一致性，适合与现有 Transformer 或注意力型 radar nowcasting 模型对比。

**主要贡献**

- 将注意力响应稳定性作为可靠降水临近预报的建模线索。
- 在 SEVIR 和 MeteoNet 上验证，具有与公开雷达基准横向比较的价值。
- 为解释极端回波区域预测退化提供了一个可分析的模型内部信号。

**与基于雷达回波的降水临近预报的关系**

SEVIR 的 VIL 雷达衍生数据使该工作可直接纳入雷达回波临近预报文献链条。它与 PixelFlowCast、Earthformer、DiffCast 等 SEVIR 系列工作有可比较性，尤其适合关注强回波结构保持与长时效误差累积的问题。

**值得关注的原因**

近期 SEVIR 论文多集中在生成式模型、流场建模和频域建模；该论文从注意力稳定性切入，可作为“可靠性/可解释性”方向的补充。

**可能局限**

当前可见信息主要来自 arXiv 元数据和摘要线索；需要进一步检查全文中的输入变量、评价指标和强降水分层结果，确认其雷达变量使用方式及相对基线提升幅度。

**后续讨论问题**

- HARE 稳定性指标能否用于诊断 ConvLSTM、Earthformer 或扩散模型的强回波衰减？
- 在 SEVIR 的 VIL 阈值分层评估中，注意力稳定性是否真正对应 CSI / HSS 改善？
- 该机制是否可作为训练正则项，而不是只作为解释性分析？

### 2. McCast: Memory-Guided Latent Drift Correction for Long-Horizon Precipitation Nowcasting

- **链接**: https://arxiv.org/abs/2605.13197
- **PDF**: https://arxiv.org/pdf/2605.13197
- **来源**: arXiv
- **发布日期/版本日期**: 2026-05-13，v1；2026-05-15 例行扫描中新发现
- **作者**: Heng Wang, Congjie Gao, Zefeng Zhou, Yongqi Wang, Zhengtao Yu, Yufei Ma, Shupeng Zhang, Jinge Shi
- **机构/会议/期刊**: arXiv preprint
- **DOI / arXiv ID**: arXiv:2605.13197；10.48550/arXiv.2605.13197
- **关键词标签**: SEVIR；MeteoNet；long-horizon nowcasting；latent drift correction；memory module
- **研究方向**: ConvLSTM / recurrent models；Transformer / attention models；长时效误差校正
- **使用的数据集**: SEVIR；MeteoNet
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: arXiv 元数据说明实验使用 SEVIR 和 MeteoNet；SEVIR 的 NEXRAD VIL 雷达衍生拼图用于降水临近预报基准，因此满足雷达数据要求。

**摘要**

论文面向长时效降水临近预报中的 latent drift 问题：随着递推预测步数增加，模型内部潜变量可能逐步偏离真实降水演变，导致结构模糊、位置偏移或强度衰减。McCast 试图通过记忆引导的潜空间校正缓解这一问题。

**方法概述**

McCast 在 latent representation 中引入 memory-guided correction，用历史或原型化时空模式约束未来表示的漂移。相比只在像素空间拟合下一帧，方法重点放在多步外推时的潜空间稳定和长期一致性。

**主要贡献**

- 将长时效 precipitation nowcasting 的误差累积表述为 latent drift correction 问题。
- 引入记忆机制，对未来潜变量进行引导或校正。
- 在 SEVIR 和 MeteoNet 上测试，便于与已有 radar nowcasting backbone 比较。

**与基于雷达回波的降水临近预报的关系**

该论文直接使用 SEVIR 基准，与雷达 VIL 序列预测和强对流临近预报高度相关。其“潜空间漂移校正”思路可与 ConvLSTM 的递推误差、Transformer 的长期注意力退化、扩散模型的采样偏移放在同一问题框架下讨论。

**值得关注的原因**

雷达回波临近预报常见问题是预测随时间变平滑、强回波衰减、雨带边界扩散。McCast 把这些现象抽象为潜表示漂移，可能为长时效 nowcasting 提供更清晰的误差控制路径。

**可能局限**

需要阅读全文确认 memory bank 的构造、推理成本、是否依赖数据集特定原型，以及在极端降水阈值上的收益是否明显。

**后续讨论问题**

- latent drift correction 是否能与光流或物理约束联合使用？
- 对 SEVIR 强降水阈值，McCast 改善的是位置、强度还是覆盖范围？
- 记忆模块是否会削弱罕见强对流形态的泛化能力？

### 3. Generative machine learning for skilful 3D radar nowcasting

- **链接**: https://www.nature.com/articles/s41612-026-01407-7
- **PDF**: https://www.nature.com/articles/s41612-026-01407-7.pdf
- **来源**: npj Climate and Atmospheric Science / Nature
- **发布日期/版本日期**: 2026-04-27 发表；2026-05-15 例行扫描中新索引发现
- **作者**: Alec Radford, Stephen P. Musgrave, Meredith Dillon, Eliza Mavrich, Sam Hatfield, Rob Pannell, Julian Brimmer, Daniel J. Gagne II, Ethan Terlizzi, Frank Kelly, Charlotte Declerck
- **机构/会议/期刊**: npj Climate and Atmospheric Science, 9, Article 163 (2026)
- **DOI / arXiv ID**: 10.1038/s41612-026-01407-7
- **关键词标签**: 3D radar echo；generative model；weather radar nowcasting；60-minute forecast；operational radar
- **研究方向**: Diffusion / generative models；Operational nowcasting systems；Short-term weather radar forecasting
- **使用的数据集**: 三维天气雷达回波观测；公开页面未在摘要区给出固定公开数据集名称
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Nature 摘要明确说明 EchoCast-3D 预测未来 60 分钟三维雷达回波，并比较地面天气雷达观测到的降雨率范围。

**摘要**

论文提出 EchoCast-3D，用生成式机器学习进行三维雷达临近预报。与只预测二维地面降水或二维雷达拼图的模型不同，该工作强调云和降水系统的水平与垂直结构，并预测未来 60 分钟的三维雷达回波。

**方法概述**

EchoCast-3D 属于生成式深度学习 nowcasting 方法，目标是在短时效内生成具有物理形态一致性的三维雷达回波场。论文强调三维结构对对流系统演变的价值，并用天气雷达观测的降雨率范围检验预报技能。

**主要贡献**

- 将生成式 nowcasting 从常见二维雷达/降水图扩展到三维雷达回波。
- 面向 60 分钟短时效，强调空间结构和降雨强度分布的技能。
- 对强对流、垂直发展和雷达体扫数据建模有直接参考价值。

**与基于雷达回波的降水临近预报的关系**

该论文以雷达回波本身作为核心预测目标，且使用三维雷达观测，比常见 SEVIR VIL 或二维 CAPPI 任务更接近体扫雷达业务场景。对希望从二维回波外推推进到三维结构预报的研究尤其相关。

**值得关注的原因**

三维雷达 nowcasting 可帮助讨论强对流垂直结构、降水生成机制和近地面降雨率之间的联系。它也能补充目前以二维图像预测为主的 ConvLSTM / Transformer / diffusion 文献。

**可能局限**

公开摘要未显示训练数据规模、雷达网络覆盖区域和模型细节；需要阅读全文核对数据可复现性、与业务基线的比较方式，以及是否提供开源数据或代码。

**后续讨论问题**

- 三维雷达回波预测是否能改善地面强降水阈值下的 CSI / POD？
- EchoCast-3D 的生成式框架能否迁移到 MP-PAWR 或双偏振雷达资料？
- 三维体扫任务和二维 SEVIR VIL benchmark 之间应如何建立可比评价？

### 4. RainPro-8: An Efficient Deep Learning Model to Estimate Rainfall Probabilities Over 8 Hours

- **链接**: https://openreview.net/forum?id=tFAzcPuZcT
- **PDF**: https://openreview.net/pdf?id=tFAzcPuZcT
- **来源**: OpenReview / ICLR 2026
- **发布日期/版本日期**: 2026-01-26 OpenReview 页面；ICLR 2026 conference paper；2026-05-15 例行扫描中新索引发现
- **作者**: Alexandre Tuel, Cesar Quilodran-Casas, Dava Newman, Themistoklis Sapsis
- **机构/会议/期刊**: International Conference on Learning Representations (ICLR) 2026
- **DOI / arXiv ID**: arXiv:2505.10271
- **关键词标签**: radar-satellite-NWP fusion；probabilistic nowcasting；8-hour rainfall probability；SEVIR；RainPro-Europe
- **研究方向**: Multi-source fusion；Uncertainty estimation / probabilistic nowcasting；Operational nowcasting systems
- **使用的数据集**: RainPro-Europe 多源数据集；SEVIR benchmark
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: OpenReview 论文 PDF 描述 RainPro-Europe 为包含雷达、卫星影像、NWP 和雨量站的多模态数据集，并在附录中使用 SEVIR 与 DGMR、MetNet、Earthformer 等模型比较。

**摘要**

RainPro-8 面向 8 小时内降雨概率估计，强调高效、概率化和多源输入。与传统单源雷达回波外推不同，该工作把雷达、卫星、NWP 和站点观测融合起来，预测未来降雨概率，适合业务化风险预警场景。

**方法概述**

模型围绕多源气象资料构建概率预报框架，输出未来若干小时的降水概率。论文还提供 RainPro-Europe 数据集设置，并在 SEVIR 上与多个代表性 nowcasting 模型进行比较，使其既有业务多源融合属性，也能与公开雷达基准发生联系。

**主要贡献**

- 提出面向 8 小时降雨概率的高效深度学习模型。
- 构建或使用包含 radar、satellite、NWP、rain gauge 的多源 RainPro-Europe 数据。
- 在 SEVIR 上补充对比，使结果可与 DGMR、MetNet、Earthformer 等 nowcasting 线索衔接。

**与基于雷达回波的降水临近预报的关系**

该论文不是纯雷达回波外推，而是雷达参与的多源概率 nowcasting。它适合放入“多源融合”和“业务概率预报”分支，与 qPrec、CastDiffuser、MS-FTNet 等雷达-卫星或雷达-多源融合论文一起讨论。

**值得关注的原因**

8 小时时效已经接近临近预报和短临预报边界，单靠雷达外推容易退化；该工作展示了用雷达加 NWP、卫星和站点信息延长有效预报时效的一种路线。

**可能局限**

雷达只是多源输入之一，模型改进不一定能归因于雷达回波建模本身；8 小时时效和概率目标也与常见 0-2 小时 radar echo extrapolation 任务存在差异。

**后续讨论问题**

- RainPro-8 在 0-2 小时时段是否优于纯雷达或 SEVIR 系列模型？
- 多源概率预报的校准指标是否比传统 CSI / HSS 更适合业务降水风险？
- RainPro-Europe 的雷达变量能否单独消融，以衡量雷达贡献？
