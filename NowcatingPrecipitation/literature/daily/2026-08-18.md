### 1. Event-Guided Spatiotemporal Transformer with Conditional Diffusion Refinement for High-Intensity Precipitation Nowcasting

- **链接**: https://doi.org/10.3390/rs18162771
- **PDF**: https://www.mdpi.com/2072-4292/18/16/2771/pdf

- **作者**: Wenqi Li; Haiyong Zheng; Haipeng Cui; Tao Bi; Yiyun Guo; Bo Yin
- **机构/会议/期刊**: Remote Sensing, 18(16), 2771
- **DOI / arXiv ID**: 10.3390/rs18162771
- **关键词标签**: EGN-Nowcast; event-guided nowcasting; spatiotemporal Transformer; conditional diffusion refinement; high-intensity precipitation; KNMI radar
- **研究方向**: Transformer / attention models；Diffusion / generative models；Radar-derived precipitation；Quantitative precipitation nowcasting
- **使用的数据集**: KNMI radar dataset, 2016-2025
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref / MDPI 官方元数据中的摘要说明，实验在 KNMI radar setting 下进行，并基于 2016-2025 年 KNMI radar dataset 评估高强度降水临近预报。

**摘要**

论文关注高强度降水临近预报中常见的过平滑问题：以 MSE 为主的回归式深度学习模型容易低估强降水中心，导致局地强降水结构不清晰、预警价值下降。作者提出 EGN-Nowcast，把事件引导的时空 Transformer 与条件扩散细化模块结合起来，在粗预测阶段增强模型对高强度区域的优化关注，再用扩散 refiner 恢复细尺度结构。实验使用 2016-2025 年 KNMI 雷达数据集，报告在像素级、分类检验和视觉指标上均有改进，并降低了高强度降水事件的虚警率。

**方法概述**

EGN-Nowcast 是两阶段框架。第一阶段使用 event-aware spatiotemporal Transformer 生成粗略降水预报，并通过 intensity-aware auxiliary supervision 对强降水区域施加隐式正则，引导主干网络不要只优化占比更大的弱降水 / 无降水像素。第二阶段使用 Conditional Diffusion Refiner，以第一阶段输出作为条件，对未来降水场进行结构细化，目标是在保留时空一致性的同时恢复局地高强度细节，缓解确定性预测常见的模糊化。

**主要贡献**

1. 针对高强度降水 nowcasting 的稀疏性与过平滑问题，引入事件感知辅助监督，把优化重点显式拉向强降水区域。
2. 将时空 Transformer 的粗预测能力与条件扩散的细节恢复能力组合成两阶段框架，兼顾动态一致性和局地纹理。
3. 在 2016-2025 年 KNMI 雷达数据上验证，覆盖较长时间跨度的业务类雷达降水场。
4. 论文将虚警率和高强度阈值表现作为关注点，和强降水预警场景直接相关。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务是高强度降水临近预报，实验数据明确为 KNMI radar dataset；模型围绕雷达降水场的未来演变、强降水中心保持和虚警控制进行设计，满足本自动化的雷达数据硬性规则。

**值得关注的原因**

近期雷达 nowcasting 中，确定性 Transformer / U-Net 路线和扩散 / flow 生成式路线都在尝试解决强回波细节丢失问题。EGN-Nowcast 的特点是把“先做事件感知粗预测、再做条件扩散细化”作为明确流程，适合与 DiffCast、PreDiff、PstpNet、QWRF-Net、FreCast 等方法对比，尤其可用于讨论高阈值 CSI / FAR 改善来自损失重加权、事件引导还是生成式细化。

**可能局限**

当前可访问证据主要来自 Crossref / MDPI 官方元数据和搜索索引摘要；本环境直接访问 MDPI HTML / PDF 返回 Access Denied，因此完整训练细节、样本划分、基线设置和消融表仍需后续复核。论文目前只在 KNMI 雷达数据上给出可见实验信息，未看到 CIKM、ShangHai / Shanghai Radar、SEVIR 或 MetNet 实验；跨区域泛化和与同类扩散 / flow 模型的统一协议比较仍不明确。

**后续讨论问题**

1. EGN-Nowcast 的性能提升主要来自 event-aware auxiliary supervision，还是来自 Conditional Diffusion Refiner？
2. 在高强度阈值下，FAR 降低是否伴随 POD / CSI 的权衡变化？
3. 如果迁移到 SEVIR、Shanghai Radar 或 CIKM，事件感知监督对强回波稀疏性的改善是否仍稳定？
4. 条件扩散细化模块的推理成本是否适合高频业务临近预报更新？
