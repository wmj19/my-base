### 1. When the Past Matters: FlashBack Memory for Precipitation Nowcasting

- **链接**: https://arxiv.org/abs/2606.16342
- **PDF**: https://arxiv.org/pdf/2606.16342
- **来源**: arXiv
- **发布日期/版本日期**: 2026-06-15
- **作者**: Yuhao Du, Boxiao Huang, Chengrong Wu, Jiankai Zhang
- **机构/会议/期刊**: arXiv preprint
- **DOI / arXiv ID**: arXiv:2606.16342
- **关键词标签**: FlashBack Memory; RNN; PredRNN; MotionRNN; radar reflectivity maps; CIKM2017; Shanghai2020; SEVIR
- **研究方向**: ConvLSTM / recurrent models; Transformer / attention models; Radar echo extrapolation; Precipitation nowcasting
- **使用的数据集**: CIKM2017、Shanghai2020、SEVIR
- **重点公开数据集匹配**: CIKM；ShangHai / Shanghai；SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 论文的问题定义明确写到目标是基于历史观测序列预测未来 radar reflectivity maps；实验在 CIKM2017、Shanghai2020 和 SEVIR 三个降水临近预报数据集上进行。

**摘要**

论文提出 FlashBack Memory（FB），面向递归式降水临近预报模型在长序列、强降水和复杂天气演变中容易遗忘关键历史状态的问题。FB 通过动态检索历史隐状态、路由聚合和自适应融合门，把与当前回波演变相似的历史记忆重新注入 PredRNN、PredRNN++、MIM、MotionRNN 和 PredRNN-V2 等基线。作者在 CIKM2017、Shanghai2020 和 SEVIR 上报告 MSE、MAE、SSIM 和 CSI 的一致改善，尤其强调高强度降水阈值与长序列预测的收益。

**方法概述**

FB 维护一个外部历史隐状态缓冲区，用当前隐藏状态与历史记忆计算相似度，再通过动态路由逐步强化相关记忆槽。检索到的 memory representation 通过卷积式融合门与当前隐状态结合，作为后续解码的更新状态。该模块是可插拔设计，可接入多种 RNN 类时空预测框架。

**主要贡献**

1. 提出面向降水临近预报的动态历史记忆检索模块。
2. 在多个递归式基线上验证 FB 的通用增益，而不是只绑定单一网络。
3. 同时覆盖 CIKM2017、Shanghai2020 和 SEVIR，便于与公开雷达 nowcasting 基准比较。
4. 可视化和消融显示 FB 有助于减少虚警、漏报并改善关键降水区域定位。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接把任务定义为未来 radar reflectivity maps 预测，并在三个常用雷达/雷达衍生 nowcasting 数据集上实验；对 ConvLSTM / PredRNN 系列模型的记忆增强有直接参考价值。

**值得关注的原因**

本轮最重要的重点数据集匹配论文。它同时覆盖 CIKM、Shanghai/ShangHai 和 SEVIR，有利于横向比较公开基准上的 RNN 记忆机制、Transformer/attention 模块和生成式方法。

**可能局限**

当前版本仍是 arXiv 预印本；需要后续核验代码开放、数据预处理细节、训练预算与各基线是否完全公平。该方法主要增强 RNN 类模型，对 diffusion / flow matching / Transformer-only 框架的直接适配仍需进一步验证。

**后续讨论问题**

1. FB 的历史检索是否主要改善强回波的空间定位，还是也能提升强度校准？
2. CIKM2017、Shanghai2020、SEVIR 三个数据集上的收益是否来自相同类型的长程依赖？
3. 该模块能否与多源融合模型或物理约束模型结合，作为轻量长期记忆组件？

### 2. DYNA-PRUNER: Input-Adaptive Data-Model Co-Pruning for Efficient and Scalable Spatio-Temporal Media Prediction

- **链接**: https://arxiv.org/abs/2606.15346
- **PDF**: https://arxiv.org/pdf/2606.15346
- **来源**: arXiv
- **发布日期/版本日期**: 2026-06-13
- **作者**: Fuyan Zhang, Yuqi Li, Qing Xu, Yingli Tian, Edmond S. L. Ho
- **机构/会议/期刊**: arXiv preprint；ICME 2026 Spotlight Paper（论文注释）
- **DOI / arXiv ID**: arXiv:2606.15346
- **关键词标签**: dynamic pruning; data-model co-pruning; spatio-temporal prediction; SEVIR; radar/satellite nowcasting; edge deployment
- **研究方向**: Operational nowcasting systems; Model compression / efficient inference; Short-term weather radar forecasting
- **使用的数据集**: WeatherBench、SEVIR、TaxiBJ
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 论文摘要说明方法支持 radar/satellite nowcasting，并在 SEVIR 上实验；文中引用 SEVIR 为 radar and satellite meteorology 的 storm event imagery dataset。

**摘要**

论文提出 Dyna-Pruner，一个针对时空预测模型的输入自适应数据-模型协同剪枝框架。它不是专门的降水临近预报模型，而是面向 WeatherBench、SEVIR 和 TaxiBJ 等时空任务的效率优化方法。对 SEVIR 这类稀疏、突发天气事件 nowcasting，Dyna-Pruner 通过动态重要性图同时裁剪低信息输入区域和对应计算单元，在 CNN、RNN、Transformer 主干上以较小精度损失降低 FLOPs 和 Jetson 边缘设备延迟。

**方法概述**

模型先从输入时空张量生成连续重要性图，再由同一重要性场派生 data mask 和 model mask。训练时用软掩码和稀疏正则保持可微，推理时二值化掩码，只在高价值空间区域和相关结构单元上执行计算。核心思想是把“哪里有动态天气信号”和“模型需要激活哪些计算单元”同步起来。

**主要贡献**

1. 提出数据剪枝与模型结构剪枝协同的动态稀疏推理框架。
2. 在 SimVP、ConvLSTM、TAU 三类主干上验证通用性。
3. 在 SEVIR 上展示 radar/satellite nowcasting 场景中的效率-精度权衡。
4. 在 NVIDIA Jetson AGX Orin 上报告实际延迟收益，贴近边缘业务部署问题。

**与基于雷达回波的降水临近预报的关系**

相关性中等偏低但可保留。论文不是专门研究降水物理或雷达回波外推，但实验包含 SEVIR，并明确把 radar/satellite nowcasting 作为应用场景之一；对雷达 nowcasting 模型的实时化、边缘部署和稀疏计算策略有参考价值。

**值得关注的原因**

SEVIR 是本专题重点公开数据集。相比继续追求更复杂主干，Dyna-Pruner 关注实际部署成本，适合放在“高效推理/业务系统”方向中与轻量 U-Net、SimVP、ConvLSTM、TAU 和模型压缩方法比较。

**可能局限**

论文对 SEVIR 的描述偏任务级，未在摘要中细分具体使用 VIL、IR 或多通道组合；本次纳入主要依据 PDF 中 radar/satellite nowcasting 与 SEVIR radar/satellite meteorology 证据。它更像通用压缩论文，气象解释性和强降水阈值评估不足。

**后续讨论问题**

1. 剪枝重要性图是否真的聚焦强对流/强回波区域，而不是仅学习到背景稀疏性？
2. 在 SEVIR 的高阈值 CSI 上，70% FLOPs 降低是否会损害极端降水捕捉？
3. 该框架能否套到 DiffCast、FREUD、PixelFlowCast 等生成式 nowcasting 模型上？

### 3. Real-Time Aircraft Rerouting Optimization in Thunderstorm Environments Leveraging Deep Learning-Based Nowcasting

- **链接**: https://doi.org/10.3390/aerospace13060545
- **PDF**: 未获取（MDPI 页面访问受限；本次依据 Crossref 元数据核验）
- **来源**: Aerospace / Crossref
- **发布日期/版本日期**: 2026-06-11 在线发表；Crossref 2026-06-12 索引
- **作者**: Luanwei Chen, Hua Gao, Xinxin Lai, Sheng Yu, Zixuan Wu, Junfeng Zhang
- **机构/会议/期刊**: Aerospace
- **DOI / arXiv ID**: 10.3390/aerospace13060545
- **关键词标签**: RainNet; radar reflectivity nowcasting; thunderstorm avoidance; dynamic aircraft rerouting; operational decision support
- **研究方向**: Operational nowcasting systems; CNN encoder-decoder; Short-term weather radar forecasting
- **使用的数据集**: 实际雷暴场景中的雷达反射率 nowcasting 输入；具体雷达产品需全文进一步核验
- **重点公开数据集匹配**: 无（未匹配 CIKM、ShangHai/Shanghai、SEVIR 或 MetNet）
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref 摘要说明感知层使用 RainNet deep learning model 对 radar reflectivity 进行 short-term recursive nowcasting，并把结果转换为动态避让区。

**摘要**

论文面向雷暴天气下的实时航班改航，提出“感知层 + 决策层”的业务优化框架。感知层用 RainNet 对雷达反射率进行短时递归 nowcasting，并通过聚类和凸包算法构建 Dynamic Avoidance Zones；决策层用两阶段改进遗传算法生成并平滑改航路径。实验摘要报告该框架在实际场景中相对采样策略减少路径长度，并显著降低累计转弯角，目标是减少雷暴改航中的锯齿路径和控制员工作负担。

**方法概述**

该工作不是提出新的 radar nowcasting 网络，而是把已有 RainNet 作为雷暴态势预测组件嵌入航路优化。雷达反射率递归预报先被转换为可用于路径规划的动态避让区，再由 receding-horizon 框架和遗传算法处理飞行路径约束。

**主要贡献**

1. 将深度学习 radar reflectivity nowcasting 与航班实时改航优化结合。
2. 用 RainNet 输出构建动态雷暴避让区，而不是只依赖静态天气区。
3. 引入路径平滑模块，降低改航路线的累计转弯角和锯齿抖动。
4. 提供了雷达 nowcasting 进入航空运行决策链的近期案例。

**与基于雷达回波的降水临近预报的关系**

相关性中等。雷达临近预报不是论文唯一贡献，但 radar reflectivity 的深度学习 nowcasting 是感知层核心输入；适合纳入“业务应用/决策支持”方向，而不是作为新模型基准。

**值得关注的原因**

多数 nowcasting 论文停留在像素指标或降水阈值指标，该论文把雷达反射率预报转成航空避让区和路径优化指标，提供了“预报误差如何进入下游决策成本”的应用样例。

**可能局限**

本次未获取全文，雷达产品来源、RainNet 训练方式、预报时效、递归误差传播、避让区阈值和实际航班样本数量都需要后续核验。论文可能更偏交通/航空优化，对 nowcasting 模型本身的贡献有限。

**后续讨论问题**

1. RainNet 的平滑化误差会如何影响雷暴避让区边界和路径安全裕度？
2. 如果换成概率生成式 radar nowcasting，是否能把不确定性显式传入改航优化？
3. 航空路径指标是否可以反向定义 nowcasting 的任务损失，而不只优化像素误差？
