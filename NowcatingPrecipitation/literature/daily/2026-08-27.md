### 1. Radar Based Precipitation Nowcasting Prediction by Using Deep Learning Techniques

- **链接**: https://doi.org/10.1051/e3sconf/202340504003
- **PDF**: https://www.e3s-conferences.org/articles/e3sconf/pdf/2023/42/e3sconf_icstce2023_04003.pdf
- **来源**: Crossref / EDP Sciences E3S Web of Conferences / E3S PDF
- **发布日期/版本日期**: Published 2023-07-26；Crossref indexed 2026-08-21 UTC
- **作者**: Shaik Imran; T. Anuradha; Ratnala Bharat
- **机构/会议/期刊**: E3S Web of Conferences, 405, 04003, ICSTCE 2023
- **DOI / arXiv ID**: 10.1051/e3sconf/202340504003
- **关键词标签**: CNN; ConvLSTM; radar echo dataset; Shanghai weather radar; precipitation nowcasting
- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；Radar echo extrapolation；Precipitation nowcasting
- **使用的数据集**: Weather Surveillance Radar in Shanghai, China；2015 年第四季度至 2018 年第三季度约 170,000 张 6 min 间隔 Doppler radar intensity images；实验子集为 1 天 80 张序列图
- **重点公开数据集匹配**: ShangHai / Shanghai Radar
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: E3S PDF 摘要说明模型在 radar echo dataset 上训练；数据集章节说明数据由上海天气监测雷达反射生成，包含 2015 年末至 2018 年第三季度的 Doppler radar intensity images，并用连续雷达图像预测未来序列。

**摘要**

论文将短时降水临近预报建模为雷达图像序列预测任务，尝试把 CNN 的空间特征提取与 LSTM / ConvLSTM 的时序记忆结合起来。作者先在 Moving MNIST 上测试序列预测能力，再迁移到真实雷达图像数据集，输入过去若干帧雷达回波图并预测未来回波图。报告结果显示模型可以生成未来 6 min 间隔图像序列，并给出超过 90% 的准确率描述。

**方法概述**

方法路线较基础：使用 CNN 提取单帧雷达图像空间特征，再用 LSTM / ConvLSTM 建模连续雷达图像的时间演变。训练目标基于预测图像与真实后续雷达图像之间的差异，文中提到使用 logcosh loss 以缓解异常值影响。整体更接近早期 ConvLSTM radar echo extrapolation 实验，而不是现代 Transformer / diffusion 架构。

**主要贡献**

1. 将 CNN 与 ConvLSTM 组合用于上海雷达图像序列预测。
2. 明确使用 6 min 间隔的雷达回波图作为输入和输出，任务定义贴合 radar echo extrapolation。
3. 命中 Shanghai Radar / ShangHai 类公开数据集线索，可与后续 Shanghai Radar benchmark 谱系交叉核对。
4. 提供一个轻量、教学型的早期深度学习 baseline，可作为高复杂度模型之外的低门槛参照。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文输入、输出和评估对象都是连续雷达回波图像，目标是用历史 radar images 预测未来 radar images，再服务短时降水临近预报。

**值得关注的原因**

本地索引此前未收录该 E3S 条目；Crossref 在 2026-08-21 重新索引后进入本轮窗口。虽然方法简单，但其数据描述与上海 2015-2018 雷达回波数据高度相关，可补充 Shanghai Radar 数据集早期使用记录。

**可能局限**

实验规模很小，正文说明最终只选取 1 天 80 张序列图进行训练与测试；文中对 Shanghai Weather Surveillance Radar 与 WSR-88D / NEXRAD 的表述存在不一致，后续若用于正式综述需要再核验数据来源；指标报告较粗，不足以和现代 benchmark 做公平比较。

### 2. NeXtNow: A Convolutional Deep Learning Model for the Prediction of Weather Radar Data for Nowcasting Purposes

- **链接**: https://doi.org/10.3390/rs14163890
- **PDF**: https://mdpi-res.com/d_attachment/remotesensing/remotesensing-14-03890/article_deploy/remotesensing-14-03890.pdf
- **来源**: Crossref / MDPI Remote Sensing / MDPI PDF
- **发布日期/版本日期**: Published 2022-08-11；Crossref indexed 2026-08-23 UTC
- **作者**: Alexandra-Ioana Albu; Gabriela Czibula; Andrei Mihai; Istvan Gergely Czibula; Sorin Burcea; Abdelkader Mezghani
- **机构/会议/期刊**: Remote Sensing, 14(16), 3890
- **DOI / arXiv ID**: 10.3390/rs14163890
- **关键词标签**: NeXtNow; ResNeXt; weather radar product prediction; reflectivity; Doppler radial velocity; Romania NMA; MET Norway
- **研究方向**: CNN encoder-decoder；Radar reflectivity；Short-term weather radar forecasting；Operational nowcasting systems
- **使用的数据集**: Romanian National Meteorological Administration Doppler single-polarization radar data；MET Norway composite reflectivity data
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI PDF 数据章节说明第一组 NMA 数据来自罗马尼亚中部 Doppler single-polarization radar，实验使用 base reflectivity 和 base velocity；第二组 MET Norway 数据为多雷达处理得到的 composite reflectivity product。

**摘要**

论文提出 NeXtNow，一个基于 ResNeXt 思路的卷积编码器-解码器网络，用于把历史天气雷达测量映射到未来雷达测量。作者认为雷达产品短时预测可以直接服务业务 nowcasting，且纯卷积结构在推理速度与多通道雷达产品建模上有部署优势。实验包含罗马尼亚 NMA 雷达数据与挪威 MET composite reflectivity 数据，比较单帧和多帧历史输入对未来雷达产品预测的影响。

**方法概述**

NeXtNow 将 ResNeXt 的 grouped convolution / cardinality 思路用于雷达时空预测。模型输入为过去的一个或多个雷达产品帧，输出未来同类雷达产品图。第一组实验使用 reflectivity 与 Doppler radial velocity 的低仰角产品；第二组实验使用挪威多雷达 composite reflectivity。研究重点不是生成式清晰化，而是检验卷积架构能否稳定预测短期雷达产品演变。

**主要贡献**

1. 将 ResNeXt 风格卷积架构迁移到 weather radar product nowcasting。
2. 同时验证罗马尼亚单站多仰角雷达产品与挪威多雷达 composite reflectivity。
3. 比较不同数量历史雷达帧作为输入时的性能变化。
4. 提供欧洲业务雷达产品预测场景下的轻量 CNN 参照。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接预测未来天气雷达产品，核心输入包含雷达反射率与径向速度，属于 radar-data-driven short-term weather radar forecasting。

**值得关注的原因**

多数公开 benchmark 聚焦单一 VIL / echo map，NeXtNow 更接近业务雷达产品预测：既有单站多仰角 R/V 产品，也有多雷达 composite reflectivity。它对多产品、多国家业务数据适配有参考价值。

**可能局限**

论文主要预测雷达产品本身，不一定直接输出降水率；数据不是 CIKM、ShangHai、SEVIR 或 MetNet，公开复现实验受限；纯卷积模型对长时程非线性运动和强对流生消的表达可能不足。

**后续讨论问题**

1. 径向速度通道对强对流触发和移动方向预测的增益有多大？
2. NeXtNow 是否适合作为多雷达产品融合的轻量 encoder baseline？
3. 如果把输出目标改为 SEVIR VIL 或 Shanghai echo map，ResNeXt 结构是否仍有优势？

### 3. RaDiT: A Differential Transformer-Based Hybrid Deep Learning Model for Radar Echo Extrapolation

- **链接**: https://doi.org/10.3390/rs17121976
- **PDF**: https://mdpi-res.com/d_attachment/remotesensing/remotesensing-17-01976/article_deploy/remotesensing-17-01976.pdf
- **来源**: Crossref / MDPI Remote Sensing / MDPI PDF
- **发布日期/版本日期**: Published 2025-06-06；Crossref indexed 2026-08-23 UTC
- **作者**: Wenda Zhu; Zhenyu Lu; Yuan Zhang; Ziqi Zhao; Bingjian Lu; Ruiyi Li
- **机构/会议/期刊**: Remote Sensing, 17(12), 1976
- **DOI / arXiv ID**: 10.3390/rs17121976
- **关键词标签**: RaDiT; differential transformer; adversarial training; U-Net; CMARC; SEVIR; radar reflectivity
- **研究方向**: Transformer / attention models；GAN / adversarial models；CNN encoder-decoder；Radar echo extrapolation
- **使用的数据集**: CMA radar reflectivity data (CMARC), 2022-08-01 to 2024-10-31；SEVIR VIL
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI PDF 数据章节说明 RaDiT 使用 CMA 国家雷达组网的 CMARC radar reflectivity 数据，并使用 SEVIR VIL mosaics；摘要也说明任务来自 sequential radar reflectivity inputs。

**摘要**

论文针对深度学习雷达回波外推中的两个常见问题：自回归预测导致的强度衰减，以及高强度回波边界的模糊扩散。作者提出 RaDiT，将 U-Net backbone、vision transformer block、differential attention 和条件 GAN 判别器组合起来，用于增强长序列雷达回波外推中的噪声抑制、结构保持和强回波定位。实验在 CMARC 与 SEVIR VIL 上报告相对 PreDiff 的 CSI 改进。

**方法概述**

RaDiT 使用混合编码器-解码器结构。U-Net 分支保留局地纹理和空间细节，Transformer block 建模长程时空依赖；differential attention 用差分注意力抑制背景噪声和虚假回波；条件 GAN 判别器负责推动生成序列在图像层面更接近真实雷达回波。训练和评估覆盖 CMARC 的多个中国区域雷达组网样本，以及下采样 SEVIR VIL。

**主要贡献**

1. 将 differential transformer 引入 radar echo extrapolation，用于长序列特征利用和噪声抑制。
2. 使用 U-Net + Transformer + GAN 的混合结构，同时关注局地纹理、全局依赖和生成清晰度。
3. 在 CMARC 与 SEVIR VIL 上验证，命中重点公开数据集 SEVIR。
4. 明确面向 >=30 dBZ 高阈值表现，关注强回波保持而非仅优化平均误差。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务就是基于历史 radar reflectivity / VIL 序列预测未来回波序列，且 SEVIR 结果可与 PreDiff、DiffCast、FreCast、FlowCast 等公开 benchmark 路线对比。

**值得关注的原因**

RaDiT 同时覆盖业务级 CMARC 雷达组网与公开 SEVIR benchmark，适合作为“Transformer 与生成式判别器结合提升强回波保持”的代表。它还提供了新的 CMARC 数据线索，可用于整理中国多区域雷达组网实验。

**可能局限**

模型结构较复杂，U-Net、Transformer、differential attention 和 GAN 判别器共同作用后，实际增益来源需要看消融；SEVIR 使用下采样版本，与其他论文协议未必完全一致；CMARC 数据不一定公开，复现主要依赖 SEVIR。

**后续讨论问题**

1. RaDiT 在 SEVIR 上与 FreCast / QWRF-Net / FlowCast 是否使用同一输入输出协议？
2. differential attention 的收益主要来自强回波边界，还是背景虚警抑制？
3. GAN 判别器是否会改善视觉清晰度但引入位置偏差？

- **链接**: https://doi.org/10.1109/access.2023.3280932
- **PDF**: https://ieeexplore.ieee.org/iel7/6287639/10005208/10138400.pdf

- **作者**: Jinliang Yao; Feifan Xu; Zheng Qian; Zhipeng Cai
- **机构/会议/期刊**: IEEE Access, 11, 53249-53261
- **DOI / arXiv ID**: 10.1109/ACCESS.2023.3280932
- **关键词标签**: DyConvGRU; U-Net; WGAN; forecast-refinement; Shanghai radar dataset; high reflectivity
- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；GAN / adversarial models；Radar echo extrapolation
- **使用的数据集**: Radar dataset from Shanghai, China
- **重点公开数据集匹配**: ShangHai / Shanghai Radar
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: IEEE 检索元数据说明该文通过上海雷达数据集实验，任务是 radar echo extrapolation；摘要片段说明目标是改善高反射率雷达回波预测，并报告 POD、CSI、HSS、FAR 指标。

**摘要**

论文关注 ConvRNN 类 radar echo extrapolation 模型随 lead time 增长而低估高反射率区域的问题。作者提出 forecast-refinement neural network，用 DyConvGRU 生成初步预测，再通过 U-Net refinement 结构增强高反射率区域，并使用 WGAN 训练策略提升生成图像真实感。实验在中国上海雷达数据集上进行，报告相较对比模型提升 POD、CSI、HSS，并降低 FAR。

**方法概述**

方法分为 forecast 与 refinement 两部分。Forecast 模块使用动态卷积 GRU 捕捉雷达回波的时空演变；Refinement 模块用 U-Net 修正初步预测，重点增强高反射率回波的空间形态和强度。WGAN 训练用于减轻 MSE 类损失造成的模糊，使未来雷达图像更接近真实分布。

**主要贡献**

1. 针对高反射率回波低估问题设计 forecast-refinement 两阶段结构。
2. 将 DyConvGRU 与 U-Net 结合，兼顾时序演变和空间细节修复。
3. 引入 WGAN 训练策略，缓解雷达回波外推中的模糊预测。
4. 在 Shanghai radar dataset 上验证，命中重点公开数据集线索。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文明确以 radar echo extrapolation 作为 precipitation nowcasting 的核心挑战，数据和指标均围绕上海雷达回波图预测展开。

**值得关注的原因**

该文是 Shanghai Radar 谱系中较早把动态卷积、U-Net refinement 和 WGAN 结合的工作，可与后续 RadarDiff、FreCast、WinG-LSTM、DuoCast 等使用 Shanghai Radar 的模型做历史脉络对比。

**可能局限**

IEEE 正文当前受访问限制，本轮只从 Crossref 与 IEEE 检索元数据核验题名、作者、页码和上海雷达数据集证据；细节如样本划分、阈值协议和完整消融仍需后续获取 PDF 后复核。

### 5. MissPred: A Robust Two-Stage Radar Echo Extrapolation Algorithm for Incomplete Sequences

- **链接**: https://doi.org/10.3390/rs17122066
- **PDF**: https://mdpi-res.com/d_attachment/remotesensing/remotesensing-17-02066/article_deploy/remotesensing-17-02066.pdf
- **来源**: Crossref / MDPI Remote Sensing / MDPI PDF
- **发布日期/版本日期**: Published 2025-06-16；Crossref indexed 2026-08-23 UTC
- **作者**: Ziqi Zhao; Chunxu Duan; Lin Song; Qilin Zhang; Wenda Zhu; Yi Liu
- **机构/会议/期刊**: Remote Sensing, 17(12), 2066
- **DOI / arXiv ID**: 10.3390/rs17122066
- **关键词标签**: MissPred; missing radar sequences; interpolation-extrapolation; dual encoder-decoder; adversarial training; Shandong radar
- **研究方向**: CNN encoder-decoder；GAN / adversarial models；Radar echo extrapolation；Operational nowcasting systems
- **使用的数据集**: CMA national radar data over Shandong Province, 2022-10 to 2024-07, 1 km / 6 min；15,000 samples with simulated 10%-50% missing rates
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI PDF 数据章节说明数据来自中国气象局气象探测中心国家雷达资料，覆盖山东省，空间分辨率 1 km、时间分辨率 6 min；实验选取降水事件的 radar reflectivity data，并用过去 10 帧预测后续 10 帧。

**摘要**

论文关注真实业务雷达数据中常见的缺帧问题。既有 radar echo extrapolation 模型通常假设输入序列完整，但设备故障、通信中断或数据传输问题会导致雷达图像缺失。MissPred 提出一个两阶段模型，将缺失帧重建和未来回波外推联合考虑，避免传统“先插值、再外推”流水线带来的误差累积。实验在山东区域国家雷达数据上模拟 10%-50% 缺失率并测试鲁棒性。

**方法概述**

MissPred 采用双编码器-双解码器架构。原始序列分支处理可见雷达帧，差分分支提取帧间变化和缺失模式；missing spatiotemporal feature fusion 模块融合原始和差分特征；训练过程按重建和外推两个串联任务组织，并加入 adversarial training 让生成雷达序列更接近真实分布。

**主要贡献**

1. 将缺失雷达输入下的 extrapolation 明确作为问题建模，而不是假设数据完整。
2. 通过原始序列与差分序列双分支捕捉缺帧模式和回波运动趋势。
3. 在 10%-50% 缺失率下评估模型鲁棒性，贴近业务雷达传输异常场景。
4. 使用 CMA 国家雷达资料，覆盖山东区域 2022-2024 年降水事件。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文直接处理 radar reflectivity sequence extrapolation，且重点是业务系统中输入数据不完整时如何保持预测稳定。

**值得关注的原因**

多数 benchmark 假设输入帧完整，MissPred 则把缺帧作为核心变量，适合用于讨论 operational nowcasting 的数据质量鲁棒性、传感器故障、通信中断和在线系统容错。

**可能局限**

缺失模式主要通过随机置零模拟，真实雷达缺测可能具有空间块状、站点级或天气相关偏差；数据不属于公开 priority dataset；模型结构包含重建和外推双任务，部署成本高于普通单阶段外推模型。

**后续讨论问题**

1. 随机缺帧模拟是否足以代表业务雷达网络的真实缺测机制？
2. MissPred 能否迁移到 SEVIR 或 Shanghai Radar 的人为缺帧 benchmark？
3. 先重建再外推与端到端融合相比，在强回波区域哪个更稳？

- **雷达数据证据**: MDPI PDF 实验章节说明模型在真实 radar echo datasets 上评估，包括 Shijiazhuang radar echo dataset 和 Nanjing radar echo dataset；摘要也说明使用石家庄和南京的实际雷达回波数据。

**摘要**

论文提出 STDGAN，用于提升 radar echo extrapolation 中局地天气形态和未来回波图清晰度。作者认为已有方法对雷达回波的局地自然特征利用不足，容易只粗略提取整体回波特征。STDGAN 通过 spatiotemporal difference module 显式提取相邻帧局地变化，再用 GAN 框架生成未来雷达回波图。实验在石家庄和南京两个真实雷达回波数据集上进行。

**方法概述**

模型生成器以历史雷达回波序列为输入，结合循环单元和时空差分模块。差分模块捕捉相邻帧中局部快速变化区域，帮助模型关注回波移动、旋转、增强和消散；GAN 判别器通过多尺度 inception 结构判断生成回波是否接近真实雷达分布。评估指标包括 MSE、PSNR、SSIM、CC 和基于 Z-R 关系转换后的 CSI。

**主要贡献**

1. 将时空差分特征显式引入 radar echo extrapolation。
2. 使用 GAN 框架缓解未来回波图模糊问题。
3. 在石家庄业务雷达数据和南京公开双偏振雷达数据上验证。
4. 同时使用图像质量指标与降水阈值 CSI 评价预测效果。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接用历史雷达回波预测未来雷达回波，并通过 Z-R 关系把像素转换为降雨阈值计算 CSI。

**值得关注的原因**

STDGAN 提供了“差分特征 + GAN”的早期路线，可与后续 FreCast 的频域残差、RaDiT 的 differential attention、MissPred 的差分分支放在一起比较：这些方法都试图显式刻画回波变化而不是只依赖隐状态。

**可能局限**

数据不属于 CIKM、ShangHai、SEVIR 或 MetNet；GAN 生成清晰图像可能并不总对应位置准确；石家庄数据公开性有限，复现主要依赖南京公开数据集。

**后续讨论问题**

1. 差分模块对快速增强/减弱回波的收益是否高于对平移回波的收益？
2. STDGAN 的差分思想能否替换成物理约束的 growth-decay field？
3. 在南京数据上与 DWL、NJU-CPOL 系列方法是否可做统一比较？

### 7. Weather Radar Echo Extrapolation with Dynamic Weight Loss

- **链接**: https://doi.org/10.3390/rs15123138
- **PDF**: https://mdpi-res.com/d_attachment/remotesensing/remotesensing-15-03138/article_deploy/remotesensing-15-03138.pdf
- **来源**: Crossref / MDPI Remote Sensing / MDPI PDF
- **发布日期/版本日期**: Published 2023-06-15；Crossref indexed 2026-08-25 UTC
- **作者**: Yonghong Zhang; Sutong Geng; Wei Tian; Guangyi Ma; Huajun Zhao; Donglin Xie; Huanyu Lu; Kenny Thiam Choy Lim Kam Sian
- **机构/会议/期刊**: Remote Sensing, 15(12), 3138
- **DOI / arXiv ID**: 10.3390/rs15123138
- **关键词标签**: dynamic weight loss; DWL; NJU-CPOL; ConvLSTM; ConvGRU; PredRNN; PredRNN++; strong echo
- **研究方向**: ConvLSTM / recurrent models；Physics-informed / physical constraints；Radar echo extrapolation；Radar reflectivity
- **使用的数据集**: Nanjing University C-band Polarimetric weather radar (NJU-CPOL), 2014-2019, 268 precipitation events, 256 km x 256 km, 6 min interval
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI PDF 摘要和数据章节说明实验使用 NJU-CPOL C-band dual polarimetric weather radar data，预测 radar reflectivity；数据时间跨度为 2014-2019 年，包含 268 个降水事件。

**摘要**

论文不提出新主干，而是从损失函数角度处理雷达回波外推中的误差累积和强回波低估。作者提出 Dynamic Weight Loss (DWL)，根据模型预测结果自适应调整不同 lead time 和不同强度区域的权重，并加入 SSIM 项以改善图像结构质量。实验在 NJU-CPOL 双偏振雷达数据上，把 DWL 应用于 ConvLSTM、ConvGRU、PredRNN 和 PredRNN++。

**方法概述**

DWL 在加权损失中加入模型自调整动态权重，使后续帧和高反射率区域获得更高惩罚，避免所有预测帧使用同一误差权重导致长时效回波持续变弱。SSIM loss 用于增强空间结构和边界细节。该设计不依赖特定 backbone，可作为 loss plug-in 接入多种 ConvRNN 序列预测模型。

**主要贡献**

1. 从损失函数层面处理 radar echo extrapolation 的强度衰减和误差累积。
2. 在 ConvLSTM、ConvGRU、PredRNN、PredRNN++ 四类模型上验证可迁移性。
3. 使用 NJU-CPOL 268 个降水事件的双偏振天气雷达数据。
4. 对高反射率强回波区域赋予更高关注，贴合强降水预警需求。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务是预测未来 radar reflectivity 图像，评估对象是 NJU-CPOL 雷达回波外推结果，目标直接服务 radar-based precipitation nowcasting。

**值得关注的原因**

在大量新论文通过更大 backbone 或生成模型提升清晰度时，DWL 代表低侵入式训练目标改进路线。它可能更容易加入现有 ConvRNN、U-Net、Transformer 或 diffusion denoiser 训练中。

**可能局限**

损失函数改进是否能独立解决回波位置误差仍不确定；只在 NJU-CPOL 上验证，没有 CIKM、Shanghai Radar、SEVIR 或 MetNet；对概率预报和不确定性没有直接建模。

**后续讨论问题**

1. DWL 能否直接叠加到 RaDiT、FreCast 或 RadarDiff 的训练目标中？
2. 动态权重是否会牺牲弱降水区域的校准表现？
3. DWL 与 focal loss、balanced loss、frequency-aware loss 在强回波阈值上如何比较？

- **链接**: https://doi.org/10.3390/s24154895

- **机构/会议/期刊**: Sensors, 24(15), 4895
- **DOI / arXiv ID**: 10.3390/s24154895

**摘要**

论文面向强对流降水临近预报，讨论单一水平反射率 ZH 输入在强回波演变和模糊问题上的不足。作者提出将双偏振雷达变量 ZH、ZDR、KDP 输入生成对抗网络，并设计两阶段 adversarial loss 和 SSIM loss，以改善强对流降水结构预测。实验使用 NJU_CPOL_update2308 数据集，这是华为杯数学建模竞赛强对流降水临近预报题目的双偏振雷达网格数据。

**方法概述**

模型以多变量双偏振雷达序列作为输入，利用生成器预测未来强对流降水相关雷达场，并通过判别器约束生成结果的空间真实性。相比只输入 ZH，加入 ZDR 和 KDP 有助于表达粒子形态、差分相位和降水微物理信息；SSIM loss 关注图像结构，two-stage adversarial loss 用于缓解模糊和平均化预测。

**主要贡献**

1. 将 ZH、ZDR、KDP 等双偏振变量联合用于强对流降水临近预报。
2. 使用 GAN 与两阶段 adversarial loss 改善强回波结构和图像清晰度。
3. 在 NJU_CPOL_update2308 竞赛数据上验证，数据为 6 min 间隔 256 x 256 km 雷达网格序列。
4. 强调多偏振变量对强对流 nowcasting 的补充价值。

**与基于雷达回波的降水临近预报的关系**

相关性高。输入数据是双偏振天气雷达变量网格序列，任务是强对流降水临近预报，属于多变量 radar-based precipitation nowcasting。

**值得关注的原因**

它与 PCFNet、DWL、NJU-CPOL 系列论文共同构成“多偏振雷达变量如何提升强回波/强降水预测”的重要线索，也适合与单变量 SEVIR VIL、Shanghai Radar echo map 方法对比。

**可能局限**

NJU_CPOL_update2308 需要作者请求或竞赛渠道获取，公开复现条件有限；论文主要聚焦强对流场景，普通层状降水或跨地区泛化仍需验证；GAN 训练可能带来稳定性和校准问题。
