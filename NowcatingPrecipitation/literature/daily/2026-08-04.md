### 1. DB-RNN: An RNN for Precipitation Nowcasting Deblurring

- **链接**: https://doi.org/10.1109/JSTARS.2024.3365612
- **PDF**: ResearchGate 作者版本页面提供全文预览：https://www.researchgate.net/publication/378192680_DB-RNN_A_RNN_for_Precipitation_Nowcasting_Deblurring
- **来源**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing / Crossref / Harbin Institute of Technology publication page / ResearchGate 作者版本
- **发布日期/版本日期**: 2024-01；Crossref indexed 2026-08-03
- **作者**: Zhifeng Ma; Hao Zhang; Jie Liu
- **机构/会议/期刊**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing, 17, 5026-5041
- **DOI / arXiv ID**: 10.1109/JSTARS.2024.3365612
- **关键词标签**: DB-RNN; MS-RNN; ConvRNN; deblurring; adversarial loss; gradient loss; radar video prediction; HKO-7; DWD-12
- **研究方向**: ConvLSTM / recurrent models；GAN / adversarial models；Radar echo extrapolation；Precipitation nowcasting deblurring
- **使用的数据集**: HKO-7；DWD-12
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ResearchGate 作者版本摘要明确说明实验使用 HKO-7 与 DWD-12 两个大型雷达数据集，任务被表述为 radar video prediction / precipitation nowcasting；HIT 页面关键词也包含 radar video prediction。

**摘要**

论文聚焦 RNN 类降水临近预报模型在长时效递归预测中常见的模糊化问题。作者认为模糊主要来自两类因素：均值型损失会鼓励模型输出未来状态的平均结果，递归预测结构又会逐步累积误差。DB-RNN 在原有 MS-RNN 预测网络后串联一个额外的去模糊网络，并加入 adversarial loss 与 gradient loss 来约束图像清晰度。实验在 HKO-7 与 DWD-12 雷达数据集上进行，报告预测帧比 MS-RNN 及多种 ConvRNN 基线更清晰、误差累积更慢。

**方法概述**

DB-RNN 由两个级联的 MS-RNN 组成：前半部分负责按历史雷达视频帧预测未来帧，后半部分对当前预测帧去模糊，并通过递归方式让后续帧逐步受益。训练中除常规重建损失外，引入 gradient difference loss 与 adversarial loss，强化边缘、强回波结构和局地梯度。框架兼容 ConvLSTM、TrajGRU、PredRNN、PredRNN++、MIM、MotionRNN、PrecipLSTM 等 RNN 主干，可作为通用去模糊增强层。

**主要贡献**

1. 将视频去模糊思想系统引入 RNN 雷达降水临近预报，针对均值损失和递归误差导致的预测模糊进行建模。
2. 提出预测网络加去模糊网络的级联 DB-RNN 结构，并支持多种 ConvRNN 主干替换。
3. 在 HKO-7 与 DWD-12 两个雷达数据集上验证，覆盖公开雷达视频预测基准。
4. 同时使用 adversarial loss 和 gradient loss，强调强回波边界与局地结构的清晰度。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接把 precipitation nowcasting 表述为 radar video prediction，并在 HKO-7 与 DWD-12 雷达数据集上进行多步外推实验。它适合纳入“RNN 误差累积 / 模糊化修正”方向，与 PredRNN、MIM、PrecipLSTM、MS-RNN 等模型对比。

**值得关注的原因**

很多新模型通过换 backbone 提升指标，而 DB-RNN 直接处理雷达预测帧变模糊这一长期问题。对需要保留强回波边界、窄雨带和局地强降水结构的业务 nowcasting，它提供了一个可插拔的后接式增强思路。

**可能局限**

论文是 2024 年正式发表、2026-08-03 才被 Crossref 重新索引的旧文献；不命中 CIKM、ShangHai、SEVIR 或 MetNet。去模糊和对抗训练可能提升视觉结构，但仍需要关注概率校准、强降水阈值下的 FAR / POD 权衡，以及额外推理成本。

**后续讨论问题**

1. DB-RNN 的清晰度提升是否稳定转化为高阈值 CSI / HSS 改善，而不只是视觉锐化？
2. 去模糊网络是否会在快速生消的对流单体上引入伪结构或过度锐化？
3. 该框架能否迁移到 SEVIR、CIKM 或 Shanghai-Radar，并与扩散 / flow matching 后处理结合？

### 2. STUNNER: Radar Echo Extrapolation Model Based on Spatiotemporal Fusion Neural Network

- **链接**: https://doi.org/10.1109/TGRS.2023.3268187
- **PDF**: 无稳定开放 PDF；IEEE Xplore 页面需访问权限，ResearchGate 仅提供摘要页面
- **来源**: IEEE Transactions on Geoscience and Remote Sensing / Crossref / ResearchGate 摘要页
- **发布日期/版本日期**: 2023-01；Crossref indexed 2026-08-03
- **作者**: Wei Fang; Lin Pang; Victor S. Sheng; Qiguang Wang
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing, 61, 1-14
- **DOI / arXiv ID**: 10.1109/TGRS.2023.3268187
- **关键词标签**: STUNNER; spatiotemporal fusion neural network; temporal differencing network; spatiotemporal trajectory network; radar echo sequence; radar echo extrapolation
- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；Radar echo extrapolation；Spatiotemporal fusion
- **使用的数据集**: 两个公开雷达回波数据集（可访问摘要未披露具体名称）
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ResearchGate 摘要说明论文面向基于深度学习的 radar echo extrapolation，使用 radar echo sequence data，并在两个公开数据集上比较 STUNNER 与五个模型。

**摘要**

STUNNER 针对雷达回波序列的时空相关性、非刚性运动和非平稳演变，提出一个时空融合神经网络。核心思想是把时间差分建模与轨迹式空间运动建模分开处理，再通过跨网络嵌入进行融合。论文报告 STUNNER 在雷达回波外推任务上相对五个对比模型取得更好结果。

**方法概述**

模型采用双流时空融合策略。Temporal Differencing Network 通过高阶差分表征雷达序列的非平稳运动趋势；Spatiotemporal Trajectory Network 则改造 spatiotemporal LSTM 中的卷积算子，用于捕捉雷达图像中的瞬态变化。两个分支通过 cross-network embedding 交互，使模型同时保留较稳定的时序演变和短时局地变化。

**主要贡献**

1. 提出 STUNNER 时空融合网络，将雷达序列的时间差分特征和轨迹式空间变化分流建模。
2. 将 temporal differencing 与 spatiotemporal trajectory 表征结合，以处理雷达回波的非平稳运动和非刚性变形。
3. 在两个公开数据集上与五个模型比较，作为早期 TGRS 雷达回波深度学习外推模型的一个重要基线。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务、输入数据和模型设计均围绕 radar echo extrapolation，可作为 RNN / LSTM 系列中“时间差分 + 轨迹建模”路线的代表性文献。

**值得关注的原因**

近期许多论文仍引用 STUNNER 作为雷达回波外推基线。本轮 Crossref 在 2026-08-03 重新索引该 DOI，且本地索引此前未收录，因此补入可以改善后续去重和谱系整理。

**可能局限**

可访问页面没有披露两个公开数据集的具体名称，也没有开放完整实验表；后续若能访问 IEEE 全文，应补充数据集、输入输出帧数、阈值指标和与 HKO-7 / DWD-12 / CIKM 等基准的关系。论文不命中本项目重点公开数据集。

### 3. REE-TTT: Highly Adaptive Radar Echo Extrapolation Based on Test-Time Training

- **链接**: https://arxiv.org/abs/2601.01605
- **PDF**: https://arxiv.org/pdf/2601.01605
- **来源**: arXiv / arXiv HTML
- **发布日期/版本日期**: arXiv v1 submitted 2026-01-04；本轮近 7 天 arXiv 站内检索新发现
- **作者**: Xin Di; Xinglin Piao; Fei Wang; Guodong Jing; Yong Zhang
- **机构/会议/期刊**: arXiv, cs.LG / cs.AI
- **DOI / arXiv ID**: 10.48550/arXiv.2601.01605 / arXiv:2601.01605
- **关键词标签**: REE-TTT; test-time training; spatiotemporal TTT; radar echo extrapolation; composite reflectivity; Beijing radar; Hangzhou radar; cross-regional generalization
- **研究方向**: CNN encoder-decoder；Transformer / attention models；Radar echo extrapolation；Test-time adaptation；Cross-regional generalization
- **使用的数据集**: Beijing composite reflectivity dataset；Hangzhou composite reflectivity dataset
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: arXiv HTML 实验部分说明北京数据集来自 Beijing Meteorological Station (Z9010) 的 raw radar base data / composite reflectivity，杭州数据集来自 Hangzhou Meteorological Station (Z9571) 的 composite reflectivity data。

**摘要**

论文关注深度学习雷达回波外推在跨区域部署和极端降水分布漂移下的泛化问题。作者提出 REE-TTT，将 test-time training 引入 radar echo extrapolation，在推理阶段根据当前测试雷达序列进行自监督适应。实验使用北京组合反射率数据训练，并在杭州强降水场景中进行零样本和少量目标域微调评估，报告 REE-TTT 在 CSI、ETS 等指标上具有更好的跨区域适应性。

**方法概述**

REE-TTT 采用类似 SimVP 的 encoder-translator-decoder 框架，在 spatiotemporal translator 中堆叠 ST-TTT block。ST-TTT 将标准 TTT 层中的线性投影替换为任务相关的时序注意力与运动增强注意力，通过自监督重建任务在测试时更新内部参数。损失函数方面，论文在加权 MAE 外加入高频聚焦的频域损失，以增强强回波和局地结构。跨区域实验中，模型先在北京雷达数据训练，再直接测试到杭州强降水样本，另设三阶段微调策略验证少量目标域数据下的扩展性。

**主要贡献**

1. 将 test-time training 引入 radar echo extrapolation，用推理阶段自监督更新缓解区域分布漂移。
2. 设计 ST-TTT block，用 temporal attention 与 motion-enhanced attention 构造更贴近雷达序列的自监督视图。
3. 在北京与杭州两个组合反射率雷达数据集上进行跨区域强降水泛化实验。
4. 结合频域结构损失，尝试提升强回波和高频局地结构保持能力。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接定义 radar echo extrapolation 任务，输入输出为雷达回波 / 组合反射率序列，并面向短时降水 nowcasting 的区域迁移问题。它适合纳入“跨区域泛化 / test-time adaptation / 极端强降水鲁棒性”方向。

**值得关注的原因**

多数公开基准论文假设训练与测试分布较一致，而业务雷达部署常遇到区域差异、历史样本不足和极端事件长尾。REE-TTT 把测试时自适应用于雷达外推，和域泛化、在线校正、少样本区域部署等问题直接相关。

**可能局限**

官方 arXiv 版本日期不是本周，属于本轮检索中新发现的本地未收录论文；仍是预印本。实验空间分辨率统一下采样到 64 x 64，可能低估高分辨率强回波边界问题；论文自身也指出上采样可能带来局地强降水核心的平均化和模糊。未命中 CIKM、ShangHai、SEVIR 或 MetNet。

**后续讨论问题**

1. TTT 在业务实时 nowcasting 中的推理延迟和稳定性是否可接受？
2. ST-TTT 的自监督重建任务是否会在观测噪声或雷达缺测场景中过拟合当前输入？
3. 能否把 REE-TTT 的区域自适应机制迁移到 SEVIR、CIKM 或 Shanghai-Radar 这类公开视频预测基准？
