### 1. Rainformer: Features Extraction Balanced Network for Radar-Based Precipitation Nowcasting

- **链接**: https://doi.org/10.1109/LGRS.2022.3162882
- **PDF**: 未直接获取；本次使用 Crossref 与 OpenAlex 元数据

- **发布日期/版本日期**: 2022；Crossref indexed 2026-07-04
- **作者**: Cong Bai; Feng Sun; Jinglin Zhang; Yi Song; Shengyong Chen
- **机构/会议/期刊**: IEEE Geoscience and Remote Sensing Letters
- **DOI / arXiv ID**: 10.1109/LGRS.2022.3162882
- **关键词标签**: Rainformer; radar-based precipitation nowcasting; window attention; global features; gate fusion
- **研究方向**: Transformer / attention models; Radar echo extrapolation; Precipitation nowcasting
- **使用的数据集**: 官方元数据未暴露具体数据集名称；任务定义为 radar-based precipitation nowcasting
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref/OpenAlex 官方标题明确为 radar-based precipitation nowcasting；OpenAlex 摘要说明 Rainformer 用于降水临近预报，并在高强度降雨预测上与多个基线比较。

**摘要**

论文针对强降水临近预报中局部卷积特征不足、全局结构捕获不稳的问题，提出 Rainformer。作者认为简单加深卷积网络只能扩大感受野，容易得到伪全局特征，对暴雨等高强度降水不敏感。

**方法概述**

Rainformer 结合 global features extraction unit 与 gate fusion unit。前者使用 window-based multi-head self-attention 学习更大范围的降水结构，后者平衡局部卷积特征与全局注意力特征，以改善强降水区域的空间表达。

**主要贡献**

1. 将窗口自注意力引入 radar-based precipitation nowcasting 的特征提取。
2. 用 gate fusion unit 融合局部和全局降水特征。
3. 强调高强度降雨预测能力，而不仅是平均误差。

**与基于雷达回波的降水临近预报的关系**

高度相关。论文题名和任务均指向 radar-based precipitation nowcasting，可作为 Earthformer、SwinNowcast、SFTformer 等注意力模型的早期对照。

**值得关注的原因**

Rainformer 是后续许多雷达临近预报论文常用的确定性注意力基线之一，补入索引后便于梳理 Transformer/attention 路线的演进。

**可能局限**

本次可访问元数据未暴露具体数据集名称、阈值设置和完整实验表；需要后续核验全文中的数据划分和与 HKO-7、CIKM、SEVIR 等公共基准的关系。

**后续讨论问题**

1. Rainformer 的窗口注意力是否主要改善强回波边界，还是改善整体平移？
2. gate fusion 的收益是否在不同雨强阈值上稳定？
3. 与 SFTformer 的时空解耦相比，Rainformer 的全局特征更适合作为轻量基线还是高精度模型？

### 2. SFTformer: A Spatial-Frequency-Temporal Correlation-Decoupling Transformer for Radar Echo Extrapolation

- **链接**: https://doi.org/10.1109/TGRS.2024.3367857
- **PDF**: https://arxiv.org/pdf/2402.18044
- **来源**: IEEE Transactions on Geoscience and Remote Sensing / Crossref / arXiv / OpenAlex
- **发布日期/版本日期**: arXiv submitted 2024-02-28；Crossref indexed 2026-07-07
- **作者**: Liangyu Xu; Wanxuan Lu; Hongfeng Yu; Fanglong Yao; Xian Sun; Kun Fu
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing
- **DOI / arXiv ID**: 10.1109/TGRS.2024.3367857 / arXiv:2402.18044
- **关键词标签**: SFTformer; radar echo extrapolation; spatial-frequency-temporal decoupling; HKO-7; ChinaNorth-2021
- **研究方向**: Transformer / attention models; Radar echo extrapolation; Precipitation nowcasting
- **使用的数据集**: HKO-7; ChinaNorth-2021
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: arXiv 摘要说明该任务是从历史 weather radar echoes 外推未来回波，并在 HKO-7 与 ChinaNorth-2021 上评估 1h、2h、3h 降水临近预报。

**摘要**

论文认为雷达回波的空间形态和时间演变既有关联也有独立性，已有模型把二者耦合到同一特征空间中，容易产生相互干扰。SFTformer 通过空间、频率、时间维度的相关性解耦，改进长时效雷达回波外推。

**方法概述**

模型堆叠 SFT-Blocks，同时挖掘回波单元的时空动态相关性，并把时间建模与空间形态细化拆开处理。训练上还引入历史回波序列重建与未来回波预测的联合范式，模拟预报员回看历史演变再外推的流程。

**主要贡献**

1. 提出 spatial-frequency-temporal correlation-decoupling Transformer。
2. 将历史序列重建作为辅助训练任务，增强回波演变理解。
3. 在 HKO-7 和 ChinaNorth-2021 上覆盖短、中、长时效实验。

**与基于雷达回波的降水临近预报的关系**

高度相关。输入和预测目标均为天气雷达回波，是典型雷达回波外推任务。

**值得关注的原因**

SFTformer 为“时空耦合是否会限制雷达外推”提供了明确的架构假设，可与 Rainformer、Earthformer、SwinKAN、FlashBack Memory 等模型比较。

**可能局限**

HKO-7 与 ChinaNorth-2021 不属于本轮重点公开数据集；跨气候区、跨雷达体制和极端强回波泛化仍需进一步验证。

**后续讨论问题**

1. 频率分支对强回波锐度的贡献能否通过谱能量指标量化？
2. 历史重建任务是否会牺牲未来预测的极端事件敏感性？
3. SFTformer 在 SEVIR 或 CIKM 上是否仍优于更简单的注意力模型？

- **研究方向**: CNN encoder-decoder; Radar echo extrapolation; Convective storm nowcasting

- **雷达数据证据**: OpenAlex 摘要说明输入为 five consecutive radar images，输出为 predicted radar reflectivity image，并与 TREC 和 TrajGRU 对比。

**摘要**

论文把对流降水临近预报转化为图像到图像翻译问题，验证简单 CNN/U-Net 架构在雷达反射率图像预测中的有效性。作者强调雷达图像是 nowcasting 中最重要的数据源之一。

**方法概述**

模型输入 5 帧连续雷达图像，输出下一时刻雷达反射率图像。U-Net 使用下采样、上采样和跳连结构进行空间编码与重建，并与传统 TREC 和循环式 TrajGRU 对比。

**主要贡献**

1. 证明简单 U-Net 可以在雷达反射率 nowcasting 中接近 RNN 类模型 TrajGRU。
2. 用图像翻译形式降低雷达外推任务建模复杂度。
3. 为后续轻量 CNN encoder-decoder 雷达 nowcasting 提供基础对照。

**与基于雷达回波的降水临近预报的关系**

高度相关。模型直接输入雷达图像并预测雷达反射率图像，是雷达回波/反射率临近预报基线。

**值得关注的原因**

U-Net 是许多后续雷达 nowcasting 模型的壳层或比较基线；补入该条有助于梳理“简单 CNN 是否足够”的早期证据。

**可能局限**

摘要未显示数据集名称、雷达分辨率和强降水阈值结果；U-Net 缺少显式时间记忆，长时效可能更依赖递推策略。

**后续讨论问题**

1. U-Net 的性能接近 TrajGRU 是来自数据集时效较短，还是来自空间结构足够强？
2. 如果输入帧数增加，纯 CNN 是否仍能保持稳定？
3. 该模型能否作为评估复杂模型真实收益的最低强基线？
