### 1. Two-Stage UA-GAN for Precipitation Nowcasting

- **链接**: https://doi.org/10.3390/rs14235948
- **PDF**: https://www.mdpi.com/2072-4292/14/23/5948/pdf
- **来源**: Crossref / MDPI Remote Sensing / MDPI PDF
- **发布日期/版本日期**: Published 2022-11-24；Crossref indexed 2026-08-18 UTC
- **作者**: Liujia Xu; Dan Niu; Tianbao Zhang; Pengju Chen; Xunlai Chen; Yinghao Li
- **机构/会议/期刊**: Remote Sensing, 14(23), 5948
- **DOI / arXiv ID**: 10.3390/rs14235948
- **关键词标签**: Two-stage UA-GAN; TrajGRU; U-Net GAN; spatiotemporal attention; HKO-7; radar echo map extrapolation
- **研究方向**: GAN / adversarial models；ConvLSTM / recurrent models；Radar echo extrapolation；Precipitation nowcasting
- **使用的数据集**: HKO-7 public benchmark radar echo dataset, Hong Kong Observatory, 2009-2015
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: MDPI PDF 的数据集章节说明论文使用 HKO-7 公开雷达回波图数据集，包含香港及周边地区 2009-2015 年 7 年雷达回波数据；实验用过去 10 帧雷达回波图预测未来 10 帧。

**摘要**

论文面向短时降雨预报中的雷达回波图外推问题，认为现有模型常在图像细节和降水精度上同时不足，容易得到模糊的未来回波。作者提出 Two-stage UA-GAN：第一阶段用 TrajGRU 做预预测，学习雨区的时空移动；第二阶段用带 U-Net 结构、时空注意力和深度残差注意力模块的 GAN 对第一阶段结果进行细化。实验在 HKO-7 雷达回波公开数据集上进行，报告相较 ROVER 光流方法和 ConvLSTM、ConvGRU、TrajGRU、PredRNN++ 等深度模型，在图像质量与降水检验指标上都有改进。

**方法概述**

模型把雷达回波外推拆成“粗预测 + 细化”两步。TrajGRU 先生成未来 10 帧回波图，提供较稳定的时空演变先验；随后 UA-GAN 的生成器接收第一阶段预测帧和近期真实回波帧作为多通道输入，通过 U-Net 编解码和注意力模块恢复小尺度强回波细节。损失函数同时考虑像素重建、强回波加权和对抗学习，目标是在保持降水位置的同时减少 GAN 类模型常见的不稳定。

**主要贡献**

1. 将 TrajGRU 预预测和 GAN 细化明确串成两阶段流程，减少单一模型同时承担运动外推和细节恢复的压力。
2. 在生成器中加入时空注意力和深度残差注意力模块，强化关键回波区域和小尺度结构。
3. 使用 HKO-7 公开雷达回波数据集，便于与早期 TrajGRU / ConvLSTM / PredRNN++ 路线比较。
4. 同时报告图像质量指标和降水准确率指标，能观察“更清晰”是否真的对应更有用的降水预报。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务就是基于历史雷达回波图预测未来雷达回波图，再由回波强度转换降水强度；输入、输出、评估都围绕雷达 echo map extrapolation 展开。

**值得关注的原因**

虽然论文发表较早，但本轮 Crossref 近 7 天重新索引后本地未收录。它提供了一个“recurrent 粗预测 + GAN 细节修复”的典型早期基线，可与后续 DiffCast、PreDiff、FreCast、QWRF-Net、RadarDiff 等扩散 / flow 生成式方法对比，尤其适合讨论强回波细节恢复与位置误差之间的权衡。

**可能局限**

HKO-7 与当前重点数据集 CIKM、ShangHai / Shanghai Radar、SEVIR、MetNet 不重合；论文主要关注图像细节和常规阈值检验，跨区域泛化、极端强降水阈值、实时推理成本和与现代扩散模型的统一协议比较仍需后续复核。

**后续讨论问题**

1. 第二阶段 GAN 细化带来的视觉改善，是否在高 dBZ 阈值 CSI / FAR 上同样稳定？
2. 如果把 HKO-7 换成 SEVIR 或 Shanghai Radar，两阶段流程是否仍优于直接多帧预测？
3. 对比现代扩散模型时，UA-GAN 的推理速度优势能否抵消生成质量差距？

### 2. A Hybrid Approach to Physical and Deep Learning Models for Radar-Based Precipitation Nowcasting

- **链接**: https://doi.org/10.1109/TGRS.2025.3560454
- **PDF**: https://www.ahrl.re.kr/img_up/shop_pds/adm014m/contents/myboard/myboard3/131.ahybridapproachtophysicalanddeeplearn.pdf
- **来源**: Crossref / IEEE Transactions on Geoscience and Remote Sensing / author-lab PDF
- **发布日期/版本日期**: Published 2025；Crossref indexed 2026-08-18 UTC；author-lab PDF metadata 2025-04-02
- **作者**: Ho-Jun Kim; Seong-Sim Yoon; Yeong Hyeon Gu; Sung Hoon Kim; Young-Don Choi; Hyun-Han Kwon
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing, 63, 1-16
- **DOI / arXiv ID**: 10.1109/TGRS.2025.3560454
- **关键词标签**: radar-based precipitation nowcasting; PySTEPS; RainNet; LightGBM; model blending; Korean radar rainfall
- **研究方向**: Operational nowcasting systems；CNN encoder-decoder；Radar-derived precipitation；Radar-based QPF blending
- **使用的数据集**: South Korea Ministry of Environment composite radar rainfall data, 2016-2021, 1 km spatial resolution, 10 min temporal resolution
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 可访问 PDF 的数据章节说明，研究使用韩国环境部 composite radar rainfall data，收集 2016-2021 年长期雷达生成的合成降雨资料，作为 PySTEPS 和 RainNet nowcasting 模型输入。

**摘要**

论文提出一种混合框架，用 LightGBM 将物理外推模型 PySTEPS 与深度学习模型 RainNet 的雷达降水预报进行融合。作者指出，PySTEPS 更擅长保持降水强度和运动结构，RainNet / U-Net 类模型更擅长学习雷达降水图像中的空间覆盖模式，但会低估较强降雨。实验使用韩国 2016-2021 年合成雷达降水数据，比较 10-90 min lead time 下 LightGBM、RainNet 和 PySTEPS 的 CSI、POD、FAR、RMSE 和 FSS。结果显示，融合模型在多个阈值和 lead time 上显著优于单独模型。

**方法概述**

流程分为三步。首先，PySTEPS 以半拉格朗日和谱分解方式生成基于雷达降水场的物理外推预报。其次，RainNet 使用 U-Net / CNN 编解码结构学习连续雷达降雨图像到未来降雨图像的映射。最后，LightGBM 将两类预测结果作为输入特征，学习逐格偏差校正和融合关系，从而在空间覆盖与强度保持之间取得更好的平衡。

**主要贡献**

1. 把传统 nowcasting 外推模型和深度学习 nowcasting 模型作为互补预报源，而不是单纯比较优劣。
2. 使用 LightGBM 对 PySTEPS 与 RainNet 输出进行融合，提升 0.1、1、5 mm/h 阈值下最长 90 min 的多项指标。
3. 在 2016-2021 年韩国 composite radar rainfall 数据上做较大时间跨度验证，接近业务雷达降水预报需求。
4. 直接分析 RainNet 低估强降雨、PySTEPS 保持强度但可能空间偏移的互补性。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文题名、摘要和数据章节均明确是 radar-based precipitation nowcasting，输入为合成雷达降雨资料，深度学习模型 RainNet 是融合框架中的核心组成之一。

**值得关注的原因**

很多近期工作试图用单个 Transformer、Mamba、diffusion 或 flow 模型替代传统外推。该文提供另一条更保守的业务路线：保留 PySTEPS 的物理外推优势，用 RainNet 补充空间模式，再用梯度提升模型做融合。这对实际业务系统、低风险部署和后处理型改进很有参考价值。

**可能局限**

模型依赖 PySTEPS、RainNet 和 LightGBM 三段流程，系统复杂度高于端到端模型；论文没有命中 CIKM、ShangHai、SEVIR 或 MetNet，跨公开 benchmark 的可比性有限；融合器在韩国雷达资料上训练，迁移到不同雷达制式、地形和降水气候区时可能需要重新校准。

**后续讨论问题**

1. LightGBM 的增益主要来自强度偏差校正，还是来自对 PySTEPS / RainNet 空间误差的条件选择？
2. 如果把 RainNet 换成现代 SimVP / Earthformer / diffusion backbone，融合策略是否继续有效？
3. 该框架在强降水高阈值下是否会牺牲 FAR，还是能同时提升 CSI 和 POD？

### 3. Assimilation of S-Band Radar Echo Extrapolation Data-Based on the GAN-rcLSTM Model

- **链接**: https://doi.org/10.1029/2024JD043132
- **PDF**: https://onlinelibrary.wiley.com/doi/pdfdirect/10.1029/2024JD043132
- **来源**: Crossref / AGU Journal of Geophysical Research: Atmospheres / OpenAlex
- **发布日期/版本日期**: Published online 2025-08-09；published print 2025-08-16；Crossref indexed 2026-08-17 UTC；OpenAlex updated 2026-08-18
- **作者**: Yujie Cao; Liangchao Geng; Jinzhong Min; Bingying Shi
- **机构/会议/期刊**: Journal of Geophysical Research: Atmospheres, 130(15)
- **DOI / arXiv ID**: 10.1029/2024JD043132
- **关键词标签**: GAN-rcLSTM; S-band radar echo extrapolation; radar echo mosaics; data assimilation; NWP short-term forecast
- **研究方向**: ConvLSTM / recurrent models；GAN / adversarial models；Radar-NWP fusion；Short-term weather radar forecasting
- **使用的数据集**: Guangdong S-band radar echo mosaics at 3 km altitude from seven radars
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref 摘要说明，研究用 GAN-rcLSTM 外推广东 7 部雷达组成的 3 km 高度 S-band radar echo mosaics，并将 WREE 数据同化进 NWP 以改善短时预报。

**摘要**

论文讨论深度学习生成的“未来观测”是否可用于资料同化。作者用 residual convolution LSTM 与 GAN 组合成 GAN-rcLSTM，对广东 7 部 S 波段天气雷达的 3 km 高度回波拼图做外推，生成 weather radar echo extrapolation (WREE) 数据。随后把 WREE 作为未来雷达观测同化到数值天气预报模型中，并与直接同化雷达回波观测进行比较。结果表明，同化 WREE 或雷达回波观测都能降低分析场和预报场的反射率误差，并改善降水位置、强度和 CSI。

**方法概述**

方法分两层：第一层是 GAN-rcLSTM 雷达回波外推模型，负责从历史 S-band 雷达拼图生成未来回波场；第二层是 NWP 资料同化实验，用生成的 WREE 数据作为“未来观测”约束模式短时预报。这样，深度学习不直接输出最终降水预报，而是通过雷达回波外推为物理模式提供高频未来信息。

**主要贡献**

1. 将 GAN-rcLSTM 雷达回波外推结果作为可同化的未来观测，连接深度学习 nowcasting 与 NWP 资料同化。
2. 使用广东 7 部 S-band 雷达拼图，数据源明确且接近业务雷达网络场景。
3. 在分析场、预报场反射率误差和降水 CSI 上评估 WREE 同化效果。
4. 给出 WREE 同化与真实雷达回波观测同化之间的对比，讨论深度学习外推数据作为 proxy observation 的价值。

**与基于雷达回波的降水临近预报的关系**

相关性中到高。论文核心模型是深度学习 radar echo extrapolation，但最终应用是把外推回波同化进 NWP 改善短时预报，而不是端到端 radar-to-radar 或 radar-to-precipitation nowcasting。它对“深度学习雷达外推如何进入业务 NWP 流程”有直接参考价值。

**值得关注的原因**

多数深度学习雷达 nowcasting 论文停留在像素级外推或分类指标比较。该文把外推回波作为资料同化输入，讨论其对物理模式短时预报的实际增益，为 DL nowcasting 与 NWP 融合提供一个可落地路径，可与 RainNet / PySTEPS blending、DGMR ensemble、NowcastNet 业务化等路线形成对照。

**可能局限**

任务重点偏资料同化和 NWP 改善，不是纯深度学习端到端 nowcasting；模型效果依赖雷达外推质量和同化系统配置；未命中 CIKM、ShangHai、SEVIR 或 MetNet，难以直接和公开 benchmark 模型比较。

**后续讨论问题**

1. WREE 同化的增益在多长 lead time 后开始衰减？
2. GAN-rcLSTM 的外推误差会在同化中被模式约束修正，还是会引入系统性偏差？
3. 如果用扩散 / flow / Transformer 外推替代 GAN-rcLSTM，WREE 同化是否会进一步改善强降水位置和强度？
