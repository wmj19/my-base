### 1. RadarDiff: A Conditional Diffusion Model with Time-Aware Context and Mixed Attention for Radar Echo Extrapolation

- **链接**: https://doi.org/10.1109/JSTARS.2026.3722210
- **PDF**: https://www.researchgate.net/publication/412162819_RadarDiff_A_Conditional_Diffusion_Model_with_Time-Aware_Context_and_Mixed_Attention_for_Radar_Echo_Extrapolation
- **来源**: Crossref / IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing / ResearchGate full-text
- **发布日期/版本日期**: Crossref created / deposited / indexed 2026-08-11 UTC；IEEE issue year 2026；ResearchGate full-text page显示 January 2026
- **作者**: Huantong Geng; Xinxin Zeng; Liangchao Geng; Han Zhao; Delong Fang; Xiaoran Zhuang
- **机构/会议/期刊**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing
- **DOI / arXiv ID**: 10.1109/JSTARS.2026.3722210
- **关键词标签**: RadarDiff; conditional diffusion model; radar echo extrapolation; mixed attention; Shanghai radar; generative nowcasting
- **研究方向**: Diffusion / generative models；Radar echo extrapolation；Radar reflectivity；Short-term weather radar forecasting
- **使用的数据集**: Shanghai radar echo dataset
- **重点公开数据集匹配**: ShangHai / Shanghai Radar
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ResearchGate full-text 摘录的实验章节说明实验使用 Shanghai radar echo dataset，该数据集提供 2015-10 至 2018-07 浦东站预处理 composite reflectivity 数据；代码与数据可用性段落给出公开数据 DOI `10.7910/DVN/2GKMQJ`。

**摘要**

论文关注雷达回波外推中确定性模型过度平滑、强对流核心被削弱，以及扩散 / 生成式模型推理成本较高的问题。作者提出 RadarDiff，把雷达回波外推建模为条件扩散过程，并通过时序先验和混合注意力增强强回波区域的预测稳定性。实验在 Shanghai radar echo dataset 上进行，输入过去 5 帧、预测未来 20 帧，对应 30 分钟历史到 2 小时预报；论文报告 RadarDiff 在 CSI、HSS、视觉清晰度和动态一致性上优于确定性基线，同时相较默认设置下的生成式模型降低推理开销。

**方法概述**

RadarDiff 由外部 Causal Context Network 和内部 Temporal Conditional Denoising Network 组成。CCNet 使用 CausalLSTMCell 提取递归时序先验，TCD-Net 通过 Long-Range Temporal Dynamic Interaction Block 建模长程动态，再结合 spatial-channel attention 和 Adaptive Multi-Scale Interaction Block 捕捉强回波的多尺度演变。生成策略采用“block-wise autoregressive and intra-block parallel”，即块间递推、块内并行，以在保持生成质量的同时降低采样延迟。

**主要贡献**

1. 将条件扩散模型用于 radar echo extrapolation，并显式围绕预报精度、图像质量和推理成本三者折中设计。
2. 用 CausalLSTM 时序先验、长程动态交互和空间-通道注意力共同改善强回波稳定性。
3. 通过多尺度交互和块式生成策略缓解扩散模型在业务 nowcasting 中的采样延迟问题。
4. 在 Shanghai Radar 公开数据集上验证，命中本自动化重点公开数据集 ShangHai / Shanghai Radar。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文任务就是从历史 composite reflectivity radar echo 序列外推未来雷达回波，目标服务于 0-2 小时降水临近预报；数据集为上海浦东天气雷达反射率序列，完全满足雷达数据硬性规则。

**值得关注的原因**

近期雷达 nowcasting 的生成式路线包括 DiffCast、RainDiff、QWRF-Net、FreCast、FREUD 等。RadarDiff 的价值在于把扩散模型的清晰度优势和业务场景的低延迟需求放在同一框架中讨论，并在上海公开雷达数据集上给出 2 小时序列外推实验，适合与同样使用 Shanghai Radar 的 ConCast、WaveCastNet、FreCast 和 SDIR 对比。

**可能局限**

当前可见实验证据主要集中在 Shanghai radar echo dataset，尚未看到 SEVIR、CIKM、MeteoNet 或跨区域业务雷达拼图上的同协议验证。输入图像被下采样到 128×128，可能弱化原始 501×501 雷达反射率场中的细尺度边界。虽然论文强调低于默认生成式模型的推理延迟，但扩散采样相对轻量 deterministic backbone 的部署成本仍需进一步评估。

**后续讨论问题**

1. RadarDiff 的 50 步采样在上海业务类数据上是否能进一步减少，而不明显损失高阈值 CSI / HSS？
2. CCNet 的 CausalLSTM 时序先验能否替换为 Mamba 或 Transformer 以降低长序列成本？
3. 与 FreCast、QWRF-Net、RainDiff、WaveCastNet 在 Shanghai Radar 同协议下比较时，主要优势来自扩散目标还是混合注意力结构？
4. 若迁移到 SEVIR VIL 或 CIKM radar echo，强回波清晰度和动态一致性是否仍稳定？

### 2. PstpNet: Dual-Branch Physics-Guided U-Net With Multiscale Spatio-Temporal Disentanglement for Precipitation Nowcasting

- **链接**: https://doi.org/10.1109/JSTARS.2026.3722192
- **PDF**: https://www.researchgate.net/publication/412104753_PstpNet_Dual-Branch_Physics-Guided_U-Net_With_Multiscale_Spatio-Temporal_Disentanglement_for_Precipitation_Nowcasting
- **来源**: Crossref / IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing / ResearchGate full-text
- **发布日期/版本日期**: Crossref created / deposited / indexed 2026-08-10 UTC；IEEE issue year 2026；ResearchGate full-text page显示 January 2026
- **作者**: Kai Xie; Bo Yin; Yue-Ting Sun; Zhaoyan Zhu; Yiyun Guo
- **机构/会议/期刊**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing
- **DOI / arXiv ID**: 10.1109/JSTARS.2026.3722192
- **关键词标签**: PstpNet; physics-guided U-Net; advection-residual decomposition; radar reflectivity; KNMI-NL50; SEVIR; VIL
- **研究方向**: Physics-informed / physical constraints；CNN encoder-decoder；Radar reflectivity；Radar-derived precipitation；Precipitation nowcasting
- **使用的数据集**: KNMI-NL50；SEVIR
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ResearchGate full-text 摘录的任务定义把 precipitation nowcasting 表述为基于历史 radar reflectivity sequences 预测未来序列；实验章节使用 KNMI-NL50 radar echo maps 和 SEVIR VIL frames；代码与数据可用性段落说明 SEVIR 通过 AWS Open Data Registry 公开。

**摘要**

论文认为降水系统的快速发展、非线性演变和长程时空依赖使深度学习临近预报仍存在动态刻画和可解释性不足的问题。PstpNet 受连续性方程启发，把未来降水演变拆分为平流传输和非守恒强度变化两个过程：motion branch 建模潜在 echo-advection field，residual branch 建模局地增长、衰减和强度残差。实验在 KNMI-NL50 和 SEVIR 上进行，报告 PstpNet 在多个阈值指标上达到最佳或接近最佳表现，尤其在 KNMI-NL50 的 10 mm/h 和 SEVIR 的 VIL 181 高阈值上保持较强检测能力。

**方法概述**

PstpNet 是一个双分支 physics-guided U-Net。Spatial Multi-Scale Module 用于提取多尺度空间结构，Temporal Evolution Module 把历史时序演变信息注入物理分解过程，Physics-Guided Gated Fusion 结合 optical-flow magnitude 这类运动先验对平流分支和强度残差分支进行自适应融合。训练损失包含 weighted MSE、Tversky loss 和 boundary loss，分别约束全场强度、稀疏强降水区域和边界清晰度。实验协议为两个数据集统一使用 12 帧输入、12 帧预测，对应 1 小时预报。

**主要贡献**

1. 用连续性方程启发的 advection-residual decomposition 将运动传输和非守恒强度变化分给两个确定性预测路径。
2. 通过多尺度时空解耦和物理引导门控融合增强强降水区域与长时效预测稳定性。
3. 在 KNMI-NL50 和 SEVIR 上验证，并对 learned motion field 与 optical-flow proxy 的方向一致性做解释性分析。
4. 命中本自动化重点公开数据集 SEVIR，便于与 EarthFormer、SimVP、SimCast、DiffCast、PreDiff、FREUD 等 SEVIR 系列工作比较。

**与基于雷达回波的降水临近预报的关系**

相关性高。PstpNet 的任务定义明确是基于历史 radar reflectivity sequences 预测未来序列，KNMI-NL50 是天气雷达回波 / 降水雷达数据，SEVIR VIL 是 NEXRAD radar mosaics 派生变量。该工作适合纳入“物理约束 / 平流残差分解 / 强降水阈值优化”分支。

**值得关注的原因**

与纯扩散或纯 Transformer 路线相比，PstpNet 更强调可解释的物理功能分工：把位移和平流交给 motion branch，把局地增长和衰减交给 residual branch。这个设计可与 NowcastNet、PDDN、LUPIN、MoCast 等物理引导 nowcasting 方法一起讨论，也能帮助分析强回波漏报究竟来自位移错误还是强度演变错误。

**可能局限**

PstpNet 是确定性模型，未直接给出概率不确定性或集合预报。SEVIR 预处理后的样本量较小，且未看到 CIKM、ShangHai / Shanghai Radar 或 MetNet 实验；跨区域泛化仍需进一步验证。代码可用性段落说明源码将在正式发表后公开，当前复现条件仍有限；KNMI-NL50 processed dataset 需要向 SmaAt-UNet 原作者请求访问。

**后续讨论问题**

1. PstpNet 的 motion branch 是否能在不依赖 optical-flow proxy 的情况下稳定学习可解释的平流方向？
2. Advection-residual 分解能否作为插件接入 SimVP、EarthFormer、FreCast 或 RadarDiff，提高强回波位移和强度的可诊断性？
3. 在 SEVIR 的高 VIL 阈值上，weighted MSE、Tversky loss 和 boundary loss 分别贡献多少？
4. 若迁移到 Shanghai Radar 或 CIKM，平流残差分解是否比纯频域、Mamba 或扩散结构更稳定？
