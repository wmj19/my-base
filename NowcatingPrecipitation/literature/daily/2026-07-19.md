### 1. A Margin-Based Decomposition Framework via Intensity Flow Matching for Precipitation Nowcasting

- **链接**: https://doi.org/10.1109/TGRS.2026.3704556
- **PDF**: 无开放 PDF
- **来源**: IEEE Transactions on Geoscience and Remote Sensing / Harbin Institute of Technology Pure / Crossref
- **发布日期/版本日期**: IEEE TGRS 2026；HIT Pure 页面在 2026-07-19 七日检索中显示为今日新抓取结果；Crossref 2026-07-06 索引
- **作者**: Wenzhi Feng; Xutao Li; Kenghong Lin; Yangjinxi Ge; Zhe Wu; Yunming Ye
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing, 64, Article 4109112
- **DOI / arXiv ID**: 10.1109/TGRS.2026.3704556
- **关键词标签**: margin-based decomposition; intensity flow matching; advection-intensity decomposition; flow matching; SEVIR; Shanghai Radar; CIKM
- **研究方向**: Diffusion / generative models；Physics-informed / physical constraints；雷达回波外推；降水临近预报
- **使用的数据集**: SEVIR；MeteoNet；Shanghai Radar；CIKM
- **重点公开数据集匹配**: SEVIR；ShangHai / Shanghai；CIKM
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: HIT Pure 摘要明确说明该方法在四个公开 radar datasets 上实验，分别为 Storm EVent ImagRy (SEVIR)、MeteoNet、Shanghai Radar 和 CIKM。

**摘要**

论文针对降水系统演变中的高值回波衰减和位置误差问题，提出基于 margin 的分解框架，将降水演变拆解为平流运动和强度变化两部分。该文同时命中 SEVIR、Shanghai Radar 和 CIKM 三个重点公开数据集，是本轮优先级最高的公开基准候选。

**方法概述**

模型用 advection branch 建模整体运动趋势，用 intensity perception network 给出强度相关变化的初始估计，再通过 margin-based decomposition 缓解传统分解方法中分支退化的问题。随后引入 intensity flow matching network，对强度分量进行流匹配式细化，以保持局地细节和高值回波。

**主要贡献**

1. 将降水 nowcasting 中的运动和强度变化显式拆分，避免单一预测分支同时承担平流和增长/消散建模。
2. 用 margin 约束减少分解分支退化，使 advection 与 intensity 分支更可区分。
3. 在 SEVIR、MeteoNet、Shanghai Radar、CIKM 上报告对多个预测 backbone 的一致改进，并给出最高 15.7% CSI 和 14.6% HSS 相对提升。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接以公开雷达 nowcasting 数据集为实验主体，且同时覆盖 SEVIR、Shanghai Radar、CIKM，适合放入公开基准对比表和 flow matching / 强回波保持专题。

**值得关注的原因**

它把 flow matching 从整体生成预测推进到强度分量细化，和 FlowCast、PixelFlowCast、MFC-RFNet 等路线有直接比较价值；同时多公开数据集设置有助于观察方法是否跨区域稳定。

**可能局限**

当前可访问材料主要是摘要和元数据；需要后续获取 IEEE 正文，核验具体 backbone、训练协议、Shanghai/CIKM/SEVIR 预处理、阈值设置和代码开放情况。

**后续讨论问题**

1. Intensity flow matching 的收益是否主要体现在高 dBZ 阈值，还是整体结构指标也有明显改善？
2. Margin-based decomposition 与 NowcastNet / Nowcast3D 中的物理分解有什么形式差异？
3. 在 SEVIR、Shanghai Radar、CIKM 三个公开数据集上，改进是否来自同一类误差缓解？

### 2. SimNowcasting: Enhancing Precipitation Nowcasting via Lightweight Multiscale Convolution and Channel-Wise Attention Mechanism

- **链接**: https://doi.org/10.1109/JIOT.2026.3670117
- **PDF**: 无开放 PDF
- **来源**: IEEE Internet of Things Journal / Crossref / DBLP / ResearchGate metadata snippet
- **发布日期/版本日期**: IEEE Internet of Things Journal 2026-06-01；IEEE 页面在 2026-07-19 七日检索中显示为今日新抓取结果
- **作者**: Meihan Qi; Wei Fang; Yang Zhao
- **机构/会议/期刊**: IEEE Internet of Things Journal, 13(11):23278-23287
- **DOI / arXiv ID**: 10.1109/JIOT.2026.3670117
- **关键词标签**: SimNowcasting; lightweight model; SimInception; channel-wise attention; radar echo sequences; Shanghai radar
- **研究方向**: CNN encoder-decoder；Transformer / attention models；轻量化雷达回波外推；业务部署效率
- **使用的数据集**: Shanghai radar data
- **重点公开数据集匹配**: ShangHai / Shanghai
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ResearchGate 元数据摘要说明 SimNowcasting 的 Spatial Encoder 模块捕获 radar echo sequences 的通道关键特征，并称实验在 Shanghai radar data 上验证。

**摘要**

论文关注现有深度学习降水临近预报模型结构复杂、计算效率低和泛化不足的问题，提出轻量化 SimNowcasting。该方法强调用较少训练参数提取多尺度时空特征，并在上海雷达数据上验证预测精度。

**方法概述**

模型核心是 SimInception 模块，用较轻的多尺度卷积替代更重的标准 Inception 式结构；同时引入 Spatial Encoder / channel-wise attention，用于突出雷达回波序列通道维度中的关键特征。整体目标是保持可用精度的同时降低参数量和推理成本。

**主要贡献**

1. 提出轻量多尺度卷积模块，面向实时降水 nowcasting 的效率约束。
2. 使用通道注意力增强雷达回波序列中的关键特征响应。
3. 在 Shanghai radar data 上报告相对基线的竞争性预测精度。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文以 radar echo sequences 和 Shanghai radar data 为实验依据，命中本项目重点跟踪的 ShangHai/Shanghai 数据集线索。

**值得关注的原因**

许多生成式或 Transformer nowcasting 模型在强回波上表现更好但推理成本高。SimNowcasting 可作为轻量 CNN/attention 路线的补充，用于比较“低参数量 vs. 高强度回波保真度”的取舍。

**可能局限**

当前没有开放全文或代码；ResearchGate 与 Crossref/DBLP 作者列表存在轻微元数据差异，本报告以 Crossref/DBLP 作者和 DOI 为准。需要后续核验 Shanghai 数据版本、数据划分和参数量/延迟指标。

**后续讨论问题**

2. Shanghai 数据上的轻量模型是否能迁移到 SEVIR 或 CIKM？
3. 与 RainNet、SmaAt-UNet、Rainformer 等轻量/中等规模模型相比，参数量和高阈值 CSI 如何？

### 3. A Space-Time Transformer for Precipitation Nowcasting

- **链接**: https://arxiv.org/abs/2511.11090
- **PDF**: https://arxiv.org/pdf/2511.11090
- **来源**: arXiv / NeurIPS Weather4Cast Challenge 2025
- **发布日期/版本日期**: 2025-11-14 提交；2026-07-14 修订为 v3
- **作者**: Levi Harris; Tianlong Chen
- **机构/会议/期刊**: NeurIPS Weather4Cast Challenge 2025
- **DOI / arXiv ID**: arXiv:2511.11090；10.48550/arXiv.2511.11090
- **关键词标签**: SaTformer; space-time transformer; Weather4Cast 2025; HRIT satellite radiances; OPERA radar precipitation fields; cumulative rainfall
- **研究方向**: Transformer / attention models；Radar-satellite fusion；Benchmark / dataset paper；降水临近预报
- **使用的数据集**: Weather4Cast 2025，输入为 11-band HRIT 地球同步卫星辐射，目标由 OPERA high-resolution radar precipitation / rain-rate fields 派生
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: arXiv 正文说明 Weather4Cast 任务使用 HRIT 卫星数据预测 OPERA high-resolution radar precipitation fields；2025 任务的目标标签由 4 小时 OPERA high-resolution rain-rate fields 派生。

**摘要**

论文介绍 SaTformer，将视频 Transformer 改造成降水临近预报模型，并将长尾降水强度回归问题改写为分类问题。该方法获得 NeurIPS Weather4Cast 2025 “Cumulative Rainfall” challenge 第一名。

**方法概述**

模型对 HRIT 卫星辐射序列切 patch 后使用 full space-time self-attention 建模时空关系，并用 class token 输出离散降水强度分布。为处理强降水稀缺和长尾分布，训练中使用 class-weighted cross entropy，按目标标签频率加权。

**主要贡献**

1. 将 TimeSformer 类视频模型用于 Weather4Cast 2025 累积降水任务。
2. 把连续降水回归离散化为多类别分布预测，并使用频率加权损失改善长尾样本表现。
3. 在 Weather4Cast 2025 challenge set 上取得 CRPS 3.135 的第一名成绩。

**与基于雷达回波的降水临近预报的关系**

相关性中等。输入主要是卫星 HRIT 数据，但训练目标来自 OPERA 高分辨率雷达降水场，属于包含雷达衍生降水图的 radar-satellite 任务；适合放在“卫星到雷达降水场 / radar target nowcasting”方向，而不是 radar-only 外推。

**值得关注的原因**

Weather4Cast 数据与公开比赛设置有利于比较跨区域泛化和概率评分。该文也提醒，简单分类化和类别重加权可能在强降水长尾问题上非常有效，可迁移到 SEVIR/CIKM 等雷达数据的强回波阈值训练。

**可能局限**

该模型预测的是累积降水目标分布，不是密集时空雷达回波视频；作者也明确指出若要输出 dense nowcasts，需要显著修改架构。输入并非雷达序列，因此与 radar-only extrapolation 模型的比较要谨慎。

**后续讨论问题**

1. 将 radar nowcasting 的像素值回归改为分类分桶，是否能提升 CIKM/SEVIR 高阈值 CSI？
2. Weather4Cast 的 OPERA target 与 SEVIR VIL target 在评价指标和物理含义上如何对齐？
3. Full space-time attention 在更高分辨率雷达序列上是否需要稀疏化或分块注意力？

### 4. Precipitation Nowcasting Based on Radar Echo Images via Multiscale Spatiotemporal LSTM

- **链接**: https://doi.org/10.1109/TGRS.2025.3584824
- **PDF**: https://ieeexplore.ieee.org/iel8/36/10807682/11062628.pdf
- **来源**: IEEE Transactions on Geoscience and Remote Sensing / Crossref / NASA ADS / ResearchGate metadata snippet
- **发布日期/版本日期**: IEEE TGRS 2025-07-02；IEEE 页面在 2026-07-19 七日检索中显示为今日新抓取结果，ADS/ORCID/DBLP 元数据也在近一周抓取
- **作者**: Yueting Wang; Ling Yao; Hou Jiang; Tang Liu; Yuxiang Lu; Chenghu Zhou
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing, 63, Article 5105614
- **DOI / arXiv ID**: 10.1109/TGRS.2025.3584824
- **关键词标签**: MS2T-LSTM; multiscale spatiotemporal LSTM; radar echo images; radar echo extrapolation; local spatial variation
- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；雷达回波外推；多尺度时空建模
- **使用的数据集**: radar echo image sequences（当前元数据未给出公开数据集名称）
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: IEEE/ResearchGate 摘要片段说明该文针对 radar echo images 的降水临近预报，并讨论 deep learning-based radar echo extrapolation methods；题名和 DOI 元数据均明确为基于 radar echo images 的 nowcasting。

**摘要**

论文面向 0-2 小时降水临近预报中的雷达回波图像外推，指出现有深度学习方法在局地空间变化预测和长时效性能退化方面仍有不足。作者提出 multiscale spatiotemporal LSTM，用多尺度机制增强雷达回波形态和时序演变建模。

**方法概述**

MS2T-LSTM 以 LSTM 时空序列建模为主线，结合多尺度空间特征提取和时序演变表示，试图同时捕获大尺度回波移动和局地小尺度变化。该类结构可视为 ConvLSTM / PredRNN 系列在多尺度空间编码上的延伸。

**主要贡献**

1. 针对雷达回波图像提出多尺度时空 LSTM 框架。
2. 关注局地空间变化和长 lead time 性能衰减，而不只是整体回波位移。
3. 在 IEEE TGRS 正式发表，可作为 LSTM 系列雷达回波外推基线补充。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文题名、摘要和任务均明确围绕 radar echo images / radar echo extrapolation，适合纳入 ConvLSTM 继承路线。

**值得关注的原因**

近期生成式模型关注强回波清晰度，但 LSTM 系列仍是许多业务或低资源场景的基线。该文提供了 2025 年正式发表的多尺度 LSTM 方案，可与 ST-TriMambaUNet、MSPTS-Net、PFST-LSTM 等序列模型比较。

**可能局限**

当前可访问元数据没有公开具体数据集名称和详细实验配置；且论文发表时间为 2025，本次纳入依据是主页面/作者元数据在 2026-07-19 七日检索中作为新抓取结果出现。后续需要核验数据来源、预处理和代码可复现性。
