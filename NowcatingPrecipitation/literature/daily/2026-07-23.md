### 1. RainPredRNN: A New Approach for Precipitation Nowcasting with Weather Radar Echo Images Based on Deep Learning

- **链接**: https://doi.org/10.3390/axioms11030107
- **PDF**: https://www.mdpi.com/2075-1680/11/3/107/pdf
- **来源**: Axioms / MDPI / Crossref
- **发布日期/版本日期**: 2022-02-28；Crossref indexed 2026-07-22
- **作者**: Do Ngoc Tuyen; Tran Manh Tuan; Xuan-Hien Le; Nguyen Thanh Tung; Tran Kim Chau; Pham Van Hai; Vassilis C. Gerogiannis; Le Hoang Son
- **机构/会议/期刊**: Axioms, 11(3), 107
- **DOI / arXiv ID**: 10.3390/axioms11030107
- **关键词标签**: RainPredRNN; UNet; PredRNN_v2; weather radar echo images; Phadin radar; reflectivity
- **研究方向**: ConvLSTM / recurrent models；CNN encoder-decoder；Radar echo extrapolation；Precipitation nowcasting
- **使用的数据集**: Vietnam Phadin weather radar station reflectivity fields
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref / MDPI 摘要明确说明 RainPredRNN 用于 weather radar echo images，并在 Phadin weather radar station 的真实 reflectivity fields 上验证。

**摘要**

论文提出 RainPredRNN，用于基于天气雷达回波图像的降水临近预报。作者关注低降水区域中未来雷达回波图像预测不足、深度模型计算量较大等问题，希望在保持预测质量的同时降低训练和推理成本。

**方法概述**

RainPredRNN 将 UNet 的编码-解码结构与 PredRNN_v2 的时序预测能力结合。UNet 负责提取和重建空间结构，PredRNN_v2 建模雷达回波序列的时间演变。实验使用越南 Dien Bien 省 Phadin 雷达站反射率场，并用 MAE、SSIM、CSI 评估。

**主要贡献**

1. 将 UNet 与 PredRNN_v2 组合成较轻量的雷达回波预测框架。
2. 在真实天气雷达反射率场上验证模型，报告训练时间显著降低。
3. 为低资源雷达站点的深度学习 nowcasting 提供一个早期轻量基线。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接预测 weather radar echo images，可与 ConvLSTM、TrajGRU、PredRNN、Rainformer 等序列预测模型对照。

**值得关注的原因**

它提供了越南本地雷达站资料上的实验案例，有助于观察公开基准之外的小区域雷达站点模型表现。

**可能局限**

实验区域和雷达来源较单一；未命中 CIKM、ShangHai、SEVIR 或 MetNet，难以直接和主流公开基准结果横向比较。

**后续讨论问题**

1. RainPredRNN 的加速收益来自 UNet 压缩，还是来自训练设置差异？
2. 在强回波阈值上，UNet + PredRNN_v2 是否仍能避免强度衰减？
3. Phadin 单站数据与多站雷达拼图数据的泛化差异有多大？

### 2. Deep learning model based on multi-scale feature fusion for precipitation nowcasting

- **链接**: https://doi.org/10.5194/gmd-17-53-2024
- **PDF**: https://gmd.copernicus.org/articles/17/53/2024/gmd-17-53-2024.pdf
- **来源**: Geoscientific Model Development / Crossref
- **发布日期/版本日期**: 2024-01-04；Crossref indexed 2026-07-22
- **作者**: Jinkai Tan; Qiqiao Huang; Sheng Chen
- **机构/会议/期刊**: Geoscientific Model Development, 17, 53-69
- **DOI / arXiv ID**: 10.5194/gmd-17-53-2024
- **关键词标签**: MFF; multi-scale feature fusion; radar echo data; 3 h nowcasting; heavy precipitation
- **研究方向**: CNN encoder-decoder；Radar echo extrapolation；Quantitative precipitation nowcasting；Multi-scale modeling
- **使用的数据集**: 2018-2022 radar echo data；2018-2021 training, 2022 testing
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: GMD / Crossref 摘要明确说明模型训练使用 2018-2021 年 4 年 radar echo data，并用 2022 年数据测试。

**摘要**

论文提出 multi-scale feature fusion (MFF) 深度学习结构，目标是提升 3 小时以内强降水临近预报能力。作者认为单尺度卷积对降水系统形状、移动方向和速度的刻画不足，尤其在长 lead time 和强降水区域容易平滑。

**方法概述**

MFF 使用不同尺寸卷积核构造多尺度感受野，以捕捉降水系统的空间形态和运动特征；同时引入离散概率机制降低不确定性和预测误差。论文将 MFF 与 TSRC、optical flow、UNet 对比，并用 POD、FAR、MAE、SSIM 和 RAPS 评价。

**主要贡献**

1. 提出面向雷达回波降水 nowcasting 的多尺度特征融合结构。
2. 用多年雷达回波资料验证 3 小时 lead time 下强降水预测能力。
3. 通过谱分析讨论模型平滑效应，对强降水细节保持有参考价值。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接使用 radar echo data 训练和测试，任务是雷达降水 nowcasting。

**值得关注的原因**

该文把公开基准中常见的“空间多尺度建模”放到多年业务雷达资料和 3 小时预报时效中评估，对长时效强降水衰减问题有实用意义。

**可能局限**

摘要未显示与 CIKM、Shanghai、SEVIR 等公开数据集对齐；模型主要是卷积多尺度增强，跨区域泛化仍需验证。

**后续讨论问题**

1. MFF 的多尺度卷积和 Rainformer / Earthformer 的注意力多尺度结构相比，强降水阈值收益是否一致？
2. RAPS 谱能量改善是否能转化为更高的高阈值 CSI？
3. 3 小时 lead time 下，模型误差主要来自位移偏差还是强度衰减？

### 3. HPRNN: A Hierarchical Sequence Prediction Model for Long-Term Weather Radar Echo Extrapolation

- **链接**: https://doi.org/10.1109/ICASSP40776.2020.9054232
- **PDF**: 无稳定开放 PDF；ResearchGate 页面含作者上传全文
- **来源**: ICASSP 2020 official program / IEEE Xplore / Crossref / ResearchGate author full text
- **发布日期/版本日期**: 2020-05；Crossref indexed 2026-07-22
- **作者**: Jinrui Jing; Qian Li; Xuan Peng; Qiang Ma; Shaoen Tang
- **机构/会议/期刊**: ICASSP 2020 - IEEE International Conference on Acoustics, Speech and Signal Processing
- **DOI / arXiv ID**: 10.1109/ICASSP40776.2020.9054232
- **关键词标签**: HPRNN; hierarchical prediction; ConvLSTM; ConvGRU; HKO-7; long-term radar echo extrapolation
- **研究方向**: ConvLSTM / recurrent models；Radar echo extrapolation；Long-horizon nowcasting
- **使用的数据集**: HKO-7 radar echo dataset
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ResearchGate 作者全文摘要说明 HPRNN 用于 weather radar echo extrapolation，并在 HKO-7 radar echo dataset 上做 extrapolation experiments。

**摘要**

论文针对雷达回波外推在长时效中误差累积、图像质量快速下降的问题，提出 hierarchical prediction recurrent neural network (HPRNN)。其核心动机是把长时效预测拆解为长程趋势和短程细节两个层次，减少直接逐帧递推导致的误差传播。

**方法概述**

HPRNN 包含 frame encoder、short-range RNN、integration layer、long-range RNN、guiding layer、refinement module 和 frame decoder。短程模块使用 ConvLSTM 捕捉局地时间动态，长程模块用 ConvGRU 建模粗尺度趋势，再通过 refinement module 进行递归粗到细修正。

**主要贡献**

1. 将雷达回波外推显式拆成长程趋势预测和短程细节预测。
2. 用 recurrent coarse-to-fine 机制缓解长时效误差累积。
3. 在 HKO-7 雷达回波数据集上验证对长时效外推质量的提升。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文直接预测未来 radar echo sequence，是 ConvRNN 系列长时效回波外推方法的重要早期条目。

**值得关注的原因**

很多新模型仍在解决同一个长 lead time 问题：结构变模糊、强回波衰减、递推误差放大。HPRNN 的层次化预测思想可作为后续 Transformer、Mamba、扩散模型的早期对照。

**可能局限**

会议论文较早，实验集中在 HKO-7，未覆盖 CIKM、Shanghai、SEVIR 或 MetNet；公开复现资源和现代强基线比较有限。

**后续讨论问题**

1. HPRNN 的长短程分解能否与频域分解或扩散 coarse-to-fine 框架结合？
2. 在 HKO-7 之外的多雷达拼图数据上，层次化 RNN 是否仍优于 TrajGRU？
3. 误差累积是否主要来自时序递推方式，而非单帧生成质量？

**摘要**

论文研究多通道 / 三维雷达回波外推问题。作者指出，多数深度学习 nowcasting 工作使用二维雷达图像，而三维雷达数据的通道间干扰、观测误差传播和过拟合问题尚未被充分讨论。

1. 将 3D / multi-channel radar echo extrapolation 中的通道串扰问题显式化。

**可能局限**

公开摘要未显示具体数据集名称，也没有命中重点公开数据集；早期模型和现代 3D Transformer / diffusion 框架的对比不足。

### 5. Toward a Deep-Learning-Network-Based Convective Weather Initiation Algorithm From the Joint Observations of Fengyun-4A Geostationary Satellite and Radar for 0-1h Nowcasting

- **作者**: Fenglin Sun; Bo Li; Min Min; Danyu Qin
- **机构/会议/期刊**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing, 16, 3455-3468
- **DOI / arXiv ID**: 10.1109/JSTARS.2023.3262557
- **关键词标签**: CWNNet; ConvRNN; Fengyun-4A; Doppler weather radar; radar reflectivity factor; convective initiation
- **研究方向**: ConvLSTM / recurrent models；Multi-source fusion；Convective storm nowcasting；Short-term weather radar forecasting
- **使用的数据集**: Fengyun-4A AGRI satellite observations；ground-based Doppler weather radar data；future radar reflectivity factor maps
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: 作者全文摘要说明 CWNNet 使用 Fengyun-4A geostationary satellite 和 ground-based Doppler weather radar data 的 0-1 h 联合观测作为输入，预测未来 0-1 h radar reflectivity factor maps。

**摘要**

论文面向强对流初生 0-1 小时 nowcasting，提出 Convective Weather Nowcasting Net (CWNNet)。其问题背景是单独使用卫星云图可以提前捕捉对流初生信号，但假警率较高；单独使用地基雷达又受覆盖范围限制，因此需要卫星-雷达联合建模。

**方法概述**

CWNNet 是 ConvRNN-based regression network，输入为最近 0-1 小时的 Fengyun-4A 地球同步卫星观测和地基 Doppler 天气雷达数据，输出未来 0-1 小时雷达反射率因子图。论文用 POD、FAR、TS、RMSE、MAE 和多个个例评估。

**主要贡献**

1. 将 FY-4A 卫星和地基 Doppler 雷达联合用于强对流初生 nowcasting。
2. 用 ConvRNN 直接预测未来 radar reflectivity factor maps。
3. 报告 CWNNet 相比单一数据源有更好 nowcasting 表现，可提前 30 分钟以上识别部分对流初生个例。

**与基于雷达回波的降水临近预报的关系**

相关性中高。它不是典型降水量 nowcasting，而是短时强对流天气 / 雷达反射率预报，符合“short-term weather radar forecasting”范围；对雷达-卫星融合模型尤其相关。

**值得关注的原因**

对流初生是纯雷达外推的短板之一。该文把卫星云顶演变作为雷达反射率增长的先兆，适合与 M4Caster、FusionCast、MAG-Net 等雷达-卫星融合路线比较。

**可能局限**

任务目标偏强对流初生而非降水量；没有命中 CIKM、Shanghai、SEVIR 或 MetNet；ResearchGate 作者全文为作者版本，最终 IEEE 版本细节仍需以后核对。

**后续讨论问题**

**摘要**

论文提出 MFSP-Net，目标是利用多源气象数据提升 0-4 小时降水量和降水强度临近预报。作者认为单一数据源只能从一个角度反映降水系统演变，而降水格点、雷达回波和再分析数据可以互补。

MFSP-Net 是 multi-input multi-output recurrent neural network。它对三类输入数据做时空尺度融合，同时保留各自的时空信息流；训练中采用 multi-task learning，同时输出降水量 nowcasting 和降水强度 nowcasting。

1. 将 precipitation grid、radar echo、reanalysis 三类数据纳入统一 recurrent nowcasting 框架。
2. 同时预测降水量和降水强度，强调多任务学习。

相关性中高。雷达回波是输入数据之一，论文重点是多源融合和 0-4 小时降水 nowcasting，不是纯雷达外推。

**值得关注的原因**

该文可作为“雷达 + 再分析 / 大尺度背景场”融合路线的早期参考，适合与 MSDM、M4Caster、PCEED-Net 等多源模型区分：哪些方法真正包含雷达，哪些只用卫星 / GPM / IMERG。

**可能局限**

多源数据对齐、时空分辨率差异和信息泄漏风险需要细读全文；没有命中重点公开数据集，难以与 CIKM / SEVIR 系列直接比较。

**摘要**

论文提出 Physics-informed Multi-Modal Network (PiMMNet)，用于更长预报时效的多模态降水临近预报。作者认为多数端到端方法只建模雷达回波序列，忽略了降水系统演变中的平流-扩散物理机制；单一雷达模态也限制了长时效泛化。

**方法概述**

PiMMNet 将降水演变建模为包含 deterministic advection 和 stochastic source 的时空输运过程。模型包含 multi-modal motion estimation network 和 motion-guided diffusion model，前者从雷达与卫星输入联合估计受物理约束的速度场，后者描述随机源项和不确定变化。

**主要贡献**

1. 用平流-扩散视角重新组织雷达-卫星多模态 nowcasting。
2. 通过物理约束速度场把不同模态的运动演变对齐到统一表示。
3. 在两个真实多模态气象数据集上报告长时效精度和鲁棒性提升，并提供 GitHub 仓库入口。

**与基于雷达回波的降水临近预报的关系**

相关性高。该文显式使用 radar and satellite data，是面向长时效的雷达-卫星融合与生成式 nowcasting 工作。

**值得关注的原因**

PiMMNet 连接了三个近期热点：多源融合、物理约束速度场、扩散生成。它适合与 FusionCast、MAG-Net、M4Caster、Rainfusion / PDRF 等方法一起讨论物理一致性和跨模态对齐。

**可能局限**

当前可访问摘要没有披露具体数据集名称，也未命中 CIKM、Shanghai、SEVIR 或 MetNet；ACM 正文和代码仓库当前公开信息有限，后续需核验数据预处理和评估阈值。
