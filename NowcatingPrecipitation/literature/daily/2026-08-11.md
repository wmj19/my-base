### 1. FreCast: Refining Radar Echo Intensity via Phase-Preserving Amplitude Residual Diffusion for Precipitation Nowcasting

- **链接**: https://arxiv.org/abs/2608.08436
- **PDF**: https://arxiv.org/pdf/2608.08436
- **来源**: arXiv / arXiv HTML
- **发布日期/版本日期**: arXiv v1 submitted 2026-08-09
- **作者**: Heping Fang; Zihuai Yin; Kaicheng Mao; Peiguang Zhang; Peng Yang
- **机构/会议/期刊**: arXiv, cs.CV；Southern University of Science and Technology
- **DOI / arXiv ID**: 10.48550/arXiv.2608.08436 / arXiv:2608.08436
- **关键词标签**: FreCast; phase-preserving amplitude residual diffusion; frequency-domain refinement; radar echo prediction; SEVIR; MeteoNet; Shanghai Radar
- **研究方向**: Diffusion / generative models；Radar echo extrapolation；Precipitation nowcasting；Frequency-domain modeling；Radar reflectivity / radar echo intensity refinement
- **使用的数据集**: SEVIR；MeteoNet；Shanghai Radar
- **重点公开数据集匹配**: SEVIR；ShangHai / Shanghai Radar
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: arXiv 摘要将任务定义为从历史 radar echo sequences 预测 future radar echoes；arXiv HTML 实验部分说明在 SEVIR、MeteoNet 和 Shanghai Radar 三个 radar precipitation nowcasting datasets 上实验，其中 Shanghai Radar 为 2015-10 至 2018-07 上海浦东采集的雷达回波图。

**摘要**

论文关注深度学习降水临近预报中一个更细粒度的问题：模型通常能预测未来降水的大致空间结构，但在单个位置的雷达回波强度上仍存在明显偏差，尤其会影响强回波和雨带连续性。作者提出 FreCast，一个两阶段雷达回波预测框架：第一阶段生成未来雷达回波的初始预报，第二阶段在该预报的空间结构约束下进一步校正局地回波强度偏差。实验在 SEVIR、MeteoNet 和 Shanghai Radar 上进行，报告 FreCast 在多类业务预报指标上取得一致提升，并在长 lead time 下更好保持雨带连续性和强降水结构。

**方法概述**

FreCast 把未来雷达回波看作“空间结构位置”和“局地强度变化”共同决定的强度场。第一阶段采用确定性频谱基线，同时预测未来回波的振幅谱和相位谱，并重建初始雷达序列。第二阶段只建模归一化真值振幅谱与基线振幅谱之间的残差，用扩散模型生成 amplitude residual；推理时保留第一阶段预测的相位作为空间结构锚点，仅修正振幅谱，再反变换回图像域。这个设计试图减少普通像素域残差扩散对降水结构位置的扰动，把生成式能力集中在回波强度偏差修正上。

**主要贡献**

1. 从误差来源角度指出，已命中降水区域内部的回波强度偏差是许多 nowcasting 模型的重要剩余误差来源。
2. 提出 phase-preserving amplitude residual diffusion，把第二阶段随机修正限制在频域振幅残差上，并用基线相位约束空间结构。
3. 在 SEVIR、MeteoNet、Shanghai Radar 三个雷达临近预报数据集上进行统一实验，命中本自动化重点数据集 SEVIR 与 ShangHai / Shanghai Radar。
4. 与 PhyDNet、SimVP、EarthFormer、AlphaPre、DiffCast、NowcastNet 等基线比较，论文报告 FreCast 在三个数据集上的 CSI、HSS 和 FSS 均为最优。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文的输入输出均围绕雷达回波序列，任务是预测未来 radar echoes，并直接在 SEVIR 与 Shanghai Radar 这两个重点公开雷达 / 雷达衍生基准上验证。它适合纳入“频域建模 + 生成式残差修正”“强回波强度保持”和“SEVIR / Shanghai Radar 横向对比”专题。

**值得关注的原因**

近期生成式雷达 nowcasting 论文常在全场像素域、潜空间或 flow / diffusion 框架中生成未来序列。FreCast 的差异在于不重新生成完整空间结构，而是把第一阶段预测相位作为结构约束，只对振幅谱残差做扩散校正。这给“如何减少强度偏差而不引入位置漂移或虚假扩张”提供了一个较清晰的分解视角，可与 AlphaPre、DiffCast、DuoCast、FREUD、QWRF-Net、WaveCastNet 等方法比较。

**可能局限**

论文仍是新提交预印本，代码和数据处理细节需要继续核验。频域相位与空间结构、振幅与强度的对应关系只是有用近似，并非严格可分；在新生 / 消散对流、快速形变或雷达噪声场景中，保留基线相位可能限制结构纠错能力。实验统一将帧调整到 128 x 128，也需要关注其对高分辨率强回波边界的影响。

**后续讨论问题**

1. FreCast 的收益主要来自频谱基线预测、振幅残差扩散，还是 phase-preserving 约束本身？
2. 当第一阶段已经出现位置偏差或漏报时，保留相位是否会限制第二阶段纠错？
3. 在 SEVIR 与 Shanghai Radar 上，FreCast 与 QWRF-Net、WaveCastNet、FREUD、DuoCast、DiffCast 的采样成本和高阈值 CSI 是否能在同一协议下复现比较？
