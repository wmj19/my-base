### 1. STADEN: A Dual-Branch Deep Learning Framework With Multithreshold Loss for Robust Radar Echo Extrapolation

- **链接**: https://doi.org/10.1155/adme/6492939
- **PDF**: https://onlinelibrary.wiley.com/doi/pdf/10.1155/adme/6492939
- **来源**: Wiley / Crossref DOI 元数据
- **发布日期/版本日期**: 2026-06-18 online；Crossref indexed 2026-06-18
- **作者**: Hui Luo; Hang Zhou; Na Xie; Kangquan Yang; Wulong Zhang
- **机构/会议/期刊**: Advances in Meteorology
- **DOI / arXiv ID**: 10.1155/adme/6492939
- **关键词标签**: STADEN; MetaFormer; Inception; multithreshold loss; radar echo extrapolation; HKO-7
- **研究方向**: Transformer / attention models; CNN encoder-decoder; Radar echo extrapolation
- **使用的数据集**: Sichuan dataset; HKO-7
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref/Wiley 摘要说明论文做 radar echo extrapolation，在 Sichuan dataset 上进行 2 小时外推实验，并在 HKO-7 dataset 上做鲁棒性实验。

**摘要**

论文针对深度学习雷达回波外推中的模糊化和高阈值指标偏低问题，提出 Spatial-Temporal-Attention Dual-path Extrapolation Network（STADEN）和 multithreshold loss（MTL）。摘要报告 STADEN 在四川数据集 2 小时外推实验中，在 15、25、35 阈值 CSI 上优于对比方法，并在 HKO-7 上验证鲁棒性。

**方法概述**

STADEN 采用双分支结构，结合 Inception 与 MetaFormer 增强时空特征学习；MTL 不要求预测值与真值逐像素完全一致，而允许预测落入真值区间以降低损失，从而提升对混沌大气状态不确定性的鲁棒性。

**主要贡献**

1. 提出面向雷达回波外推的双路径时空注意力网络。
2. 提出多阈值损失，用区间式约束缓解像素级 MSE 带来的过度平滑。
3. 在 Sichuan 与 HKO-7 上报告高阈值 CSI 改善。

**与基于雷达回波的降水临近预报的关系**

高度相关。任务本身是雷达回波外推，评价重点覆盖强回波阈值，对强降水临近预报模型设计有直接参考价值。

**值得关注的原因**

相比只换主干网络，STADEN 同时调整特征提取结构和损失函数，可作为“结构 + 目标函数”联合改进路线的近期样例。

**可能局限**

目前可访问元数据未给出 Sichuan dataset 的公开性和详细采样规范；HKO-7 也不是本任务优先关注的 CIKM/ShangHai/SEVIR/MetNet 数据集。

**后续讨论问题**

1. MTL 是否可迁移到 SEVIR、CIKM 或 Shanghai Radar 的强降水阈值评估？
2. 区间式损失与分位数回归、多阈值分类损失的差异在哪里？
3. MetaFormer 分支对长期外推的贡献是否能通过消融验证清楚分离？

### 2. TITAN-LSTM: A Weather Radar Nowcasting Tool

- **链接**: https://doi.org/10.22541/essoar.174534290.09062305/v1
- **PDF**: https://essopenarchive.org/doi/pdf/10.22541/essoar.174534290.09062305/v1
- **来源**: ESS Open Archive / Crossref DOI 元数据
- **发布日期/版本日期**: posted 2025-04-22；Crossref deposited/indexed 2026-06-17
- **作者**: Andrea S. Viteri López; Carlos A. Morales Rodriguez
- **机构/会议/期刊**: ESS Open Archive preprint
- **DOI / arXiv ID**: 10.22541/essoar.174534290.09062305/v1
- **关键词标签**: TITAN; LSTM; weather radar nowcasting; storm tracking; operational nowcasting
- **研究方向**: ConvLSTM / recurrent models; Operational nowcasting systems
- **使用的数据集**: DAEE-SPOL weather radar (SAO-SPOL) rainstorms, 2016-2019
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref 摘要说明该算法使用 DAEE-SPOL weather radar (SAO-SPOL) 2016-2019 年观测到的雨暴进行训练和验证。

**摘要**

论文提出一个将 TITAN 风暴识别/跟踪算法与 LSTM 网络结合的天气雷达临近预报工具。TITAN 负责识别和跟踪雨暴生命史并预测位移，LSTM 则基于 TITAN 跟踪结果预测降雨面积和降水强度。

**方法概述**

模型采用三层 LSTM、20% dropout 和线性输出层。输入由 TITAN 生成的风暴跟踪序列构成，输出包括未来雨区面积和降雨率分布。评估覆盖 5 到 30 分钟短时效，报告雨区 RMSE、POD、FAR、BIAS 和降雨率 RMSE。

**主要贡献**

1. 将传统风暴单体跟踪 TITAN 与 LSTM 预测模块结合。
2. 使用实际 SAO-SPOL 雷达雨暴资料进行训练和验证。
3. 给出短时效雨区形状和降雨率误差评估。

**与基于雷达回波的降水临近预报的关系**

中高相关。它不是端到端雷达图像生成模型，而是面向业务风暴单体跟踪的 AI 增强 nowcasting 工具。

**值得关注的原因**

这类“传统雷达跟踪 + 轻量序列模型”的路线适合与纯深度学习回波外推模型比较，尤其适合低延迟、可解释的业务工具场景。

**可能局限**

预印本发布时间较早，本次是 Crossref 新近 deposited/indexed；模型主要聚焦风暴对象和雨区统计，空间细节可能弱于图像到图像模型。

**后续讨论问题**

1. TITAN-LSTM 是否可作为强对流单体级 baseline，与端到端 radar image nowcasting 并行评估？
2. 风暴对象级误差与像素级 CSI/HSS 如何建立可比关系？
3. 是否适合与雷达回波外推模型做后处理融合？

- **研究方向**: Multi-source fusion; Transformer / attention models; Radar-NWP fusion
- **使用的数据集**: South China real-world dataset with historical radar echo observations and NWP data
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: OpenAlex 摘要说明 HST-AFP 融合 historical radar echo observations 与 NWP data，并在 South China real-world dataset 上实验。

**摘要**

论文关注单一雷达回波输入难以适应业务中的异构多源数据问题，提出 HST-AFP，用于雷达回波外推和进一步降水临近预报。模型同时处理密集时空张量和稀疏时空张量，并在华南真实数据集上与 RNN 和 U-Net 类方法比较。

**方法概述**

HST-AFP 使用 attention-based ST diffusion module、多编码器和 fusion-decoder。模型通过 scale-wise attention fusion 和深层残差时空注意力机制融合多源时空特征，目标是在保持较短预测时间的同时提升 nowcasting 指标。

**主要贡献**

1. 将历史雷达回波与 NWP 数据纳入异构时空融合框架。
2. 设计面向稠密/稀疏时空输入的多编码器结构。
3. 在华南真实业务数据上报告相对 RNN/U-Net 基线的改进。

**与基于雷达回波的降水临近预报的关系**

高度相关。雷达回波是核心输入之一，NWP 被用作补充约束，适合多源融合章节引用。

**值得关注的原因**

它提供了 radar + NWP 异构融合的较早 IEEE TGRS/JSTARS 案例，可与 VMU-Diff、MeteoLogist、PW-FouCast 等融合路线比较。

**可能局限**

数据集不是公开优先基准；Crossref/OpenAlex 摘要未给出完整数据分辨率、雷达产品类型和训练样本量。

**后续讨论问题**

1. HST-AFP 对 NWP 稀疏/低频输入的编码方式能否迁移到 SEVIR 或 MRMS？
2. 注意力融合收益是否主要来自 NWP 还是网络深度？
3. 与 diffusion/flow 类概率模型融合时，NWP 应作为条件还是残差校正项？

**摘要**

论文提出 MultiModal RNN（MM-RNN），在 RNN 降水临近预报中加入气象要素知识约束，使降水运动更符合潜在大气运动规律。模型兼容 ConvLSTM、PredRNN、MIM、MotionRNN 等多种 RNN 主干。

**方法概述**

MM-RNN 将多模态气象要素引入序列预测过程，用元素级知识约束降水演变。论文在 MeteoNet 和 RAIN-F 上验证，报告相对单雷达模态 MS-RNN 的 CSI、MSE、HSS、B-MSE 改善。

**主要贡献**

1. 提出可插拔的多模态 RNN 框架。
2. 在多个 RNN 主干上验证多模态气象要素对雷达降水预报的增益。
3. 同时预测降水和其他气象要素，强调物理一致性。

**与基于雷达回波的降水临近预报的关系**

高度相关。论文直接比较多模态输入与单雷达模态输入，是多源融合和 RNN 基线改进的重要样例。

**值得关注的原因**

MeteoNet 在文献中容易与 MetNet 混淆；本条明确将其作为非优先数据集记录，便于后续检索时避免误标。

**可能局限**

MeteoNet/RAIN-F 与 CIKM、ShangHai、SEVIR 的可比性有限；摘要未说明各模态缺失、时间对齐和空间重采样策略。

**后续讨论问题**

1. MM-RNN 的多模态约束能否与 Transformer 或 diffusion nowcasting 主干结合？
2. MeteoNet 与 RAIN-F 的雷达产品、空间分辨率和降雨阈值是否一致？
3. 多模态收益在强降水样本上是否显著高于普通降水？

### 5. MPFNet: Multiproduct Fusion Network for Radar Echo Extrapolation

- **链接**: https://doi.org/10.1109/TGRS.2024.3496081
- **PDF**: 无
- **来源**: IEEE TGRS / OpenAlex / Crossref
- **发布日期/版本日期**: 2024；Crossref indexed 2026-06-19
- **作者**: Yanle Pei; Qian Li; Liang Zhang; Nengli Sun; Jinrui Jing
- **机构/会议/期刊**: IEEE Transactions on Geoscience and Remote Sensing
- **DOI / arXiv ID**: 10.1109/TGRS.2024.3496081
- **关键词标签**: MPFNet; multiproduct radar fusion; composite reflectivity; echo top height; SWAN; MeteoNet
- **研究方向**: Multi-source fusion; Radar echo extrapolation; Transformer / attention models
- **使用的数据集**: SWAN; MeteoNet
- **重点公开数据集匹配**: 无；MeteoNet 不是 MetNet
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: OpenAlex 摘要说明 MPFNet 面向 radar echo extrapolation，融合 echo composite reflectivity 和其他 radar products，并在 SWAN 与 MeteoNet 上做 convective nowcasting experiments。

**摘要**

论文认为现有雷达回波外推多依赖组合反射率，容易丢失回波顶高等垂直结构信息。MPFNet 通过多雷达产品融合来增强对对流系统的表征，并在 SWAN 和 MeteoNet 上优于 Earthformer、PreDiff 等方法。

**方法概述**

模型包含 residual convolutional encoders、多产品融合模块和 residual decoder。融合模块用 multihead attention 建模不同雷达产品间关系，并用 depthwise separable convolution 聚合特征。

**主要贡献**

1. 将多雷达产品而非单一组合反射率用于雷达回波外推。
2. 设计多产品注意力融合模块，保留垂直和结构信息。
3. 在 SWAN 和 MeteoNet 上报告 CSI/HSS 相对 Earthformer 的提升。

**与基于雷达回波的降水临近预报的关系**

高度相关。它直接处理雷达产品融合，可用于讨论从 2D 组合反射率走向多层/多产品雷达输入的路线。

**值得关注的原因**

与只增加模型容量相比，MPFNet 的贡献在于改善输入物理信息量，对业务雷达产品选择有启发。

**可能局限**

MeteoNet 不是 MetNet；SWAN 与 MeteoNet 的雷达产品可得性和公开复现条件需要进一步核验。

**后续讨论问题**

1. 多产品融合是否比多高度 CAPPI 或 3D radar volume 更易部署？
2. MPFNet 与 3D-ConvLSTM 的差异主要来自输入产品还是模型结构？
3. 是否能在 SEVIR 这类公开基准上构造近似多产品输入？

**主要贡献**

2. 提出 STAM + ST-ConvLSGRU 的轻量时空预测框架。

**与基于雷达回波的降水临近预报的关系**

**值得关注的原因**

当前很多高性能 nowcasting 模型忽视部署延迟；该论文可作为“雷达外推在边缘端运行”的参考。

**可能局限**

**后续讨论问题**

1. STAM-LSGRU 的延迟收益能否量化到 GPU/CPU/边缘设备实际吞吐？
2. 它的注意力模块与 PredRNN、MotionRNN、SimVP 类模型相比复杂度如何？
3. 若迁移到 CIKM/SEVIR，是否仍能保持低延迟优势？

### 7. Three-Dimensional Gridded Radar Echo Extrapolation for Convective Storm Nowcasting Based on 3D-ConvLSTM Model

- **链接**: https://doi.org/10.3390/rs14174256
- **PDF**: https://www.mdpi.com/2072-4292/14/17/4256/pdf
- **来源**: Remote Sensing / Crossref
- **发布日期/版本日期**: 2022-08-29；Crossref indexed 2026-06-19
- **作者**: Nengli Sun; Zeming Zhou; Qian Li; Jinrui Jing
- **机构/会议/期刊**: Remote Sensing
- **DOI / arXiv ID**: 10.3390/rs14174256
- **关键词标签**: 3D-ConvLSTM; gridded radar echo; convective storm nowcasting; 3D optical flow; NCAR
- **研究方向**: ConvLSTM / recurrent models; Convective storm nowcasting; Short-term weather radar forecasting
- **使用的数据集**: Public NCAR Data Archive 3D gridded radar echo dataset
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: Crossref 摘要说明模型对每个 input grid radar volume 提取 3D 空间特征，并在 public National Center for Atmospheric Research Data Archive dataset 上做对比实验。

**摘要**

论文关注二维雷达图像无法表达多高度结构的问题，提出 3D-ConvLSTM 模型进行三维格点雷达回波外推，用于强对流风暴临近预报。实验报告在 35 和 45 dBZ 以上反射率阈值的长期表现更好。

**方法概述**

模型先用 3D-CNN 提取每个雷达体扫的三维空间特征，再用 3D-ConvLSTM 建模时空关系并递归生成未来隐藏状态，最后通过 3D-CNN 上采样得到未来三维雷达回波。

**主要贡献**

1. 将 ConvLSTM 从二维回波图扩展到三维格点雷达体。
2. 与 3D optical flow 和其他深度学习模型比较。
3. 在高反射率强风暴外推上报告更好的定量和个例表现。

**与基于雷达回波的降水临近预报的关系**

高度相关，尤其适合讨论三维雷达输入、垂直结构和强对流 nowcasting。

**值得关注的原因**

它为“2D 雷达图像外推是否足够”提供了具体对照，可与 MPFNet 的多产品融合路线共同讨论。

**可能局限**

- **研究方向**: Diffusion / generative models; Quantitative precipitation nowcasting
- **使用的数据集**: open-source nimrod-uk-1km dataset, UK rainfall radar information, 2016-2019

3. 在 NIMROD UK 1 km 雷达降雨数据上与 GAN 类模型比较。

**与基于雷达回波的降水临近预报的关系**

高度相关。它使用公开英国 NIMROD 雷达降雨数据，是扩散模型在雷达降水图生成中的直接案例。

**值得关注的原因**

**可能局限**

源码正文提到生成 256 x 256 x 4 输出约需 1000 次模型计算，推理成本较高；论文命名在 arXiv 与 DOI 中存在 RNDiff/SRNDiff 混用。
