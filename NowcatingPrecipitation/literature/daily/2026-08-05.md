### 1. QWRF-Net: A Quantum-Wavelet Framework with Rectified Flow for Short-Term Precipitation Nowcasting

- **链接**: https://arxiv.org/abs/2608.01626
- **PDF**: https://arxiv.org/pdf/2608.01626
- **来源**: arXiv
- **发布日期/版本日期**: arXiv v1 submitted 2026-08-03
- **作者**: Zhuo Wang; Chaorong Li; Wenjie Luo; Chuanhu Deng
- **机构/会议/期刊**: arXiv, cs.LG / cs.AI
- **DOI / arXiv ID**: 10.48550/arXiv.2608.01626 / arXiv:2608.01626
- **关键词标签**: QWRF-Net; quantum-wavelet bottleneck; rectified flow; radar-based precipitation nowcasting; KNMI radar; SEVIR
- **研究方向**: Diffusion / generative models；Radar-derived precipitation；Precipitation nowcasting；Flow-based generative nowcasting
- **使用的数据集**: KNMI radar；SEVIR VIL
- **重点公开数据集匹配**: SEVIR
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: arXiv 摘要说明实验在 KNMI radar 与 SEVIR benchmarks 上进行；arXiv HTML 方法部分进一步说明 SEVIR 使用 VIL 预测目标，KNMI 使用对应的 radar-based precipitation field。

**摘要**

论文面向预警场景中的短时降水临近预报，关注雷达降水场多尺度结构耦合、强降水核心保持和长 lead time 退化问题。作者提出 QWRF-Net，把小波分解、量子启发式调制和 rectified-flow 非自回归生成解码结合起来，在统一协议下使用 KNMI radar 与 SEVIR 基准实验。摘要报告模型在中高降水阈值、极端事件子集以及强降水核心和细尺度结构保持方面取得较稳定收益。

**方法概述**

QWRF-Net 采用 U-Net 式 encoder-decoder 主干。历史雷达帧先编码为多尺度特征，瓶颈层用离散小波变换把潜在特征分解为 LL / LH / HL / HH 子带，再对不同子带进行量子启发式非线性调制；未来序列由 rectified-flow 解码器以非自回归方式生成。论文设置为过去 6 帧 30 min 条件输入，生成未来 12 帧 60 min 预报。

**主要贡献**

1. 将降水临近预报表述为条件降水表征与未来序列生成的联合问题。
2. 在生成式 nowcasting 中引入 quantum-wavelet bottleneck，用频段分解显式区分大尺度降水组织和高频强回波结构。
3. 用 rectified flow 替代逐帧递归 rollout，减少多步预测中结构退化和误差累积。
4. 在 KNMI radar 与 SEVIR 上进行统一协议评估，并命中本项目重点公开数据集 SEVIR。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文明确是 radar-based precipitation nowcasting，输入输出均为雷达 / 雷达派生降水序列，并把 SEVIR VIL 作为重点公开基准之一。它适合纳入 rectified flow / flow matching、生成式强降水 nowcasting 和公开基准横向对比专题。

**值得关注的原因**

近期雷达 nowcasting 生成模型从扩散向 flow matching / rectified flow 迁移，核心诉求是更低采样成本和更稳定的多步生成。QWRF-Net 同时使用小波频段拆分和 flow 解码，可与 FREUD、CRFT、MFC-RFNet、G2Lcast、ConCast 等近期方法比较强回波结构保持与实时性。

**可能局限**

预印本刚提交，仍需核查代码、数据预处理、SEVIR 阈值定义、采样步数和与近期 flow / diffusion 方法的公平比较。量子启发模块是在经典硬件上模拟的结构化非线性算子，不应直接理解为真实量子计算优势。

**后续讨论问题**

1. QWRF-Net 的收益主要来自小波子带分解、量子启发调制，还是 rectified-flow 解码？
2. 在 SEVIR 高 VIL 阈值上，它能否稳定超过 FREUD、CRFT、PreDiff 和 ConCast 等已收录方法？
3. flow-based 非自回归生成是否能在业务实时系统中保持足够低的延迟和可校准不确定性？

### 2. Hierarchical Transformer With Lightweight Attention for Radar-Based Precipitation Nowcasting

- **链接**: https://doi.org/10.1109/LGRS.2024.3359229
- **PDF**: 无稳定开放 PDF；IEEE Xplore 页面需访问权限，ResearchGate 提供摘要页面：https://www.researchgate.net/publication/377794916_Hierarchical_Transformer_with_Lightweight_Attention_for_Radar-based_Precipitation_Nowcasting
- **来源**: IEEE Geoscience and Remote Sensing Letters / Crossref / ResearchGate / DBLP / GitHub
- **发布日期/版本日期**: 2024；Crossref indexed 2026-08-04
- **作者**: Wenhui Li; Ying Zhou; Yue Li; Dan Song; Zhiqiang Wei; An-An Liu
- **机构/会议/期刊**: IEEE Geoscience and Remote Sensing Letters, 21, 1-5
- **DOI / arXiv ID**: 10.1109/LGRS.2024.3359229
- **关键词标签**: HTLA; hierarchical transformer; lightweight attention; U-Net; cross-channel self-attention; KNMI radar
- **研究方向**: Transformer / attention models；CNN encoder-decoder；Radar-derived precipitation；Precipitation nowcasting
- **使用的数据集**: KNMI radar dataset
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: IEEE / Crossref 标题明确为 radar-based precipitation nowcasting，ResearchGate 摘要说明论文提出 HTLA 并给出实验结果；相关作者/文献页面说明该方法基于 KNMI radar dataset 做降水 nowcasting。

**摘要**

论文关注 U-Net 和 Transformer 在降水临近预报中的计算复杂度与冗余信息传递问题。作者提出 Hierarchical Transformer with Lightweight Attention (HTLA)，在编码和解码中引入轻量 cross-channel self-attention 与 dual feedforward module，并设计 Gaussian pooling skip-connection 抑制 encoder-decoder 跳连中的冗余干扰。摘要报告 HTLA 在 CSI 和 HSS 上相对强基线提升，同时参数量只有 state-of-the-art 方法的 3.6%。

**方法概述**

HTLA 将 U-Net 的层级编码-解码框架与 Transformer 注意力结合。Cross-channel self-attention 用较低复杂度建模降水图内部的通道和空间依赖；dual feedforward module 增强局地与全局特征转换；Gaussian pooling skip-connection 对跳连信息加权，减少无效或噪声特征从 encoder 直接传到 decoder。整体目标是保留 Transformer 的序列建模能力，同时控制参数量和计算量。

**主要贡献**

1. 提出轻量层级 Transformer 架构 HTLA，用于雷达降水临近预报。
2. 用 cross-channel self-attention 和 dual feedforward module 降低注意力计算复杂度。
3. 设计 Gaussian pooling skip-connection，缓解 U-Net 跳连中的冗余传播。
4. 在 KNMI radar 数据集上报告更高 CSI / HSS 与更小参数规模。

**与基于雷达回波的降水临近预报的关系**

相关性高。题名和方法目标均指向 radar-based precipitation nowcasting，数据源为 KNMI radar dataset。它可作为轻量 Transformer / U-Net 混合 nowcasting 路线的早期补充，与 Rainformer、Earthformer、SwinNowcast、STFF-Transformer 等模型对比。

**值得关注的原因**

许多 Transformer nowcasting 模型提高精度的同时显著增加参数量和推理成本。HTLA 的价值在于把注意力机制做轻量化，并继续保持 U-Net 式多尺度结构，适合关注资源受限部署、实时推理和轻量化基线的比较。

**可能局限**

可访问页面没有提供完整实验表和预处理细节；KNMI 数据集设置、阈值、输入输出窗口和与后续公开基准的可比性仍需查 IEEE 全文确认。论文不命中 CIKM、ShangHai、SEVIR 或 MetNet。

**后续讨论问题**

1. HTLA 的 3.6% 参数量是相对于哪个具体 SOTA 基线，推理延迟是否同步下降？
2. Gaussian pooling skip-connection 是否会削弱高阈值强回波边界信息？
3. HTLA 能否迁移到 SEVIR、CIKM 或 Shanghai-Radar，并与 ConCast 这类轻量增强模型公平比较？

### 3. Precipitation nowcasting using transformer-based generative models and transfer learning for improved disaster preparedness

- **PDF**: ScienceDirect 开放文章页面：https://www.sciencedirect.com/science/article/pii/S1569843224003169；ResearchGate 作者上传全文预览：https://www.researchgate.net/publication/381880634_Precipitation_nowcasting_using_transformer-based_generative_models_and_transfer_learning_for_improved_disaster_preparedness
- **来源**: International Journal of Applied Earth Observation and Geoinformation / Elsevier / Crossref / ResearchGate
- **发布日期/版本日期**: Available online 2024-07-01；Crossref indexed 2026-08-03
- **作者**: Md. Jalil Piran; Xiaoding Wang; Ho Jun Kim; Hyun Han Kwon
- **机构/会议/期刊**: International Journal of Applied Earth Observation and Geoinformation, 132, 103962
- **DOI / arXiv ID**: 10.1016/j.jag.2024.103962
- **关键词标签**: transformer-based generative model; transfer learning; radar reflective data; South Korea radar composite; Soyang Dam basin; cGAN; U-Net; ConvLSTM
- **研究方向**: Transformer / attention models；GAN / adversarial models；Radar reflectivity；Precipitation nowcasting；Transfer learning
- **使用的数据集**: South Korea radar composite reflectivity data from 10 weather radars, 2018-2022
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: ResearchGate / 作者全文预览摘要说明模型使用韩国 10 部天气雷达的 radar composite data 与 radar reflective data 训练；数据覆盖 2018-2022，空间分辨率 1 km，960 x 1200 网格。

**摘要**

论文面向灾害准备中的短时降水预报，提出基于 Transformer 的生成式 nowcasting 方法，并结合迁移学习提升雷达反射率数据上的预测能力。研究区域为韩国汉江上游昭阳坝流域，数据来自韩国 10 部天气雷达构成的 composite reflectivity 场。论文报告模型相对 cGAN、U-Net、ConvLSTM 和 pySTEP 等基线取得更好预测表现。

**方法概述**

方法以 Transformer-based generative model 为核心，先在较大数据上训练，再用 radar reflective data 对 precipitation nowcasting 任务做适配和微调。输入反射率数据先归一化并转为灰度图像序列，模型通过 self-attention 捕捉长程时空依赖，目标是预测未来降水 / 反射率模式。论文强调 transfer learning 可在特定流域样本条件下提升效率和精度。

**主要贡献**

1. 将 Transformer-based generative model 与 transfer learning 用于雷达反射率降水临近预报。
2. 构建韩国昭阳坝流域 2018-2022 年 radar composite reflectivity 数据实验。
3. 与 cGAN、U-Net、ConvLSTM、pySTEP 等代表性深度学习和 nowcasting 基线比较。
4. 将模型应用语境明确连接到山洪、滑坡和灾害响应等下游风险管理。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接使用 weather radar composite reflectivity 数据训练 precipitation nowcasting 模型，任务和数据都属于雷达降水临近预报。它适合纳入“Transformer 生成式模型 / 迁移学习 / 流域灾害应用”方向。

**值得关注的原因**

相比只在公开视频预测基准上做方法比较，该文强调特定流域和灾害准备场景，使用多年韩国业务雷达合成反射率数据。对研究“公开基准模型如何迁移到具体区域水文风险场景”有参考价值。

**可能局限**

论文发表于 2024，本轮是 Crossref 近 7 天重新索引后本地补收；不属于本周新研究。可访问文本显示部分表述较泛化，需要进一步核查模型结构细节、训练数据划分、lead time 设置、指标定义和 pySTEPS 拼写/配置是否严谨。未命中 CIKM、ShangHai、SEVIR 或 MetNet。

**后续讨论问题**

### 4. Advection-Free Convolutional Neural Network for Convective Rainfall Nowcasting

- **链接**: https://doi.org/10.1109/JSTARS.2023.3238016
- **PDF**: IEEE Xplore 页面需访问权限；ResearchGate 作者版本预览：https://www.researchgate.net/publication/367274582_Advection-Free_Convolutional_Neural_Network_for_Convective_Rainfall_Nowcasting
- **来源**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing / Crossref / IEEE Xplore / GitHub / FMI B2Share / ResearchGate
- **发布日期/版本日期**: 2023；Crossref indexed 2026-08-01
- **作者**: Jenna Ritvanen; Bent Harnist; Miguel Aldana; Terhi Mäkinen; Seppo Pulkkinen
- **机构/会议/期刊**: IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing, 16, 1654-1667
- **DOI / arXiv ID**: 10.1109/JSTARS.2023.3238016
- **关键词标签**: L-CNN; Lagrangian CNN; RainNet; LINDA; Finnish weather radar; radar reflectivity; convective rainfall nowcasting
- **研究方向**: CNN encoder-decoder；Radar reflectivity；Radar-derived precipitation；Precipitation nowcasting；Advection / Lagrangian representation
- **使用的数据集**: Finnish weather radar data / FMI composite radar reflectivity data
- **重点公开数据集匹配**: 无
- **是否包含雷达回波相关数据**: 是
- **雷达数据证据**: IEEE / ResearchGate 摘要说明模型在 Finnish weather radar data 上比较 L-CNN、RainNet 和 LINDA；FMI B2Share 数据页说明数据可转换为 radar reflectivity，给出 dBZ = (data - 64.0) / 2.0。

**摘要**

论文针对深度学习降水临近预报难以表示降水生消和小尺度强降水的问题，提出 Lagrangian convolutional neural network (L-CNN)。模型把运动平流与降水强度变化拆开，在拉格朗日坐标中输入连续 rain-rate field 差分，再用 U-Net / RainNet 式 CNN 学习降水增长和衰减。实验在芬兰天气雷达数据上进行，相比 RainNet 与 LINDA，L-CNN 对降水低估更少，短 lead time 指标有所提升。

**方法概述**

L-CNN 先利用运动估计把欧拉坐标中的降水场转换到拉格朗日坐标，使主要平移运动被显式移除；随后对连续雨强场的差异建模，让 CNN 专注学习局地增长、衰减和结构演变，而不是同时学习平移和强度变化。参考模型包括 RainNet 和 LINDA，其中 RainNet 提供深度 CNN 基线，LINDA 提供光流 / 外推基线。

**主要贡献**

1. 将平流方程思想与 CNN 结合，把降水生消从平移运动中分离出来。
2. 在拉格朗日坐标中训练 RainNet 式 CNN，以改善强降水低估和时间演变表达。
3. 在 Finnish weather radar 数据上与 RainNet、LINDA 比较，并公开代码和数据说明。
4. 为“显式运动处理 + 轻量 CNN”路线提供可复现基线。

**与基于雷达回波的降水临近预报的关系**

相关性高。论文直接处理 convective rainfall nowcasting，实验使用 Finnish weather radar / radar reflectivity 数据，并比较雷达 nowcasting 常用深度学习和外推基线。它适合与 RainNet、SmaAt-UNet、pySTEPS、LINDA、Lagrangian deep learning 方向一起整理。

**值得关注的原因**

很多深度模型直接把历史雷达图像映射到未来图像，容易把运动和平流误差混在一起。L-CNN 的思路是先把主要运动显式剥离，再让网络学习降水生消，有助于分析“物理预处理 + 深度模型”相比端到端 Transformer / diffusion 的优势和边界。

**可能局限**

论文是 2023 年正式发表、2026-08-01 才被 Crossref 重新索引的旧文献；不命中 CIKM、ShangHai、SEVIR 或 MetNet。方法依赖运动估计和拉格朗日变换质量，在快速新生对流、缺测和复杂地形场景中可能受限。

**后续讨论问题**

1. L-CNN 的性能提升来自拉格朗日坐标变换，还是来自 RainNet 训练目标和数据处理差异？
2. 该方法能否与现代 flow matching / diffusion 模型结合，把显式平流作为条件或先验？
3. 在 SEVIR、Shanghai-Radar 或 CIKM 上，拉格朗日预处理是否仍能改善高阈值强回波指标？
